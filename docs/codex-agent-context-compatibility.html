§1 — Outcome

A fresh Codex or Claude session must automatically receive the applicable user-global and project-scoped rules, and must be able to prove what it loaded. “Read by default” means instruction files are in the initial effective chain and skill metadata is discoverable; full skill bodies remain trigger-loaded so context stays bounded.

§2 — Implementation

  1. Create ~/.codex/AGENTS.md as a managed link or generated shim to the canonical ~/.agents/AGENTS.md.
  2. Raise project_doc_max_bytes to a measured safe value and add a budget report so truncation is visible.
  3. Add an agent-context doctor that reports canonical path, agent-specific entrypoint, root-to-target instruction chain, byte count, digest, skill metadata roots, and which skill bodies were activated.
  4. Require target-path preflight before dispatch so nested AGENTS.md files are included even when the orchestrator launched at repository root.
  5. Reconcile Nova main/develop instructions and remove stale git recipes; validate Claude-only HPC skills before mirroring them into ~/.agents/skills.

§3 — Acceptance and evidence

The research input is Codex Agent Context Audit. Landed evidence must cover black-box launches from user home, repo root and nested physics/GPU directories; instruction digests and byte counts; skill discovery and trigger activation; and negative cases for stale, missing and conflicting files.

§ Decisions

One canonical source prevents Claude and Codex policy drift while preserving each agent's discovery convention.
