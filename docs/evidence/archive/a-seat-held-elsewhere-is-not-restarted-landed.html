§3 — why the hook still reads no producer

Cause. The seated producer publishes obligation snapshots only for sessions whose list_followers row reads live (reckon/crew/runs.py:1920-1927 at 81b1d6e). live requires the registration's recorded pid and parent pid to be alive in the producer host's process table (reckon/crew/follower_registration.py:506-533), and the registration records no host (:296-307). A follower attached from another host therefore reads registered=True live=False, no snapshot is written for its session, and freshness returns NO_PRODUCER on the absent document (reckon/crew/obligation_snapshot.py:385-386) before its foreign-seat fallback (:389-390) can apply. The prompt hook takes the not-fresh branch (reckon/hooks/coordinator_obligations.py:904-907) and prints the literal "no producer" (:747-769).

§2 — a producer finding a foreign seat waits instead of exiting

_watch_registration in reckon/crew/recovery_watch.py now loops. While seat_names_a_live_foreign_producer reports the project's seat held by a producer on another host whose stream is fresh, it sleeps FOREIGN_SEAT_REREAD_SECONDS (5 s) and re-reads the seat, taking it once that stream goes stale or the seat is released. Any other held seat is reported as before. The stream seed is read once, by the producer's first sweep in runs._publish_watch_transitions, and kept on the producer record as seeded_states. The seat's own ticker takes that read instead of reading the stream again.

§8 — a follower on another node is judged by a lease it renews

Run r-20261015T152637789069-a-follower-on-another-node-renews-a-lease, merged into main as bbaee1634 at reviewed head 9651d949e.

In reckon/crew/follower_registration.py, _follower_liveness judges a registration from another host by a lease, not by its node-local flock. The lease file comes from follower_lease_path and is renewed by renew_follower_lease. The lease decides registered, live and released together, so session_follower_released and the dispatch admission read it too. The follower renews the lease on the same wait pass that renews the producer's lease, in reckon/crew_follow_commands.py.
