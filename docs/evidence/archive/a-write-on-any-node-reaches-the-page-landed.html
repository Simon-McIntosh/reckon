_FleetChangeWatch now runs a detector thread beside its inotify event loop. Every 10 s the fast pass compares each mounted tree's directory identities against the stamps the index persisted, and reloads those stamps when the persisted index file changes. Every 60 s, for a tree with an open change stream or read through /_index or /_discover in the last ten minutes, the slow pass compares the covered files' count and newest mtime. A change invalidates the tree's views once and writes one byte to each wake pipe its open streams registered. _ProjectChangeWatch.wait treats a readable pipe as a change. close() stops and joins the detector thread.
