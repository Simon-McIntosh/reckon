§11 — The fleet supervisor runs current code

The supervisor's request loop in reckon/crew/fleet_supervisor.py compares its start-time code stamp with the checkout's on every pass. When the stamp has moved it asks served_code.moved_checkout(), the trust decision served code already makes. On a trusted move it re-executes itself through _reexec, the path a manual reload takes, and the declared services it adopted keep running. A checkout with a tracked file modified is not trusted, so the supervisor keeps its image. The trust test loads the whole package, so it runs at most once per 60 s, and a refused stamp is asked about again after that interval, so a passing refusal (dirt later discarded, an import probe that timed out) cannot pin a stale image.

Why: on 28 October the station was down for 73 minutes while the supervisor ran eight-day-old code that did not know the station request.
