What this node could not do

A stored review requires a delivered report.md and its code-review.json sidecar under ~/.config/reckon/crew/reports/<project>/code-review/<neighbourhood-key>/. This run's fence mounts that root read-only: reckon crew review fails with [Errno 30] Read-only file system on the composed directory, so the review can be neither composed, dispatched nor stored from inside the node.

The review itself is produced and held at <run>/code-review/16d8dbaf3cd2/report.md with its sidecar. The coordinator, whose shell is unfenced, lands it with:

install -D <run>/code-review/16d8dbaf3cd2/report.md \
  ~/.config/reckon/crew/reports/reckon/code-review/16d8dbaf3cd2/report.md
install -D <run>/code-review/16d8dbaf3cd2/code-review.json \
  ~/.config/reckon/crew/reports/reckon/code-review/16d8dbaf3cd2/code-review.json

then stores it through reckon.crew.plan_review.store_delivered_reviews("reckon", <any-live-slug>), which walks every delivered code review for the project. The findings then appear at crew(view="findings", path="reckon/crew/promotion_") and are disposed with reckon crew dispose --run <review-run> --finding <n> --kind exempted|folded: the three stale rows are exempted as already repaired, the interface-growth and test-debt rows are folded into follow-on nodes, and the duplicate-capability row is folded into the treatment node named above.
