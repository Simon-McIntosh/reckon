§2 — The index is the contract

Commit 1720fe8 removed the PNG-header read from the capture gate. Each capture is validated from its index entry and the stat of its named file: recorded width and height, nonempty filename, file presence, nonzero file size, population fields, and the plan's declared surface and width set.
