The change

_review_dispatch_fields in reckon/crew/recovery.py owns the composition once — project, plan, section, node id, goal, done-when, write path, time budget, session — and _review_dispatch_argv, _review_dispatch_action and the new dispatch_review_for_run all read it, so the command a record carries and the dispatch it performs cannot drift apart. dispatch_review_for_run takes one scoring run and returns a report rather than raising: dispatched says a review run is now in flight, awaiting_lane says the lane was unavailable and the reason is recorded against the run, refused carries whatever admission said no. recover runs the reflex for every scoring run it classifies and reports the outcome per run alongside its existing counts.

The node is dispatched as role=review with a write path outside the repository, because the review role is repository-write-restricted and the review store lives under the delivery root. The dispatch passes watch_required=True, which is the same admission a coordinator’s crew dispatch passes. The refusal is caught rather than propagated, and that is deliberate: the caller is a sweep over the fleet, and one run’s refusal must not stop the rest. The refusal itself still comes from dispatch.

§5 — A released registration is swept by age

Run r-20260918T161024019059-a-released-registration-is-swept-by-age. Commit a77bd30b, 173 insertions across reckon/crew/runs.py and tests/test_follower_freshness.py — the two authorised source paths, with no deletions and no new imports.

Mechanism. The previous anchor made the payload count the released registrations instead of listing them; nothing yet removed a file. Releasing a registration drops its advisory lock and leaves the path in place on purpose, and a read path must not unlink either, because a reader that did would put two inodes behind one session's name — a claimant opening the old file and a fresh one on the same path would each hold the lock. So the registry only grows, and sweep_released_followers is the one explicit maintenance call that trims it: it takes each file's lock itself, unlinks only when the lock is free and the file is older than the threshold, and returns the entries it removed so the caller reports a count. A claimant arriving while the sweep holds the lock is refused by _FollowerRegistration.acquire rather than silently succeeding.

Where the age comes from

The transition record carries counts, not per-item ages, so the age of a bucket's oldest member is derived in the renderer from the transitions the pane has itself observed, using each event's own observed_at as the clock. A run already in its bucket keeps the stamp it arrived with, so an unrelated transition cannot reset the reading, and a run that leaves every bucket is dropped because it is no longer a member of anything the row counts. The bucketing is read from reckon.crew.recovery's fleet partition at call time rather than restated, so the counter and the age that qualifies it always describe the same population; a held run counts as queued as the partition reads it.

The age is a reading within one pane's own view. A re-attach restamps every live run, because an age nobody observed cannot be reported honestly; a baseline row therefore carries the attach time rather than a history. The clean fix is for the producer to carry the age on the event, which is outside this node's write scope and is recorded as a follow-on.

Why the ages are paid for out of the margin

A reserved fixed-width age block was measured first and refuted: the reason text starts at screen column 132 for both widths, leaving the age budget at effectively one column, because test_crew_ticker_layout.py requires the clipped reason to keep the 47-character predicate clause at 180 columns and at least 75 columns at 208. Widening the counter block by 12 columns broke six layout tests and shortened the reason onto a row a reader cannot act on.

So the ages take fixed columns ahead of the reason only where the clipped clause does not need them, and blank when a clause claims the margin whole. What is present holds its room and what is absent holds none. A clause that fills the margin wins, because it is the actionable text and the age is a reading of it. The row's right edge never moves and no line ever wraps: an age that widened the block would shunt every column to its right and cost the reader a second line of an eight-line pane.
