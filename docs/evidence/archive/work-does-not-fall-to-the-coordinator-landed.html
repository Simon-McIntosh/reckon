Roster commit content agrees with its message

The previously recorded mismatch reproduced at base 51c2b9e0. A default registration of internal-a left the roster uncommitted; a subsequent commit=True registration of public-b created one commit whose subject was chore(roster): register public-b while its content carried both members. The checkout was clean afterward, so the earlier registration had been silently absorbed rather than left visible.

Commits cf9afcf1 and c57ec115 choose the explicit-refusal design. Before writing, a committing registration now inspects only the roster path. If that path is dirty, it compares the current roster with HEAD, names the blocking registrations, and refuses. The reproduced sequence now reports cannot commit roster registration 'public-b': uncommitted member registration(s): internal-a, creates zero commits, retains internal-a, and never writes public-b.
