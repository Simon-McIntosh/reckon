§9 — The server records each request's duration, in a bounded log

Run r-20261018T133140302224-request-duration-and-bounded-log (head 10bf1675b). Each request now logs one access line carrying its duration in milliseconds, and each response carries a Server-Timing: app;dur=… header. The header is sampled when the headers end; the access line is sampled when the request ends, so for a response with a body the line's figure is the larger. The served log is bounded at 8 MB. An over-bound file is copied to one predecessor, server.log.1, and the live file is emptied in place, which works with the unit's StandardOutput=append: descriptor because every append re-seeks to the end.
