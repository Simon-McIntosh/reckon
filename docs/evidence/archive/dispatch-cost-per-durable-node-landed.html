§7 — The pilot was retired because the measurement had already happened

The qualification ladder declared a 20-to-40 run gated pilot, elapsed about two days, to produce a rework figure and hence a cost per durable node for the one marginal candidate lane. It was retired as a declared measure on lead authority on 2026-09-14 rather than run. The argument is that the pilot names a quantity the ledger had already accumulated from ordinary merged work, past the band the section itself set.

Sample counts against the section's own stated requirement — roughly 20 runs for a two-standard-error separation and about 40 to be comfortable:

The section's own break-even bar would have rejected this, and the bar was the weaker instrument. It set a 0.24 rework ceiling derived from published benchmark tool-steps. Measured rework is higher than the incumbent's at both levels — 0.278 against 0.330 at exact, 0.288 against 0.247 at guided — and the candidate is still far cheaper per durable node, because its median input is much lower. A rework-rate threshold is a proxy for cost per durable node; the ledger now carries the direct measure, and where the two disagree the direct one is what the plan set out to route on.

The distinction the section defends is merged versus never-merged, not dedicated versus organic. A shadow run contributes no rework figure because nothing can later re-touch its paths; every run counted above was merged real work, so the objection does not reach them.

Caveat carried, not dropped. The routing surface reports short_window_can_reflect false, so rework that has not yet surfaced is absent from both figures. At 66 and 300 samples over a long window this bites far less than it would on a fresh 20-run pilot, but it is not nothing, and a later reader revisiting this decision should start there.

Acted on the same evidence before the retirement was authorised: the candidate is slice-locked into roles.implement.by_spec_level for exact and guided in the host flight layer, per the ladder's own decision rule.
