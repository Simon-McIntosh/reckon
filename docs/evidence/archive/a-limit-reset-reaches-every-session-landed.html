§1 — a limit reset is one record, landed

reckon crew budget --reset --group <group> --used --reason "…" now records one reset event in the banked-reset store whether or not a banked flag is available. The event carries an id, the instant (now or --from), the clock, the announcer, the required reason and an optional --session scope, and it clears an available flag only for a global event. A second global announcement for the same group and clock within ten minutes returns the first event. budget_reset.recent_resets reads announced and detected events for a session, and crew budget --list shows the last day's events.
