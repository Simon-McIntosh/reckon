Prior-art reconnaissance — the meter surface and the refusal stamp

The headline finding is that nothing in this section requires a newly authored derivation. Every figure the surface needs is already computed in Python, and both refusal detections already exist; what is missing is persistence and a display.

Already computed, and not to be re-derived in the surface

reckon/budget.py's BudgetState already carries utilisation, burn multiple, projected exhaustion, the window period, the reset and the observation time. The window-selection machinery already distinguishes a lane's own window from a shared account figure, returning own, shared or own-unmeasured — the same distinction the borrowed-figure measure needs, one layer down. Building a second computation in JSX would be the defect the repository's render-never-derive invariant exists to prevent.

The meter primitive exists and is the right one to extend

The Crew surface already carries a track-plus-fill meter with a percentage label, styled in docs/ui/crew.css. It currently shows time budget rather than quota, so a quota meter is a second use of the same primitive, not a new one. Three other progress bars in the SPA are explicitly not the right primitive — different semantics and thinner. No new CSS token is needed; the accent, warning and background tokens already exist in the shared foundation.

Two refusal detections exist; neither persists where it must

One reads the live run's stream for the newest rejected rate-limit event; the other classifies a rejected threshold status into a blocked reason. Both are pure readers. What is written today goes to the committed ledger — which is precisely the store the survivorship trap excludes, because a refusal kills the run, a killed run never promotes, and so no ledger row is ever written for the one event that proves a limit exists.

The lowest-cost durable slot was already declared and empty. The run store — an embedded database on the shared config home, outside both the run directory and the committed ledger — carries a holds table in its schema that nothing writes. Both halves of the survivorship requirement hold there by construction.
