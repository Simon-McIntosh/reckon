Only a version tag sets the version — landed evidence

One section, one measure, passing. What makes the record worth keeping is the shape of the verification: the defect was demonstrated to be fixed as a class, with the offending tag deliberately left in the repository, rather than made to disappear by deleting the tag that exposed it.

Record scope

A rescue tag named rescue/spec-level-names-a-backend-957c042 ends in a commit sha. The default describe pattern accepted it as a version tag, the version parser then failed on the name, and every wheel build in the repository failed with it — five test ids, none of which had anything to do with packaging. The fix constrains both halves in pyproject.toml: the describe command matches only v[0-9]*, and the tag regex admits only a release-shaped version.
