§3 — a review round's id carries the head it read

Run r-20261012T225451838591-a-re-review-round-has-its-own-identity, commit f5c9157f8, merged at e4c010554. The run-review node id is now composed by the rule repair_node_id already applied, <prefix><source>-<head[:12]>. That rule is now shared as round_node_id and round_node_source in reckon/crew/repair.py and applied in reckon/crew/recovery_review_subject.py. A re-review of a resumed run whose head moved therefore never reuses the earlier round's id, nor collides with its worktree.
