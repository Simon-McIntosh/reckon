Method and the reproducible denominator

The denominator is the plan's declared sections that carry a deliverable: every section declared implementable or done, except §1, which counts only when declared implementable. Where a plan carries no plan-section-declarations meta, the denominator is its authored h2 count less §1. The declaration is read from reckon's own reader, reckon.mcp._read_plan(project, slug, view='raw')['data']['section_declarations'] — not from a hand filter and not from the plan's stored impl. The command below prints every plan's denominator and the exact sections counted; run it from the worktree root.

PYTHONPATH=. .venv/bin/python - <<'PY'

"a-review-dies-where-nobody-is-looking"]
for slug in SLUGS:
    d = _read_plan("reckon", slug, view="raw")["data"]
    decl = d.get("section_declarations")
    if isinstance(decl, dict) and decl:
        counted = sorted(s for s, c in decl.items()
                         if c in ("implementable", "done") and not (s == "s1" and c != "implementable"))
        src = "declarations"
    else:
        soup = BeautifulSoup(open(f"docs/plans/{slug}.html").read(), "html.parser")
        counted = [h.get("id") for h in soup.find_all("h2") if h.get("id") and h.get("id") != "s1"]
        src = "authored h2 minus section 1"
    print(f"{slug:58} {len(counted):2}  {src:22} {','.join(counted)}")

Presence is read by opening each counted section's implementing symbol at head with git grep -nE '<symbol>' HEAD -- <paths> (or git show HEAD:<path>); a section is counted present only where that file and symbol were found, and the row names them. A test file alone is never a citation for a product deliverable. A section whose implementation was not found in this round is counted absent — the reading records what was verified this round, not what the plan's own stored impl claims.
