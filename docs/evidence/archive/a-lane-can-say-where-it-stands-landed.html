The coordinator gets its own reserve

Landed 2026-09-14, commit 5e3e041. A declared coordinator reserve is now subtracted from the dispatch ceiling, alongside the resume reserve that was already there and withheld for a different purpose.

Why it is declared rather than computed. There is no measurement of coordinator burn on this machine; the client's transcripts do not persist a quota position, and inventing a figure and presenting it as measured would be the precise error this plan exists to correct. The reserve therefore ships as a declared default with its reasoning recorded in the schema description beside it, and a cadence of account-surface readings is what calibrates it later.

The consequence it prevents runs in the dangerous direction and is worth restating: the account position already counts every consumer, including the coordinator running the wave. A wave sized to fill the remaining headroom leaves nothing for the coordinator that must survive it to audit manifests, merge commits and record outcomes. If that coordinator is refused mid-wave, every worker's output is stranded in a worktree with nobody to land it — the workers succeed and the wave is lost.

Measure: 144 passed, 0 failed across the reserve, flight and budget suites; 12 tests added. The chain mirrors the existing resume reserve end to end — schema entry, shipped default, generated model, policy read, subtrahend in the effective ceiling, and a fence test proving the reserve holds a dispatch while permitting a resume. Re-running the schema generator produces no diff, which is the check that the generated module was regenerated rather than hand-edited.

The refusal reason names which reserve was subtracted, so a held dispatch is arguable rather than opaque.

The dialect owns its reading, and its transport

Landed 2026-09-14, commit fab092d. The claude dialect now returns its own quota reading from the account surface instead of describing a probe for a module-level function to execute. The surface answers for free — an account metadata read rather than an inference request — so the position no longer has to be inferred from worker streams that stop arriving the moment nobody dispatches to that lane, which is the decay this plan is named against.

Parsing is strict in the direction that matters. A named window and a numeric utilisation are required; anything else returns unknown rather than a low figure, and a missing field never resolves to zero. Credential expiry produces unknown too — never a clear reading and never an exhausted one — because the honest answer when the instrument cannot read is that the position is not known.

Measure: 13 tests added, 86 passed across the account, budget and lanes-view suites, no regressions.

Two findings the coordinator's verification produced, not the manifest

The manifest was empty. It reported status: complete with commits, changed_paths and tests all blank, while a real commit sat one ahead of the base with a clean tree. The commit, the scope and the test delta were all established by reading the worktree rather than by reading the report. A promotion trusting the manifest would have recorded nothing.

The prior-art scout predicted the exact gap, forty minutes before the node ran. Its map warned that a node which only adds a method on the dialect would leave _declared_probe_command reporting the old answer, because that function asks whether a probe is declared without executing one. That is precisely what happened: the worker added a new reading method, never overrode the base method the lanes view consults, and did not touch mcp_views.py despite declaring it in scope. So the lane can now read its own position while the surface still reports it as having no probe. Followed up rather than treated as failure — the node's stated goal was the dialect reading, and that is met and tested.

The value there is the instrument existing beforehand. A scout costs one read-only node; the alternative is finding the same gap weeks later through a surface quietly saying “unobserved” about a lane that knows exactly where it stands.
