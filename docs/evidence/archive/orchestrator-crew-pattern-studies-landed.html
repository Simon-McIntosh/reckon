Worker anatomy: where turns and context go

What was asked. A census of how crew workers spend turns, attention and context by lane and role, for runs dispatched in the study window, reporting per cell the median and p90 of first-request input tokens, assistant turns, turns before the first file edit, the share of tool calls reading record-keeping material (plan, evidence or research HTML, AGENTS.md, skill files, manifests), the share of file edits by class, the share of wall time inside gate or test commands, and self-verification reads — each with its sample size, stratified by run outcome.

Two shapes. The clearest structural finding is the turn shape: clive-dialect workers read before they write (clive/implement reaches its first edit at median turn 30 of 88), while codex-dialect workers write before they read (first edit at median turn 2, finishing in a median of 14 assistant turns against clive's 88, and 5 in review against 46.5). Both shapes reach the same promotion outcomes, so the census states the shapes; which produces the better work is the synthesis node's question, not this one's.

Proof. Two consecutive runs of the script are byte-identical (run.log, kept with the artifact). Because the run store grows after the capture instant — an unpinned re-run two minutes apart differed by one run — the population is pinned in population.json and the script reads the pin when it is present. Each stream grammar is proved on one named healthy run: claude grammar r-20260914T160220568583-cca-solve-profile-kernel-count parses to 319 assistant turns, 64 tool calls, first edit at turn 112; thread.started grammar r-20260915T041619672372-cca-private-region-figure-and-wedge-audit to 19 turns, 190 tool calls, first edit at turn 2. The script refuses to write output if either proof parses to zero turns or zero tool calls, so a silent parser failure cannot produce an empty census. After the final edits, re-running against the committed anatomy.json reproduced it byte-for-byte (log in the run directory).

Limits, stated rather than smoothed. First-request input tokens are unmeasurable on the codex grammar, which publishes only a whole-turn usage sum, so those cells are reported as such instead of labelling a whole-run total "first" (the call carryover_census makes). Gate wall share is claude-grammar only, since the codex dialect emits no timestamps. Outcome strata are thin where outcomes are rare — every cell names its n in anatomy.json (48 strata cells). A discarded stratum resolves to zero because crew discard leaves no durable per-run terminal record this census can read; those runs land in no_terminal_record or complete_unpromoted.
