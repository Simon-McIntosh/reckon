A Worker Knows It Is On Compute — landed evidence

One cumulative record per plan. Each node appends its own section; this anchor carries the declared bound, the three observations that show it firing, and the negative control.

§5 — The suite carries its own bounds

What was declared. pyproject.toml adds pytest-timeout and pytest-xdist to the dev dependency group and a [tool.pytest.ini_options] section whose sole key is timeout = 300. The three named tests below were observed in that order (pip-free, through the declared plugin set), then the declaration was removed to falsify its effect. uv.lock was regenerated with uv lock (117 packages resolved; execnet 2.1.2, pytest-timeout 2.4.0, pytest-xdist 3.8.0 added).

Three observations, one mechanism

ObservationCommand shapeHeader the plugin printedResult
Bound fires pytest … -o timeout=2 timeout: 2.0s 1 failed — Failed: Timeout (>2.0s) from pytest-timeout at the time.sleep(10) line
Declared default is live pytest … -n 4 tests/test_doccheck.py timeout: 300.0s, configfile: pyproject.toml 25 passed in 2.00 s across 4 workers
Mutation: line removed pytest … with no override, bound deleted — no timeout: line (the bound is gone) 1 passed in 10.04 s — the 10 s sleep no longer times out

Why the middle row is the load-bearing one. The first row shows the plugin can be told to fire, which a -o flag would do whether or not the file declares anything. The middle row is the only observation that reads the declaration itself: its header prints configfile: pyproject.toml and timeout: 300.0s, so the 300 is the file's and not the command's. The third row removes that line and the header's timeout: entry disappears with it, so the middle row's value is shown to be produced by the declaration rather than by the plugin's mere presence.

What the throwaway test is for. It lives outside tests/ under /tmp and does one thing — time.sleep(10) — so the red is unambiguously the bound rather than a real defect. The third row's green is the control: it shows the same file passes when unbounded, so the red was the bound speaking.
