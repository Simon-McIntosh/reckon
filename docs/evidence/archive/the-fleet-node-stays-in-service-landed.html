§7 — a watch producer sweeps the whole fleet every second

Each producer cycle lists every project's live pointers, walks run directories, parses streams and calls git on a 1 s beat whether or not anything moved. That costs about 1,880 opens, 1,575 stats and 1.25 git-shim calls per cycle, which is 114 to 115 git executions in 32 s, independent of the live pointer count. Five producers make roughly 9,000 GPFS opens a second and about 35 of the node's 80 process creations a second. The change-driven fix is to gate the sweep on inotify, or on one mtime stat of the crew home, and keep only the liveness probe on the beat.
