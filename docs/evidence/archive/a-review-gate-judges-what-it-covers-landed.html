A queued request is checked against its own contract

queue_admission.record_review_contract stores a queued request's section and contract digests. The admission pass holds a request that has a current contract record only while its own section or the document contract has an unreviewed change. A request with no current record keeps the dispatch gate's hold, and so does a request whose stored reviews cover none of the units it reads, so a queued request and a fresh dispatch give the same verdict. plan_review_units has one definition, in routing.py.
