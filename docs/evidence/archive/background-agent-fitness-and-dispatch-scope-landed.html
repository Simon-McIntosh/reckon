Interpretation recorded for review

The ruling says "one artifact"; the cue in this node's brief glossed it as "at most one non-test path". Read literally over all write paths, that would refuse every node dispatched on a plan — including this one, whose record carries the two shared landing paths — which contradicts the same brief's requirement that this node's record pass. The judgement therefore excludes test paths and the two landing records, which is the repository's own existing notion of what a node's scope contains (reckon.crew.dispatch._shared_landing_paths: the plan file and the cumulative evidence record "are shared by all of them rather than owned by any one"). A node that produces two source artifacts still fails one-artifact.
