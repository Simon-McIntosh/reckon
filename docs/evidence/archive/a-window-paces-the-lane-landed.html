§4 — The bookend reserve holds from the start of the window

A review dispatch verifying a local repair is small and bounded, and it is the first thing an audit wave starves: the wave ahead of it spends the window, and the bookend that would have closed the repair waits for a reset. The fix makes the window two pools rather than one. A fraction of every window is reserved for the review and verify roles and is not available to implementation work at any bar.

The reserve holds from the start of the window, and that is a property of the arithmetic rather than a branch on window state: a non-bookend role's ceiling is the window ceiling less the reserve outright. Nothing is withheld until the window fills, so the fraction is already gone when the window is empty. A rule that withdrew the fraction only near the ceiling is a function of utilisation; this one reads the role and the configured fraction alone.
