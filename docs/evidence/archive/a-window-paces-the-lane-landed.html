§4 — The bookend reserve holds from the start of the window

A review dispatch verifying a local repair is small and bounded, and it is the first thing an audit wave starves: the wave ahead of it spends the window, and the bookend that would have closed the repair waits for a reset. The fix makes the window two pools rather than one. A fraction of every window is reserved for the review and verify roles and is not available to implementation work at any bar.

The reserve holds from the start of the window, and that is a property of the arithmetic rather than a branch on window state: a non-bookend role's ceiling is the window ceiling less the reserve outright. Nothing is withheld until the window fills, so the fraction is already gone when the window is empty. A rule that withdrew the fraction only near the ceiling is a function of utilisation; this one reads the role and the configured fraction alone.

§5b.i — The re-query, and what it returns when it cannot answer

The plan's premise for this section is a view that hands back a 2.4-hour-old receipt and a 6.7-day-old one as though they were positions. A five-hour window rolls over several times inside 2.4 hours, so an old figure is a statement about a window that has already closed. The landed mechanism decides, per reading, whether the figure and the age it carries are enough to report it, or whether the lane's own probe must be asked again.

Commit 0fc81fc, 161 insertions across the module and its tests. Gate pytest -q tests/test_staleness.py — 8 passed.

Reading inside its shelf life. The reading is returned as a position with its own serving state and requeried=false, and the probe is never called. The test supplies a probe whose body raises, so a call that should not happen fails loudly rather than passing silently — the assertion is that the re-query is not unconditional, which a test written without that guard could not show.

Reading past its shelf life. The probe is asked once; its figure and provenance are what the caller reports, with requeried=true.

A re-query that fails. Two failure shapes are driven — a probe that raises, and a probe that returns no figure — and both must not be read as a measurement. The old figure survives with its age and a serving state of unknown: neither a fresh-looking number nor nothing. That the returned used_percent is the old value and not the probe's is what makes "not a fresh-looking number" an assertion rather than a hope.

An undated reading is not trusted. A reading with no observation time cannot be shown to be inside any shelf life, so it is re-queried like a stale one; if that also fails, its age is reported as unknown rather than invented. This is the plan's carry the age with the figure rule applied at the one point it must be.

The shelf life is a flight key, and its change moves behaviour. The resolver reads budget.evidence_shelf_life_minutes through the same budget.policy the fence uses, and the test drives two resolved configs differing only in that key: a 90-minute-old reading re-queries at a 60-minute shelf life and is trusted at 180. The test asserts the resolved key values before asserting the behaviour, so a config plumbing error cannot masquerade as a passing boundary.

§2 — The pace function, on two clocks

Commit 6fa4a99c. The allowance for a declared budget group is

remaining_budget  = 1 - utilisation
remaining_windows = (D - elapsed) / 5h
allowance_5h      = pace_multiple * remaining_budget / remaining_windows

with D the weekly period less a configured lead time, and the provider's own five-hour ceiling applied last as a separate number. The last window before the deadline is asked for whatever remains rather than for a share, so the deadline itself cannot construct a hidden None through a denominator of zero. A ceiling that could not be read is not a ceiling: the effective limit falls back to the derived share, because absence of a signal is not evidence of absent headroom.

§3 — The bar names the lane, and never holds a prescribed node

Commit ea8d38f5. The module is reckon/crew/bar.py and its gate is tests/test_bar.py; both are new, so the baseline is an empty file set and all nineteen cases are this change's own. pytest -q tests/test_bar.py — 19 passed, exit 0, through the repository's root environment with the module asserted to resolve to the worktree copy of reckon.crew.bar (/home/…/the-bar-names-which-lane-it-recommends/reckon/crew/bar.py) rather than to a sibling checkout.

Four verdicts replace the single send that covered both lanes. send-metered is a node that clears the bar with room left in the window; send-local is a node the free lane executes as written; split is a close call in the band below the bar; and hold is a node too open-ended for the free lane, or one the full window has no room left for. The order of the tests in the one decision function is the policy: prescription is judged before the bar, because at a full window the bar sits at its ceiling above every prescribed score and a node judged by the bar alone falls through it into hold.

The bar is a smoothstep in the fill and is asserted monotone at 201 points, not at transitions a continuous bar does not have. It is fill²(3 − 2·fill): zero at an empty window, one at its ceiling, flat at both ends and steepest in the middle. One fixed score therefore travels from an admitted metered send at an empty window through the near-bar band to a hold at a full one, which is the only assertion that proves the bar reads window state at all.

The two assertions the rejected implementation inverted are pinned separately. A maximally prescribed node (score 0.0) is send-local at every fill sampled across the whole domain including a completely full window, asserted as a set of one over 201 fills and then again at the ceiling alone. A maximally open-ended node (score 1.0) at that same full window is hold and explicitly not either send, which is the other half of the same inversion. And hold is asserted to be decided by the score with the fill held constant at 0.85: varying only the score produces both outcomes, and every held score is above the prescribed ceiling.

No routing is checked against the type's own field names rather than a blocklist of lane spellings. The field set of Recommendation is closed to {verdict, bar, score, window_fill, margin, override}, so a field added to carry a routing fails the check whatever it is called — where a blocklist of the lanes spelled today would pass a lane spelled tomorrow, which the review of the rejected node found. The two string fields are additionally asserted to hold only a verdict.

The clamp branch is driven in both directions, since no case exercised it before. A fill of −0.4 comes back with window_fill 0.0 and bar 0.0 and the verdict of an empty window; a fill of 1.6 comes back with 1.0 and 1.0 and the verdict of a full one. And an orchestrator override in each direction is recorded rather than refused: a hold overridden toward the free lane and a metered send overridden toward hold each keep the bar's own verdict untouched while override and effective carry the decision; a value outside the four outcomes is a caller error, not a decision against the bar.

§7 — A hold carries the evidence that produced it

The plan's premise is that a governor holding on a figure it cannot vouch for is worse than none, because the hold looks identical either way. The landed mechanism makes the hold a record that cannot be built without its evidence, and refuses the three ways a hold can look real while resting on nothing.

Commit 3094ce26, reckon/crew/hold.py and tests/test_hold.py. Gate pytest -q tests/test_hold.py — 13 passed; the gate over the consumed modules, tests/test_hold.py tests/test_staleness.py tests/test_budget_group.py — 33 passed.

The four omissions, each refused on its own. One parametrised test drops each of the four facts in turn and requires MissingHoldEvidenceError; the assertion is on the exception's field attribute, so nothing depends on the wording of a message and no test inspects a formatted hold. A second test fixes a figure under the omission check: a figure of 0.0 and an age of 0 are measurements and are accepted, which is what makes "missing means None, never falsy" an assertion rather than a convention.

The re-query is not unconditional and the hold rests on what comes back. A reading inside its shelf life is held on with the probe never called — the forbidden probe in that test raises if it is asked, so the assertion that the re-query is bounded fails loudly rather than passing silently. A reading 2.4 hours old with a probe answering 97 over a stale 80 yields a hold whose figure is 97, which is what makes "hold on what comes back" observable.

Unknown does not hold, and the refusal is shown to rest on the unknown state. The test drives the staleness reader with the same input first and asserts its serving state is unknown, then calls the hold path and asserts no hold — so the refusal cannot be passing for an unrelated reason. The stale figure is 95, above the ceiling of 90: it would hold if unknown were read as exhaustion, which is the plan's asymmetry stated as a measurement rather than a preference.

A borrowed figure never becomes the group's position. A reading whose source names codex-main sits in a spark group's position above the ceiling, inside its shelf life; no hold is produced and the probe is never asked. A reading whose pool is not stated at all is likewise not owned and is not adopted on trust — a figure that cannot be shown to belong to the group is treated as unscoped rather than assumed to belong. An unobserved position and a figure below the ceiling complete the set, each asserted separately.

§6 — The pace is visible before a wave opens

The section's premise is that a governor nobody can see is a governor nobody trusts, so the pace has to be readable before a wave is committed to rather than discovered in a refusal. budget.preflight now carries a groups key, one entry per declared budget group, built by budget.group_pace. Each entry holds both metered clocks with the age of each reading, the allowance reckon/crew/pace.py derives from the week the group has to last, and the bar reckon/crew/bar.py draws for a stated ready set.

The measure, and what it reads

Asserted from the payload, never from the summary. Every case reads the returned mapping's fields. The summary is prose a reader parses; the payload is what a caller routes on, and a test against the rendered string would pass while the field a caller reads was absent.

Each clock carries its own observation age, including a fresh one. A reading three seconds old reports an age of three seconds, so a reader never has to infer that a missing age means a current reading — the inference that turns an absence into a measurement.

One wallet, one reading. A group is read once, from its newest dated member, because lanes sharing a wallet hold one allowance between them and a per-lane figure would report each share as though it were the whole. An undated reading does not compete: a figure that cannot be aged cannot be told from a current one. The allowance is not re-derived here — the test recomputes it from the emitted clocks through pace.allowance_for_group and compares, so a curve restated inside the payload would show as a mismatch.

The bar is drawn against the five-hour clock, not the week. The two clocks are set to disagree in the fixture, because only one of them fills. The bar's value is asserted equal to bar.recommend(fill, score) rather than to a literal, so the curve stays the module's.

Four outcomes, and the buckets partition the set. A ready node is named with the bar's own verdict — send-metered, send-local, split, hold — and the four buckets are asserted to partition the stated set exactly, so a node cannot be silently dropped from every bucket. Each node keeps its own group's bar, because a wave's nodes are judged against the wallet they will spend.

Prescription is judged before the window. A node whose shape is read off its own record is local at every fill, so its outcome is the same at every fill and is therefore decidable with no reading at all. Its window_fill is still reported unread and its decided_by says prescription, which keeps "we read a window" apart from "no window could have changed this". A node with open-endedness left to invent is undecided, with no verdict, rather than judged against a fabricated empty window.

A malformed ready set is refused. A node naming an undeclared group raises with the declared groups named; an unscored node raises. A ready node silently missing from the admitted set is the failure a pre-flight exists to prevent, so it is refused rather than skipped.

Unknown is not a zero, applied to a second quantity

A group no reading reached reports state: unknown, None for both clocks' utilisation, both ages and every derived allowance field, and an explicit reason. The assertion is two-sided — the figures are absent and not 0.0 — because a zero utilisation reads as an empty window and would admit everything, which is exactly the substitution budget.py already refuses for a hold. The rule is the module's first rule applied to a second quantity, not a new one.

The partial case is kept distinguishable from the empty one: where the weekly clock was read but its reset stamp cannot be placed in the week, the measured utilisation is still carried and only the derivation is withheld, with the reason naming what is missing. A spend that cannot be placed in the week is a different report from a group nothing reached, and collapsing them would lose a measurement to save a line.

The command's payload was asserted to be unchanged apart from the addition: the field set is compared against the pre-existing names plus groups alone, and a run naming a window and a ready set is asserted to leave the hold decision, the held and clear backend lists and the resume figures byte-identical to a run naming neither. The pace is added to the pre-flight, not substituted for any part of it.
