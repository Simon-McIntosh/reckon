§2 — a worker never outlives its supervisor

Reproduction. A worker launched through an intermediary is reparented to init when the intermediary exits. The run directory's worker record then names a pid the process table no longer holds. local_liveness falls through, and a manifest left at complete is classified complete and then scoring while the worker still runs. A direct worker's children survived too, because the signal reached only a process group the worker did not lead.

Repair. signal_worker gains reach_run. It ends every process the run owns, found two ways: by descent from the recorded supervisor and worker pids, each checked against its recorded start time, and by RECKON_RUN_ID in a process's environment, through a new private /proc scan, _processes_owning_run, with a launch-time floor. A process whose environment cannot be read is not signalled. A process that only holds the worktree as its cwd is listed, never signalled. _signal_process_group gives the reach to every run-ending caller that passes a run directory, so promotion release, the stall watch, review delivery and the rest inherit it. The suite runner and fleet service stops stay single-pid. crew stop records ended_pids, alive_after and held_by. The supervisor's exit record names the pids ended. A run whose recorded pids are gone but whose environment mark lives reads alive.
