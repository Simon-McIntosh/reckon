An endpoint without a handle reports itself

The measured failure this plan records was a coordinator reading handle: null on both derived endpoints of a live capability it had already fetched, and acting anyway — because nothing in the payload reported the gap as actionable. The orientation precedent already announces its own gap (unoriented-plan); an unshippable outcome had no equivalent. This record is the equivalent.

The finding: an endpoint closure that cannot be addressed

build_roadmap now emits a dag finding with code endpoint-without-handle at severity warn for every structural endpoint — a sink with live members beneath it, in the same closure sense the endpoints payload already computes — whose plan carries no graph_handle and is not itself terminal. The message names the plan and counts its closure; the extra.members list names every member the closure would reach. A terminal endpoint plan stays silent, matching how the orientation precedent skips terminal status. The finding is advisory: it is appended to wiring_findings, a diagnostic surface no readiness or execution verdict reads, so it can never shift what runs.
