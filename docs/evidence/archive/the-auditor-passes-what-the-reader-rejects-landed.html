Why this plan was retired without running

Forty minutes after it was opened, and before any node ran, the same validator gap was found already owned by a-review-dies-where-nobody-is-looking section six, in more depth: it carries the missing sprint state island and a duplicated plan scalar that parses last-wins, with four evidence records in this repository already carrying duplicates. A second plan aimed at the same file would have been two implementations of one truth.

The measurement above moved to that section as a comment, where it also narrows the section's own framing. That section had said the two defects the validator misses are both about the authoritative state rather than the prose around it; the table-row case is not about state at all, so the gap is wider than it stated.

The pre-flight rule that should have prevented this exists — search existing titles and summaries before creating a resource. It was skipped. The owning section's heading names the mechanism rather than the symptom, which is the ordinary reason such a search misses, and reading the sprint the finding belonged to would have surfaced it.
