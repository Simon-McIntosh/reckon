§3 — An op collapses a landed section

reckon/_store.py gains collapse_section. It replaces a section's authored prose with the landed card and sets the section's declaration to done in one versioned write, so a reader never sees the card without the declaration or the reverse. The card keeps the original <h2> and its id inside a section-landed header, the shape the structure audit exempts as card chrome. Collapsing a section that already carries a card replaces that card in place from its opening tag to its matching close, so a refresh keeps exactly one card. A landed card is itself a boundary, so collapsing a neighbour cannot consume it. reckon/mcp.py lists the op in _OP_VOCAB.
