A first attempt wrapped each run in srun --partition=all_debug. The head per-file logs survived it (each wrote with truncation, and every copy ran the identical command) but the control log, written with append, interleaved thirty writers into an unreadable record. Both were superseded by the foreground runs above, which execute the step exactly once.
