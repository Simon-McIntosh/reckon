Reported, not repaired — one product defect

reckon/crew/promotion.py::_preserve_cited_gate_log returns None at lines 628–630 when the gate check carries no log_path:

raw = str(gate_check.get("log_path") or "").strip()
if not raw:
    return None

The caller assigns that None over the whole gate check, so a check that supplies a log_digest and no path loses its command, exit status and digest together. Promotion then refuses with missing command, exit_status, log path or digest — while reckon/ledger.py::gate_check_missing_fields accepts log_path or log_digest. The guard contradicts its own refusal text and its own validator, so the behaviour is wrong rather than the assertion. Introduced by bd576e66 (2026-09-22); the red test predates it, added at f05f85b5 (2026-08-26) with the gate-evidence refusal itself.
