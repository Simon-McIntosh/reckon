§4 — The run store carries the backend as a query column

§5 — Work in progress is visible

Commit fe33dbf6 extends reckon/velocity.py with a plan census read from each project's own git history. A plan is opened by the commit that added its file: the earliest commit at which the path exists, counted only when that commit added the file, so a path whose first appearance is a rename has no opening here. Commit 106e4bbb adds session_continuity() to reckon/velocity.py and reports, per lane and promotion day, the share of all dispatches that continued another task's session. A dispatch continues another task's session when its recorded session_id equals that of an earlier-dispatched run whose (project, plan, node) differs. Each lane-and-day cell carries the share beside the same-task, fresh and unmeasured counts; a dispatch with no recorded session_id is unmeasured and is never counted fresh and never counted as a continuation. §4 — A resumed run prices per thread

Commit eaa6adfb changes how reckon/crew/metering.py folds one run's streams. A codex exec resume re-enters the same client thread and its stream restates that thread's cumulative usage rather than reporting only the new work, so a fold that adds the attempts counts each earlier one again. _measure_streams now reads the identity each stream declares (thread.started → thread_id) and keeps only the newest ranked measured attempt per thread, adding threads together. The ranking is stream.jsonl, then resume-N.jsonl in order, then lane-change-N.jsonl. A stream that declares no identity is its own thread, so an unlabelled pair still sums and no attempt is silently dropped. run_streams also gathers lane-change-N.jsonl beside the original and its resumes, deduplicated by path — a lane change is a second thread and is summed, not superseded. The per-attempt delta rule stays in ledger.per_run_budget, extended rather than copied: commit d72ffc3f makes an unmeasured prior attempt leave the run's interval "unknown" — the marker the ledger already uses where a figure cannot be read — instead of subtracting a zero and charging the whole cumulative to the newer attempt. A first attempt, with no predecessor, keeps the zero baseline and its whole cumulative as its own work.

§4 — Quota runway

Commit c45327c8 extends the group pace in reckon/budget.py so each declared budget group carries a runway: the runs remaining before the weekly reset, and the refusal of a wave that would run past it. The figure is the group's remaining seven-day window divided by the mean per-run quota cost over the trailing seven days. Neither input is restated — the remaining window is the group's own seven-day clock, the same one the pace already divides, and the drain deadline comes from reckon/crew/pace.py's drain_deadline; membership comes from budget_group.declared_groups. The judgement extends _group_bar and group_pace rather than adding a second bar, so one entry carries the whole verdict.

Commit 0f135716 corrects how the per-run cost is priced, which is the whole substance of the figure. A run record's own lane_receipt.quota_windows row for the ten-thousand-and-eighty-minute window is the level that window stood at when the run was harvested — a stock, not what the run itself consumed. Dividing the remaining window by that level is a stock over a stock. The per-run cost is instead the flow: the rise in a window's level from its earliest to its latest priced receipt, divided by the intervals that rise spans — n receipts bound n - 1 gaps of spend, because the first receipt is the level the rise starts from, not a run the rise paid for. Dividing by the receipt count would understate the cost by n / (n - 1) — a factor of two on a two-receipt window — and so overstate the runs remaining, the direction that weakens the refusal. The rises and their intervals are summed across the reset windows present in the trailing week. Because a window is keyed by its own reset boundary, a window that reset inside the trailing week contributes its own rise and never its level against the current window's; a receipt from outside the horizon, measuring a window that has already reset, does not enter.

Three properties make the figure honest rather than merely present. It carries the age of both its inputs — the window reading's own age and the mean's observation age — because a figure that cannot be aged cannot be told from a current one. It is unmeasured, never zero, when a window holds fewer than two priced receipts or none that rose: an absence is not a spent week, and the same substitution is refused for a hold and for a reset; the receipt-quantisation caveat rides the figure.
