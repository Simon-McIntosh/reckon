§3 — Coordinator cost per landed node

Commits e2fc9f03 and 280d7fa9 extend reckon/velocity.py with a coordinator_cost section. Each landed node names its coordinator's runtime session, so nodes are grouped by the session that directed them; the section then divides that session's assistant responses, logical input, separately reported cache-read share and output tokens by the nodes it landed in the window. Runs whose node carries no runtime session id enter an explicit unattributed bucket. The transcript accounting is ported from the review's census and the module imports nothing from docs/.
