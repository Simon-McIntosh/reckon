§2 — The home view

An empty hash routes to the home view and the brand mark navigates back to it. The eyebrow reads N of M shown from the visible set, and hiding a project changes the stat band by that project's own count. Rows render only for projects that have plans, in last-edited order. A project whose activity series is empty renders the words no recorded activity and no polyline at all, which is the decision that matters: a flat line reads as broken and is indistinguishable from a genuinely flat series, while the payload distinguishes them and so must the surface.
