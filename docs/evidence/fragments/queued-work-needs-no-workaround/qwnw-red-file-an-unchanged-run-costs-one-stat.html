A poll over a run with no manifest opened that manifest on every poll

Cause, with verdict: the product was wrong. The snapshot reuse key reads the identity of every file a classification reads, and its review-annotation reader (_review_annotation_identities, reckon/crew/recovery_memo.py) then decoded the reviewed run's manifest to find the gate logs it names. The manifest's identity had just been read and it read absent, but the decode was attempted anyway. The decode raised FileNotFoundError, and file_memo.memoized_key stores only what a computation returned, so nothing was remembered and the next poll opened the same missing file again. The identities that read can contribute are only the manifest's own absent entry, which the raise produced anyway, so the reader now returns at the stat: the unchanged poll costs the stat at which failure asks and no open.
