A test file red on the primary branch passes: the cached account age file

What changed. tests/test_cached_account_age.py was red at the base revision in one case, test_a_live_reading_is_untouched_by_the_cache_fallback, which asserts that a live account-surface answer wins over a supplied cache copy. The case injected a transport answering 89.0% utilisation and read 53.0% back — the cached figure — because the dialect's live path never reached the injected answer.

Verdict: the test was wrong. The dialect's account read owns the credential, the transport and the parse: it loads the stored login and refuses before it calls the transport when the store holds no usable login. The case supplied a transport but no login, so the read resolved to unknown for a reason the case never named, and the cache fallback then supplied the figure the assertion read. It silently depended on a login the machine happens to hold outside the repository.
