A refused promotion request settles once its run has landed or gone

What changed. A refused promotion request settles once its run has been promoted, landed or discarded, and the settlement word names which. The landed word is decided by ancestry: whether the delivered head is reachable from the primary branch. The reader asked that question of the promotion request record, which names the project and never a checkout, so the ancestry answer was always unread and every landed run settled as promoted. The settlement now resolves the checkout a project's promoted heads land in and asks ancestry there; a fabricated head still reads as unverified.
