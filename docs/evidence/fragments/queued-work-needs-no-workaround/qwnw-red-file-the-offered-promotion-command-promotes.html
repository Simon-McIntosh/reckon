The offered promotion command promotes the run it names

What was wrong. tests/test_the_offered_promotion_command_promotes.py failed both cases at 35fb9f3ae769. The recovery classifier read a promotable run and offered reckon crew observe --run <id> in both: for a read-only run whose only recorded commit is its dispatch base, and for a run citing a commit of its own. The module's original repair had offered the commitless declaration for the first and the citation list for the second; two later narrowings had withdrawn the offer instead. _promotion_command read "this run changed nothing" from the manifest's changed_paths, so a read-only run that named the report it delivered outside the repository fell out of the commitless branch and was left with nothing to run. And a run with a commit of its own lost its citation list entirely when its manifest recorded no suite arm at the head, because the same composer declined to offer anything rather than offer it under a verdict its evidence supported.

What changed in reckon/crew/recovery_classification.py. The commitless case is now decided by the worktree, which is what promotion itself reads: a worktree still on the run's dispatch base with no changed path inside the repository takes the commitless declaration, and a run whose tree moved past the base keeps no offer rather than one citing the base. The declaration has two readers: the classifier's action, shown to a coordinator, leaves the reason and the outcome as <why the run produced no commit> and <what the run produced> placeholders filled by the caller; an obligation's command is replayed verbatim by the tool surface, which carries no placeholder, so it states the reason the worktree measurement settles (the run changed no repository file; its worktree still sits on its dispatch base) and the outcome the manifest's landing or checkpoint holds. A citation offer states the verdict its evidence supports: passed when the manifest's after-suite arm measured the current head, not-run otherwise, and the citation list is kept in both.
