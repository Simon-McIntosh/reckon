A read-only run promotes on its own commits line, with or without a reason

A review run has no repository work to commit and writes its manifest's commits line as prose, such as none — this node writes a review record outside the repository. Promotion resolved that sentence against the run's repository and refused it as a citation naming no object. A --no-commit reason did not reach the refusal, because the readers that resolved the line answer a scope question rather than the ledger's commit list.

The declaration parser that already decides whether a commitless role's field declares an absence is now asked by _declared_manifest_commits, the single reader every caller resolves a manifest's commits through. A genuine declaration therefore reads as an empty list everywhere; a citation-shaped value is still returned, and still refused by value.
