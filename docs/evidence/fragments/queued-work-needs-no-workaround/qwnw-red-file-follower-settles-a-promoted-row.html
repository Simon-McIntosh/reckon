A delivered promotion settles its row instead of flapping it

At the base revision this file failed in two cases from one cause. The fold recognised a run settled on its ledger row only by the word that row produced, and since 5f81f71e4c ("read a promoted run as delivered until its landing merges") a row whose delivered head no branch carries yet words the run delivered rather than promoted. The settled family — promoted and recorded — therefore did not cover the window a promotion leaves its live pointer in. A pointer still reading its own phase drove the row complete → dispatched → complete on every poll, and the pointer's later disappearance was worded withdrawn against a run whose row records that run's commits.
