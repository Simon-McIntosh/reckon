The admission-pass readiness measurement queues no section declared done

What changed. Nothing in the product. The file tests/test_an_admission_pass_reads_the_roadmap_once.py is the only file this node changes, and its repair is a fixture fix.

The cause, and its verdict: the test was wrong. The fixture declared s1 done and then queued a request for section s1, while reckon/crew/dispatching/preparation.py refuses a dispatch of a section declared done unless it is a measurement run: a done section is the plan saying its work is already on the branch. The product rule is deliberate and is the one the code keeps; the fixture contradicted it. Three failures came from that one contradiction:

  • the pass builds the readiness once — r-s1 was refused, so two of the three requests launched and the assertion ['r-s2', 'r-s3'] == ['r-s1', 'r-s2', 'r-s3'] failed. The refusal recorded for it reads section '\u00a71' of plan 'plan-a' is declared done, so its work is already on the branch; it is dispatchable only as a measurement run.
  • a plan touched between two launches forces a rebuild — the test makes the first launch edit the plan's mtime. That first launch was r-s1, which never ran, so nothing edited the plan and the other two launches died on assert edited.wait(10); the pass launched nothing and built no readiness.
  • the launches read the waits an uncached computation gives — the same r-s1 refusal, with the same two-of-three assertion.

The repair. The done section the waits point at is now a separate upstream, s0, so all three queued sections (s1, s2, s3) are implementable and launch, and the fourth test's waits name plan-a#s0 instead of plan-a#s1. The fixture's docstring states why the upstream is not one of the queued sections. No assertion was deleted or weakened: every count, every launched-id list and every readiness-build count in the file is unchanged, and the gate is still asked for its own section's verdict.

The fourth test still passed at the base revision, which is why the base run reads three failures and not four; the dispatch it makes is faithful and was left alone.
