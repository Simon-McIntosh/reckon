A member registration is a store transaction, and the file says so

What changed. tests/test_member_registration_commits.py was red for one cause, and the cause is the rule the test states, not the product. Eight of the file's ten cases asserted a commit, a committed blob, or a dirty-roster refusal the code no longer performs.

Verdict: test wrong, product correct.
