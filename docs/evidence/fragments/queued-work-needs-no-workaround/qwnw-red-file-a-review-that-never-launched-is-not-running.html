A review that never launched is not running

What changed. recovery_liveness._stranded_launch dates a launch with no attempt clock from the claim its dispatch registered, and failing that from the pointer's own created_at. Commit 57d91db2ce widened that fallback from a cli launch to every launch kind, so that a station launch stopped at claim-published would age and release. That fix also caught the pointer whose liveness belongs to the calling harness: it holds a claim naming no holder, so this host had no process to call gone, and past the 900 s bound it read launch-failed. Releasing a run that cannot be shown to have stopped removes its pointer and its whole run directory, which is the cost tests/test_a_review_that_never_launched_is_not_running.py exists to prevent.

An in-harness pointer is now dated only from a claim that names its holder (holder_pid and holder_host), the process a station launch publishes beside the claim and the one the stranded reading already judges. A cli launch is unchanged, and so is every launch that recorded an attempt clock.

The named case also asserted the sentence a pre-spawn pointer carried before the launcher-claim arm existed (fab923980b, 14 November). That arm answers for every claimed, unstarted pointer, so the case asserts the reading it now carries — the claim — with its classification assertion unchanged and a second one added for the recovery classification.

The two causes, each with its verdict. The product was wrong that an in-harness pointer whose claim names no holder was dated and released: no process existed for this host to find gone, and no plan text asks for such a run to be freed, while the in-harness claim case of the section that introduced the dating names the in-harness pointer as still running. The test was wrong that the row's detail names the harness: the launcher-claim arm answers for that shape and reports the same running classification with the claim it holds. No assertion was deleted or weakened; the detail assertion is re-pinned to the sentence the reading carries and a second classification assertion is added beside it.
