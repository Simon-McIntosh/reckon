The named file ran 1 failed, 3 passed at the base revision. Both arms below are all_debug jobs submitted with SLURM_JOB_ID unset inside the job, on the worktree at the revision each names. The base arm is the negative control; its log sits beside the head arm under the run directory named in the manifest.

Cause 1 — the refusal: test wrong

crew.dispatch no longer raises UnreconciledRuns over an overdue backlog. A session's finished-but-unreconciled runs are duties it owes, not a fence: the dispatch runs and records the overdue runs on the run it writes, in unreconciled_override.waived_runs, and the fence reads only the asking session's pointers, so another session's row is neither counted, copied nor named on that record. The retirement is recorded in the product's own docstrings and asserted by tests/test_a_dispatch_is_not_refused_on_its_backlog.py, tests/test_a_dispatch_classifies_only_its_own_runs.py and tests/test_closure_fence_agreement.py, which pass at the base revision (12 passed). Nothing in the tree raises the refusal any more: the only construction of it left is the uncalled _session_unreconciled_refusal.

The case asserted the retired rule — exit 6, payload["runs"] and payload["peer_runs"], a detail sentence reading 1 unreconciled run(s) and another naming r-peer (session peer-session). It now asserts what the dispatch does instead, from the caller-visible document: exit zero, and exactly this session's overdue run on the record. The case it was written for is kept, namely that only the asking session's row is counted and the peer's is not; the r-peer absence is checked against a control read of the same fixture, since the drain still counts that pointer.

Cause 2 — the stream: test wrong

The case parsed command.output. Under the installed Click (8.4.2) result.output is stdout and stderr interleaved in write order, and a dispatch that reaches the launch writes its load notice on stderr — by design, so that stdout stays the document a caller reads. Once dispatch stopped refusing, the case reached that notice and the document was no longer the first line. The case reads command.stdout, which the product's own comment states as the contract. It also stubs the spawn seam and waives the delivery gate, so it studies the backlog fence rather than starting a worker or stopping at the separate watcher refusal.
