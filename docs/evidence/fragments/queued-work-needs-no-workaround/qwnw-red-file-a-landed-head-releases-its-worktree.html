A landed head releases its worktree

What changed. One cause, one verdict: test wrong. Nothing in reckon/ changed.

The three cases read crew complete --land's outcome with json.loads(result.output) and then asserted report["steps"]["land"]. Since the completion path began answering a direct caller with a bounded receipt, stdout carries only {"ok", "merged", "run_id", "record_path"} and the merge, release and refusal detail lives in the archived record that record_path names. Each case therefore failed with KeyError: 'steps' before reaching any landing assertion. The rule the file now asserts is that crew complete reports through its linked record: a new _full_report(result) helper loads json.loads(result.output)["record_path"], and the three cases read that document.
