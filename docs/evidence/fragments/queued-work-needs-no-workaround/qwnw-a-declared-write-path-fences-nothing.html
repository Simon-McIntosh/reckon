A declared write path is a hint on every surface

What changed. Two surfaces still treated a node's declared write paths as a fence. Promotion refused a run that changed a file beside the one it declared until a coordinator named the companion path with --accept-path, and the write-time manifest audit reported a companion source path as "changed paths outside the write scope", which makes a delivered manifest fail the check its own worker runs itself. Both now defer to one rule. A declaration still says what a run intends, and it is still readable on the request, but only a path whose class a merge cannot reconcile needs a coordinator: a plan document, generated state, a cumulative evidence record, a figure topic directory, a dependency lock or a binary receipt.

The rule has one implementation. reckon/crew/promotion_scope.py asks _shared_write_paths(...).exclusive_pattern(path), the same question a claim and a worker fence already ask, so promotion and the write-time audit refuse one set of paths rather than two spellings of it.
