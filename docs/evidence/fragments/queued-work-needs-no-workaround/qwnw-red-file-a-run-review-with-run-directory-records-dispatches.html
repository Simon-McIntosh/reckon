The rule. A run review delivers its record inside the reviewed run's review-records/ directory, and _review_record_directory_grant in reckon/crew/dispatch_admission.py admits a declared path only when it lands in that run's directory, located through the review module's own shape rule. The fence is the second reader of the same answer: the granted root is the record directory alone, never the project directory — the admission is worthless if the fence grants more than it. A review node whose id names no live run grants nothing, because there is no directory such a record could belong to.

The guard fires. A passing suite does not show a guard fires, so both directions were made to happen. Replacing the grant with nothing turns the admission case red: the reviewed run's own record path is refused as scoped. Both are recorded below with their failing ids.
