What the node changed

  • The time budget is taken from the section's effort hours (2.5 h stores as 150m).
  • The specification level is taken from the section's capability request: tool_autonomy guided maps to guided, autonomous to open, and a section declaring no capability supplies none.
  • The negative control is taken from the section's own declaration by the plan reader that already reads it, so the batch derivation holds no second reader of its own.
  • The derivation runs on both dispatch paths, so a single dispatch that omits the done-when stores the section's.
  • The placeholder rule now judges the text around a bracketed token: one embedded in a path or filename pattern, or naming an HTML element written as test data, is a literal; a token standing alone is refused in a dispatch's done-when, in a code span as in prose.
