Observation, not repaired here

Rebuilding a pointer's node from a stored dict raises a bare TypeError when the stored node lacks a field TaskNode declares without a default, rather than a refusal naming the request. Every pointer the dispatch path writes carries the field, so nothing in production reaches it; the fault only surfaces from a hand-built fixture, as it did here. Fixing it is a product change with its own test and is outside this node's measure.
