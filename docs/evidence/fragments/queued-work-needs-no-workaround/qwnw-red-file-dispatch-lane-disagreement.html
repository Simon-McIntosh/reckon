A dispatch lane-disagreement case registers the member it dispatches to

What changed. One case in tests/test_dispatch_lane_disagreement.py was red on the primary branch, and the failure was in the test rather than the product. The case is about a dispatch that names a backend while the roster member it dispatches to declares no harness: the caller's backend must route. Its helper appended the member to the payload ledger.load returned and wrote it back with ledger.write. That call writes the run aggregate, and the roster it carries is a reader's projection — write ignores it, so the member was never stored.

The dispatch therefore refused at its first gate, before the routing the case measures. Quoting the base run: detail reads "project 'proj' has no crew member 'worker'; register it with `crew member add` before dispatching to it" and the assertion that failed was the exit status, not the lane. A probe over the same helper showed the store answering an empty roster after the write (MEMBERS-AFTER-WRITE []), which is the instrument check that the absence was real rather than an empty read of a populated roster.

The helper now reads the roster's own store with ledger.load_auxiliary and writes it with ledger.write_members, which is the writer paired with that version. It is also the only roster writer that admits a member declaring no harness: ledger.register_member refuses an empty harness, so the state under test cannot be reached through the registration path the other cases use. No assertion was deleted, weakened or reworded — the case's requested_backend, backend and agent.backend expectations are the ones it carried.

Verdict: test wrong, product correct. The product already keeps the rule the case asserts: a member whose harness is empty is not a disagreement, and the caller's named backend stands (requested_backend = requested_backend or member_harness in reckon/crew/dispatch_plan.py), while a declared harness that differs from the requested backend still refuses as D15 — the case beside it proves that refusal fires.
