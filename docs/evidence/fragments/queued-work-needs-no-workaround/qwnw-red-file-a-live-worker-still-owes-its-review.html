A live worker's delivered run still owes its review

What changed. Only the test. tests/test_a_live_worker_still_owes_its_review.py dispatched a run, then committed the run's declared work on the repository's integration branch and cited that commit to crew complete. The citation guard reads reachability against the run's worktree head, never the repository's — a rule the code has kept since the fix that reads a citation's reachability in the run's own worktree, and the test predates it. The fixture therefore failed before the review obligation the test is about was ever reached.
