A dispatch reads no git dates — and the ten-second bound is still not met

What changed. reckon/serve.py gains discovery_without_git_dates(), whose flag is a contextvars.ContextVar rather than a module global, so a suppression one caller entered is invisible to a concurrent reader on another path. Under the scope, discovery answers document stamps from the working tree instead of calling _git_first_committed and _git_last_committed, each of which is bounded at ten seconds, and the answer is cached under its own key so a reader that needs commit times never receives the approximation. Three callers enter the scope: a dispatch preview (reckon/crew/dispatching/fences.py), a batch (reckon/crew/dispatch_batch.py), and now the re-plan a lane change performs (reckon/crew/dispatch_sessions.py). That third path imports plan_dispatch straight from the plan module, so it reached the unwrapped core and skipped the scope entirely — the gap this round closes. reckon/crew/dispatch_batch.py keys its one-derivation cache on the project and derives from the project's registered mount, because queue ordering names the mount while a section's wait check names the checkout's own, so a dispatch from a worktree keyed those readers apart and derived the whole project twice.

Negative control — the test file fails on the base revision. tests/test_a_batch_derives_the_project_once.py now carries two measures: a batch of three entries derives its project once, and a batch makes no git history or last-modified lookup. Both are read through a counter that is proven alive before the zero is believed: the same test runs one discovery outside the scope first and requires that counter to read _git_first_committed and _git_last_committed. What remains, and the next step. The cost that still holds a dispatch near ten seconds is the claim sweep over the crew home's live pointers — 66,546 lstat calls and 16,433 stat calls in one preview at load 47 — and it is read at least twice on the preview path, once for the picker inputs and again for the live-conflict check.
