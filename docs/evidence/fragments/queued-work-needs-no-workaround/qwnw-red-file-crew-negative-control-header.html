The rule it now asserts. Admission reads two records and either one suffices

  • a log that states the run failed somewhere — a non-zero terminal EXIT=<n>, or the runner's own FAILED ids beside its summary — is admitted when it names a failing test id the head arm does not fail;
  • a log that states no failure in either record is refused, and the refusal names that fact: reports no failure.

No assertion was deleted or weakened. The refusal case keeps its three assertions — the declaration, the log path, and the fact the refusal read and found absent — over a fixture whose fact really is absent (a 1 passed log with no capture line), and two more pin the wording admission no longer compares (first line, verbatim).
