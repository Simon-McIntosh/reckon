A queued request waits only over a path a merge cannot reconcile

The admission pre-check compared two queued requests' declared write paths by containment alone, whatever class those paths were, so a request declaring a repository-wide directory such as reckon parked every request queued behind it. The pre-check now reads the sharing rule the live-claim check, the fence and the write-time audit already use (runs._claim_paths_share), so only the class git cannot reconcile holds one request behind another: a plan document, generated state, a cumulative evidence record, a figure topic directory, a dependency lock or a binary receipt. The pass's exclusive-path policy is resolved once per request and handed to every comparison, so the pass keeps its one resolution per request.
