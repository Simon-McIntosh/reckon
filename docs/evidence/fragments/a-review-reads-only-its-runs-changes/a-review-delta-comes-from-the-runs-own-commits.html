A review's delta is the run's own commits, taken against the remote-tracking integration ref

What changed. A run's changes are now read by one helper, reckon/clones.py::own_changed_paths(tree, older, tip, *, integration_ref=...), which returns the paths of commits reachable from tip but from neither the run's base nor the integration branch. Its first pass walks rev-list --no-merges and diffs each commit; a second rev-list --merges pass adds the combined diff of the run's own merge commits, so a conflict resolution the run wrote survives a range that drops merges. The helper returns None when the history cannot be compared — no remote, or a ref git cannot resolve — and every caller reads None as an unshown delta rather than an empty one.

The integration ref is resolved by recovery_review_dispatch._integration_ref: the symbolic refs/remotes/origin/HEAD when the clone carries one, otherwise origin/main, otherwise origin/master, otherwise the empty string. A local branch is never the selector: it can lag the remote, so a range taken against it readmits commits the integration branch already has.

The two callers. review_head_move measures the delta between a stored review's head and the head the run now carries, and returns {} when the delta cannot be shown, so no review is carried forward on an unmeasured move. _changed_figure_paths keeps its failure-as-no-figure reading. _review_delivered_paths and changed_paths are untouched.

Measured

The node test drives three real histories. A run that merges main mid-flight reads only its own paths and stays classified as a non-runtime move, while the lagging local branch is shown admitting an integration path. A run that resolves a conflict in its own merge keeps that resolution, which the no-merges pass alone cannot see. A repository with no remote reads the move as uncomparable.

The fixtures. Three existing review fixtures built repositories with no remote at all, so their delta was uncomparable and their tests asserted the empty reading. Each now records refs/remotes/origin/main at its seed commit — the state a dispatched run sees after its clone's fetch. One fixture also wrote the same figure with the same message as the commit its test reviews, so a commit made in the same second produced the same object as the fixture's own: the reviewed head was already carried by the integration ref and the figure review was never composed. The reviewed commit now carries its own message, so the two cannot collapse onto one sha.
