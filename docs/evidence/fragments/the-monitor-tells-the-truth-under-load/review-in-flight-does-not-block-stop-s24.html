The stop hook blocks only on work a coordinator can shorten

What changed. A run whose head a review is reading carries a review-in-flight duty. The row's own text says to read the run with crew observe, and the reflex that dispatched the review re-fires when it ends, so nothing the session runs moves the wait — yet the stop path classified the kind as actionable and refused the turn. A coordinator was held in a ten-minute foreground wait by a row telling it to look at work already moving, instead of ending its turn with a watch armed.

The kind is now declared among the duties no action shortens, in both places the vocabulary is stated: reckon.crew.obligations gained a named REVIEW_IN_FLIGHT_DUTY_KIND, used by the review duty's own builder and added to NON_BLOCKING_DUTY_KINDS, and reckon.hooks.coordinator_obligations added the string to _NON_BLOCKING_KINDS, the set its stop path reads on a fresh snapshot. A review in flight is therefore counted in the checklist's [N waiting, no action shortens them] line and does not hold a stop open. The two sets are separate statements of one rule — the hook cannot import the derivation on the paths that read a fresh snapshot — so the test drives the derivation's builder into the hook's predicate rather than assuming they agree.
