Three dry-run gaps, each reproduced at the base revision before it was repaired, and each held by a test that fails against the code it replaces. crew complete --dry-run reported would_promote: true for a run whose armed suite pair the landing refuses: both arms ran a command other than the one the run was armed with, the run declared no command of its own, and the landing refuses on those fields without measuring anything, because there is nothing it could measure over a question the run has already answered differently. The dry run carried no refusals and named no measurement it had not taken, so a coordinator planned around a promotion the --land refused.

The suite evaluation the promotion already runs now reaches the report — the delta itself, would_measure, and the arm fields the pair is missing — and the refusal is reported exactly when the landing refuses without measuring, spoken with the landing's own predicates so the two cannot drift. The other population is reported as what it is: a pair the landing takes itself by running the armed command over the base and head trees is not a refusal, because a merge reads would_promote before it moves anything and a run the landing would promote must not read as refused. That case carries the fields a failing measurement refuses on in the delta, names the measurement as the landing's, and notes that this call measured nothing.

The review gate's own predicate is extracted and read by a helper that states the review owed as a fact: the run, the tier that decided it is owed and the head it must read.
