The hook's figures count the obligations it lists

What changed. format_checklist in reckon/hooks/coordinator_obligations.py took its header count from the payload's summary.count and its closing figure from summary.unreconciled_runs, and printed the instruction to work the list unconditionally. Both figures now come from the rows the render prints: the header counts the obligations it lists, and the trailer appears only when the list holds a row a coordinator can act on, counting those obligations rather than the closure's run figure.

The reproduction, at the base revision. Two workers recorded in phase working and one request awaiting upstream, on a fixture repository and a synthesised configuration home:

summary: {'count': 0, 'oldest_age_seconds': 0, 'unreconciled_runs': 2}
items: []
--- rendered
reckon obligations for session probe-session (project probe-derive): 0 outstanding
unreconciled runs: 2; work the list to empty before ending the turn.

summary: {'count': 1, 'oldest_age_seconds': 0, 'unreconciled_runs': 3}
items: [('run-queued', 'run-upstream-request')]
reckon obligations for session probe-session (project probe-derive): 1 outstanding, oldest 0s
- [1 waiting, no action shortens them] run-queued 1 (oldest 0s)
unreconciled runs: 3; work the list to empty before ending the turn.

That is the reported reading word for word: a count of three runs beside a list holding none, and the same count beside a list holding one wait. The three are runs the closure calls unreconciled, and none is a duty — a worker in flight is work already moving, and a request awaiting upstream starts by itself when its last ref lands.

The second reading. A registered session with no live pointer and no producer was answered at every prompt with are not current: no producer; run `reckon crew watch --ensure …. The prompt path now reads the session's own live pointers before warning: session_holds_live_work walks the pointer directory, and an unreadable pointer counts as work so the silence is only ever taken on evidence. The same fixture with one live run still names the remedy, which is what shows the silence is the fleet's answer rather than a hook that stopped speaking. The no-follower reading is untouched: it is asserted by tests/test_a_missing_snapshot_names_a_live_seat.py for a session holding no pointer, and that reading still speaks.

What the figures mean now. The header counts rows; the trailer counts the same rows, and only prints when at least one of them is actionable.
