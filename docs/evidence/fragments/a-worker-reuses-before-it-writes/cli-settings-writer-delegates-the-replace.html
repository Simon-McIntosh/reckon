§3 — the harness-settings writer reuses the shared atomic JSON writer

reckon/cli.py:_write_json_atomically keeps its unchanged-bytes early return and both concurrent-edit refusals, then hands the temporary write and rename to reckon/_store.py:write_json_atomically with fsync=False, indent=2, sort_keys=False, ensure_ascii=False and the revision's own mode, so the bytes, the mode and the refusals are unchanged. tests/test_cli_settings_writer_reuses_the_store.py asserts the written bytes, both modes, both refusals and the absence of a leftover temporary against a replica of the pre-migration writer.
