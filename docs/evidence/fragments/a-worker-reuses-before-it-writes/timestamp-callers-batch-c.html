timestamp-callers-batch-c — the last eight readers join the shared parser

Eight readers across five modules still carried their own ISO-8601 handling — a datetime.fromisoformat call and, next to it, the tolerance each author had added by hand. They now read through reckon._timestamps.parse_utc: _parse_cached_fetch_stamp and _event_timestamp in reckon/_backends.py, _parse_stamp in reckon/budget.py, _observed_moment in reckon/crew/budget_group.py, _event_timestamp and _stamped_elapsed in reckon/crew/metering.py, and row_moment and local_clock in reckon/crew/ticker.py. No fromisoformat call remains in any of the five modules.

The bar was not a shared parser but a shared parser that changed nothing observable. The eight callers did not agree with parse_utc on four points, and each disagreement was kept rather than unified: the readers refuse a stamp whose text is not strictly spelled (surrounding space, a lowercase zone designator) where parse_utc tolerates both; metering._event_timestamp keeps raising TypeError on a non-string where parse_utc returns None; ticker.row_moment reads a stamp naming no zone as the replaying machine's local wall clock where parse_utc reads UTC. A guard sits above the call in each case, and the local-zone branch reproduces the recorded epoch exactly.

Preservation. The eight callers were driven over one shared sixteen-input list at the base revision and again at the new head, through the door each caller already exposed: a zoned ISO string, a Z-suffixed one, a lowercase z, a space-separated zoned stamp, a space-separated naive one, an offset carrying seconds, a near-midnight offset, a naive stamp, a date-only stamp, a valid date with trailing text, surrounding whitespace, an epoch number, an empty string, None, a non-string object and garbage text. A raised exception is recorded as its type. The comparison is canonical: each datetime is recorded as the instant it names and whether it is zone-aware, so a caller cannot pass by re-parsing to recover the offset the shared parser discarded. Base and head agree on all 144 cells — nine rows (the eight callers plus parse_utc itself, run as the reference) by sixteen inputs — with zero differing cells. Timezone- sensitive cells are made deterministic by pinning the local zone to Europe/Paris inside the test.

Negative control. Making metering._event_timestamp drop the zone from a zoned input reddens the space-separated zoned case, tests/test_timestamp_callers_batch_c.py::test_migrated_caller_keeps_its_recorded_output[metering._event_timestamp-space_zoned] — the recorded instant is aware and the mutated caller returns a naive one. The red log is negative_control.log under the run directory, whose first line repeats the declared mutation verbatim.
