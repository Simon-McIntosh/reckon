The velocity view reports the interface level and its weekly change

The velocity view measured what the fleet delivered but not the interface that delivery grows. A new git-only counter ports the review census's own counting rules and velocity.report now carries an interfaces block: for each ISO week in the window: the revision at the week's end, the four counts at that revision, and the change from the previous week.

What changed

  • reckon/interface_counts.py is new. It parses one revision's reckon/ tree read straight out of git — the module list from ls-tree, the bytes from one cat-file --batch pass, no checkout and no import — and ports the census's interfaces() rules and its public-definition count. The four counted families are public definitions (non-underscore module-level functions/classes plus public methods; nested functions excluded), CLI options (option decorators on command/group callbacks, aliases together, version_option included), MCP views (read-plan VIEW_NAMES, audit-reachable names, literal view annotations, crew view comparisons, as distinct tool/name pairs) and coded refusal families (distinct literal codes passed to format_refusal). Nothing under reckon/ imports from docs/; the census is imported only by the test, for parity.
  • Counts are cached by resolved sha under the velocity cache root, so a warm read of a revision already counted recomputes nothing; a corrupt or version-mismatched entry is rebuilt rather than trusted.
  • reckon/velocity.py gains _interface_week_rows and a report interfaces block. Each row names the ISO week, its start and end, the first-parent revision bounded by the week's end, the four counts at that revision, and their delta against the revision at the week's start (so the first in-window week carries a real change against the week before it). The block is emitted for the project named reckon; interfaces is also accepted as a view field.

  • Head (4544e7ea2, worktree): 232 passed, EXIT=0 — adds no failing test id.
  • Base (4e05e287a, git archive scratch): 1 failed, 227 passed, EXIT=1.
