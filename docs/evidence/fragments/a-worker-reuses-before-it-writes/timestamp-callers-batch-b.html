Batch B — five top-level readers on one parser, one retained exception

Five timestamp readers outside reckon/crew/ no longer parse timestamps themselves: each now calls reckon._timestamps.parse_utc and keeps only the policy around the call that its own callers depend on. Re-parsing locally would have been the smaller edit and is the defect this migration exists to remove, so a reader whose policy differs holds that policy in a line or two rather than reaching for a parser of its own.

One reader does not migrate. doccheck.modified_age_days reports whole calendar days between a plan's modification stamp and today, reading the date the value states in its first ten characters. That is a stated date, not an instant: a zone on the value must not move the day it reports, and a stated date followed by trailing text is still a stated date. Resolving the value through the shared parser would shift 2024-03-05T00:30:00+02:00 to 2024-03-04 and would return None for 2024-03-05bogus, which silently switches derived_plan_age to its filesystem fallback. It keeps its own reading and is recorded as a retained exception rather than a migration.

The base outputs were recorded before any edit, at 142cdf05, by exercising each reader through the door it already exposed over one shared thirteen-input list — aware ISO, Z-suffixed, naive, date-only, an aware stamp whose wall clock sits at midnight, a date prefix followed by non-date text, a Z-suffixed stamp with surrounding spaces, a lowercase-z stamp, epoch number, empty string, None, a non-string object, and garbage text. Those readings are the expectations of tests/test_timestamp_callers_batch_b.py, which asserts every reader still produces the output it had; a raised exception is recorded by its type and message. The five modules this node touched are byte-identical between 142cdf05 and the worktree base a15e11cb, the parent of the migration commit, so the two base revisions give the same readings.

Five of the six readers preserve every recorded cell. sprint_liveness._observed_seconds read a naive string as local time through .timestamp(), so its reading depended on the host timezone the node ran under; parse_utc reads a naive value as UTC. Four cells move — the naive and date-only strings, an epoch number the C parser rejected with TypeError, and a non-string object — and each is named in the test beside its base reading and the reason the unified rule replaces it. In production the value is always Z-suffixed, written by the runs and fleet-supervisor producers, so the change is invisible to every live caller; the difference is the timezone-independence the migration buys.

A shared parser is deliberately lenient where the callers it replaces were strict: it strips surrounding whitespace and accepts a lowercase z zone designator, and it returns None for a value of an unsupported type rather than raising. Reaching for it must therefore not widen a reader whose own contract is narrower. Three call sites carry a guard for that: project_state._validate_review validates a resolution stamp and so refuses the two non-canonical spellings before calling the parser, which keeps the base acceptance set rather than accepting a spelling it would reject downstream; schedule._stamp_millis and sprint_liveness._observed_seconds take the same guard so each reproduces its base output on the padded and lowercase-z inputs. The recorded table carries those inputs for all six readers.

The hook that runs outside the package is among the five. reckon/hooks/worker_stop.py is registered as its own file path and launched by its shebang, so its process carries no sys.path entry for the checkout. A module-scope import of the shared parser broke that launch with ModuleNotFoundError, which surfaced as the hook writing empty stdout and its own test failing to parse it. The import now sits inside the one function that needs it, with a sys.path bootstrap from the file's own location that runs only when the module is not imported as a package, so an ordinary import is untouched and the bare-script launch still resolves the shared parser.
