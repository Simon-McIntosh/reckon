A promoted code review is stored

Promotion recognises a review-code-<key> promoting run, resolves its neighbourhood key with code_review_identity, finds the delivery through its code-review.json sidecar, and stores it in the staging store through the refusal-recording loop the plan-review path uses. Nothing is committed: a code review names neither a plan nor a reviewed run, so a committed payload would roll the landing back.
