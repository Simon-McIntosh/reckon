A stored finding is readable by the repository path it names

reckon/crew/findings.py walks a project's committed run-review and plan-review records, pulls every finding whole — blocking and follow-on alike — and groups the rows by the repository path each names with a recurrence count of the distinct reviews naming it; a path outside the checkout is kept as scope: artefact and adds no recurrence. It is served as the crew MCP view crew(project, view="findings", path=<prefix>) and as reckon crew ledger --view findings [--path <prefix>]. The gate tests/test_findings_read_by_path.py builds three committed run-review records — two naming reckon/a.py and one naming an absolute report path — and reads recurrence 2 for reckon/a.py with both rows open, the report row scope artefact with no recurrence, and the CLI printing the same rows; the declared negative control, the reader filtered through repair.blocking_findings, drops the follow-on row and fails three tests at EXIT=1. tests/test_ledger.py holds the MCP surface at five tools.
