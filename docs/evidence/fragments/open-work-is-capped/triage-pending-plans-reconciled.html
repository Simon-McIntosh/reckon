Method and the reproducible denominator

A plan's denominator is its declared sections that carry a deliverable: every section declared implementable or done, except §1, which counts only when declared implementable. A section is present only where its implementing file and symbol are found at head; a test file alone is never the citation for a product deliverable. The denominator is read from the plan's own plan-section-declarations meta, falling back to the authored <h2 id> ids minus s1 where a plan declares none.
