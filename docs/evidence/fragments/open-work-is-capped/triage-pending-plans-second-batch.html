Method and the reproducible denominator

The denominator is the plan's declared sections that carry a deliverable: every section declared implementable or done, except §1, which counts only when declared implementable. Where a plan carries no plan-section-declarations, the denominator is its authored h2 count less §1. The declaration is read from reckon's own reader, reckon.mcp._read_plan(project, slug, view='raw')['data']['section_declarations'] — the detail view carries no declaration map — not from a hand filter and not from the plan's stored impl. The command below prints every plan's denominator and the exact sections counted; run it from the worktree root.

PYTHONPATH=. .venv/bin/python - <<'PY'
from reckon.mcp import _read_plan
SLUGS = ["a-review-is-sized-to-its-risk","a-small-change-is-a-small-node",
"a-sprint-closes-on-completable-work","a-sprint-is-live-while-a-crew-works-it",
"a-stalled-row-says-whether-the-worker-lives","a-window-paces-the-lane",
"a-worker-can-take-a-brief","a-worker-cannot-write-your-home","a-worker-is-charged-to-a-job",
"a-worker-knows-it-is-on-compute","a-worker-owns-its-own-record","a-worker-reuses-before-it-writes",
"advise-the-lane-never-force-it","an-orchestrator-can-discharge-a-refusal",
"an-orchestrator-cannot-forget-its-obligations","an-orchestrator-is-bound-by-its-inbox",
"background-agent-fitness-and-dispatch-scope"]
for slug in SLUGS:
    d = _read_plan("reckon", slug, view="raw")["data"]
    decl = d.get("section_declarations")
    if isinstance(decl, dict) and decl:
        counted = sorted(s for s, c in decl.items()
                         if c in ("implementable", "done") and not (s == "s1" and c != "implementable"))
        src = "declarations"
    else:
        from bs4 import BeautifulSoup
        soup = BeautifulSoup(open(f"docs/plans/{slug}.html").read(), "html.parser")
        counted = [h.get("id") for h in soup.find_all("h2") if h.get("id") and h.get("id") != "s1"]
        src = "authored h2 minus s1"
    print(f"{slug:58} {len(counted):2}  {src:20} {','.join(counted)}")
PY
