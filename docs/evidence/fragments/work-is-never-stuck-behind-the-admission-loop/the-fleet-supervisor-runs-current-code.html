The fleet supervisor reloads itself when its checkout moves

What changed. The supervisor's request loop in reckon/crew/fleet_supervisor.py compares the cheap code stamp it recorded when it started with the checkout's on every pass. Only when that stamp has moved does it ask reckon.served_code.moved_checkout() — the moved-and-trusted decision the served code path already makes — and it replaces its own image through _reexec, the same path a manual reload request takes, only on a verdict that the checkout moved and may load. The declared services it adopted keep running and a later reader sees one supervisor. A tree with a tracked file modified against HEAD is not trusted, so the supervisor keeps the image it has rather than running code a half-finished edit produced. The trust test behind that verdict loads every module of the package, so it is paid for at most once per MOVE_CHECK_INTERVAL_SECONDS (60 s): a checkout left dirty costs one check per interval rather than one per pass. The same stamp is asked about again after the interval, because a refusal describes the tree at the moment it was taken and the tree can become loadable without its identity moving — dirt discarded, or an import probe that timed out — so a stamp refused once is never held for ever. An identity read that did not answer is never treated as a moved stamp — the loop adopts the first readable stamp rather than testing on every tick, which would loop while the read keeps failing. No request verb and no CLI option is added, and the manual reload request stays for an operator. serve() takes code_stamp, moved_checkout and clock by argument, defaulting to the cheap identity, the served-code decision and the monotonic clock, so a test can drive them against a temporary checkout.

Why it was needed. The station was down for 73 minutes on 28 October while the supervisor ran eight days on code that predates its station request. It answered unknown request: station until an operator sent reload by hand. Every fix to how it keeps services now reaches the node without a request.
