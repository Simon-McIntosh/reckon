Named admission and persisted queue positions

crew admit --run <id> decides one queued request under the existing admit lock. It reuses the lane, claim, review and launch checks, skips queue-wide release and recovery, and starts no landing worker. Full passes store queue_position, rank_key and last_admission on requests that remain queued.

The rank key binds the computed fair-share position to arrival time and run identity. An unchanged verdict and position retain their receipt time, so repeated holds stay byte-identical. Metadata writes reuse the existing promotion guard while holding the pointer lock.
