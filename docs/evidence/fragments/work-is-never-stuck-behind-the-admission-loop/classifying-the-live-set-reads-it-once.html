Classifying the live set reads it once

The live-run partition now hands its pointer snapshot through the classifier to review-subject resolution, filtered to the requested project. A caller classifying one record without a snapshot retains its own live-set read, and one-argument classifier substitutes still work.

The new check classifies 50 synthetic pointers, including 10 review runs, against categories captured from the base revision: 40 scoring and 10 running, committed as individual expected values. The partition's counted live-set reads are at most one. A second check confirms that a foreign project's pointer never enters the review lookup. Restoring the per-pointer review lookup makes the counted read total 710 and fails the first check. The head gate passed (2 tests), and 87 importer test files added no failures against the base revision: the same three failures and five setup errors occurred on both revisions. Ruff reported three existing findings on both revisions and none added by the change.
