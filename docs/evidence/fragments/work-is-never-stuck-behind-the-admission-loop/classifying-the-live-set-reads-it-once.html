Classifying the live set reads it once

The live-run partition now hands its pointer snapshot through the classifier to review-subject resolution. A caller classifying one record without a snapshot retains its own live-set read, and one-argument classifier substitutes still work.

The new check classifies 50 synthetic pointers, including 10 review runs. Every classification matches the independent reading; the partition's counted live-set reads are at most one. Restoring the per-pointer review lookup makes that same count 710 and fails the check. The head gate passed (1 test), and 87 importer test files added no failures against the base revision: the same three failures and five setup errors occurred on both revisions. Ruff reported three existing findings on both revisions and none added by the change.
