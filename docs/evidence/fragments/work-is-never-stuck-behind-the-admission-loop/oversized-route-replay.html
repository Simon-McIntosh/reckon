What would have to change for the node to reach codex. The waiver (snapshot.py:1896–1899): judge the unreserved population as the lanes that could serve the node at all — an in-harness backend cannot be launched by a dispatch, so it is not evidence that some ordinary lane could run the work — and read a competence refusal for the same window shortfall as a context exclusion, since the scan reports one shortfall as two codes depending on which verdict measured it. The candidate scan: nothing here needs to widen. _reserved_lane_exclusion withholds a reserved lane on a rule, not on a measurement, and that rule is the lead's; the waiver is the one place that is allowed to override its tier and attempts terms, and it applies its own context fit to any lane it admits. The reroute (snapshot.py:612, dispatch.py:633): if the reroute is to move an oversized request onto a reserved lane, it has to run the same waiver before filtering, because it excludes every candidate that carries a reason and a released reserved lane still carries the policy's reason.
