A state write commits a set of paths in one commit

What changed

reckon/ledger.py: _commit_state_write now accepts a single Path or an iterable of paths. Every path resolves through _state_checkout before any staging, so a set spanning two checkouts is refused with nothing staged; the paths are then staged and committed together with one git commit --only. A single-path call stages and commits exactly one path, as before. Callers are unchanged.

Gate: tests/test_state_write_commits_a_set_of_paths.py and tests/test_ledger.py — 3 new cases pass and the ledger suite is green.
