The review store keeps no unreachable refusal

resolve_record_times no longer raises for a review run whose own record exists yet carries no dispatch stamp. Its sources are tried in order and a record whose times resolve from no source is committed with both stamps empty and times_source "unknown", whatever other records exist for its review run. The removed branch answered nothing for a standard run id, because every minted id encodes a dispatch instant and the run-id source is consulted after the record's own stamps — so the refusal was unreachable and its two docstrings were false. Both docstrings now state the rule alone.

The new case holds a review run whose own run record exists with no dispatch stamp, under an id that encodes no instant, committed with times_source "unknown" and empty dispatched_at/completed_at, with the store clock in neither stamp.

The companion case test_a_committed_record_carries_the_run_records_times, which had asserted the removed refusal, now asserts the unknown commit and its module docstring marks the absence rather than a refused write.
