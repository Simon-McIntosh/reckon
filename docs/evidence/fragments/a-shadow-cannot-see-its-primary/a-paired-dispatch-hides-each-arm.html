What landed

reckon crew dispatch gains --pair-backend <backend>. One call resolves two arms at one base revision: a primary arm routed as any dispatch is, and a shadow arm on the named backend configured from the primary arm's own planning resolution through _shadow_dispatch_config. Both run ids, both run directories and both worktree paths are fixed before either arm launches (dispatch_pair in reckon/crew/dispatch.py), so each arm's fence is composed from its partner's allocation rather than from a live pointer or a ledger row the partner does not have yet. The primary arm records paired_shadow_run_id; the shadow arm names its primary through the existing shadow lineage.

promotion_scope._allocated_read_surfaces resolves an allocated arm's readable surfaces through _primary_read_surfaces, the same function the contamination scan reads, so the launch fence and the scan cannot disagree. dispatch threads the partner surfaces to launch_plan in place of the committed-row lookup a standalone shadow performs, and skips that lookup only when the allocation supplies them.

Each arm supplies its dispatch keywords through one source, the per-arm mapping that strips what that arm fixes before it re-adds them, so no key can arrive twice however the caller's keyword surface grows. The identity arguments stay explicit because the two arms deliberately differ in config. That the pair can launch at all is itself asserted: the gate drives the launch path with a stub in place of the harness and requires both arms to launch under their own allocated run directories, because a dry run never reaches the arm dispatch calls and so cannot see a keyword collision at them.

Measure

The gate executes the composed argument vector under a real bubblewrap fence, never inspecting its shape: each arm lists its partner's run directory as empty (partner-run-dir []) and can still write its own run directory and worktree. With the primary arm's masks dropped the same listing is non-empty (partner-run-dir [stream.jsonl,]), which is the declared negative control and is what makes the empty listing mean anything.
