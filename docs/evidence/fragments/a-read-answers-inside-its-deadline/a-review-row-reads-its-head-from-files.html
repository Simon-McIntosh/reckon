A review row reads its run's head from git's files

_reviewed_run_head in reckon/crew/recovery_review_subject.py now reads the run worktree's head from git's files through a new _worktree_head_revision in reckon/crew/recovery_memo.py, instead of spawning git rev-parse HEAD once per review row. A detached worktree's HEAD file holds the revision itself; an attached checkout names a ref whose loose file holds it. A ref kept solely in packed-refs, an unreadable git directory, or anything else unresolved returns empty and the caller asks git as before, so no answer changes. The git-directory and ref resolution is factored into _named_ref and _ref_roots, which _worktree_head_identity also uses, keeping its answers unchanged.
