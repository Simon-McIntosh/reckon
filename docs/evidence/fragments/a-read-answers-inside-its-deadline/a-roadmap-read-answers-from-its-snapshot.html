A roadmap read answers from a snapshot keyed on the project's write generation

A warm reckon.mcp._roadmap call is answered from a snapshot of the composed result, keyed on the few facts that result is a function of. Each mounted project contributes three: the modification time of its .git/index, the commit HEAD resolves to, and the store's plan-write counter, advanced by reckon/_store.py's write_plan — the one place every plan-state writer in every process reaches — and persisted one file per project under the shared crew home so a write in one process is seen by readers in all of them. The process's held code stamp joins the key, and a read never re-takes it. A live run's classification is a function of files the crew owns and of the clock, so the key carries, per live run of this project only, the crew watcher's own per-run reduction (_watch_snapshot), so a clock advance or a classification change moves the key exactly as it moves the watch, and a peer project's run cannot invalidate this project's snapshot. The key is read with stat and open only: no git subprocess, no walk, and no file in the docs tree.

A matching key and a stored snapshot inside the revalidation window return the stored composition. Anything else recomposes through build_roadmap's existing path and stores what it composed, under the key the project is in after the read, so a write that landed while the read ran is never answered from the composition made before it. The snapshot is persisted node-locally through reckon.crew.review_records.node_local_cache_dir(project), so a fresh process, another session's server and the current-code child answer their first call from a snapshot one of them computed. A write that neither reckon nor git made moves none of the three facts, so a full revalidation is forced at most once per window, 120 s by default. The mounts resolution the key reads is held until the mounts file itself moves, because establishing that a docs tree exists is a stat inside the covered tree — the one place the key would otherwise touch it to learn nothing.
