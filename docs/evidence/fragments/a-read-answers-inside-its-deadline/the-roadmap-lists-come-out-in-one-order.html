The roadmap's lists come out in one order

_scope_slugs returned a set, so the order in which the roadmap report visited plans — and appended decision_blockers and wiring_findings — depended on the process hash seed. It now returns the slugs sorted by plan identity, so two reads of an unchanged project emit the same rows in the same order. tests/test_the_roadmap_lists_come_out_in_one_order.py renders one fixed docs tree in two subprocesses under seeds 1 and 104729 and requires the JSON byte-identical: 1 passed, EXIT=0, and 411 tests across the 40 roadmap-importing files passed at head as at base (EXIT=0 each). Negative control — the order key removed (_scope_slugs back to a set) — gave 1 failed, EXIT=1.
