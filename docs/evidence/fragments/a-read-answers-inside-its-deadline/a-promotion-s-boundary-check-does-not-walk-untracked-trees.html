A boundary check reads only the roots a run can be charged for

What changed. A promotion's repository-boundary check took its status read with --untracked-files=all over every dispatch-visible tree, so a shared checkout's untracked worktree, cache and tool trees cost one directory walk per file on the filesystem for paths the check could never charge: it refuses a changed path only when the run's own declaration covers it. git status is now read with the declared roots named as literal pathspecs (reckon/crew/routing.py, _tree_state and _repository_tree_snapshot), so an untracked directory outside every declared root is never opened, while a declared path inside one is still reported. A run that declares no write path reads no untracked entry at all, because nothing can be charged to it. Every selected tree is still read exactly once, so the number of status calls a fenced or unfenced run makes is unchanged.

The bound is drawn from the run's declaration in _repository_tree_boundary_violations (reckon/crew/promotion_scope.py), the same root set that check already uses to decide whether a changed path is chargeable, so the read and the charge cannot disagree about which roots matter.

Measured

Both arms of the timing comparison run against one checkout, one recorded baseline and one run record; only the contents of the untracked directory change between them, so the two figures differ for no reason but the one under test. The baseline is recorded while that directory is empty, which is the case the check must not pay for: the tree grows between the dispatch that recorded the baseline and the promotion that re-reads it.

Every arm is a log whose first line names its revision, tree and command and whose last line reads EXIT=<code>.

Why the negative control is the ratio. The test asserts that the 20,000-file check costs no more than twice the empty one. At the base revision the untracked read walks all 20,000 files, so the same assertion fails there while the head measure holds, which is what separates the bound from a check that had merely stopped looking.
