A live coordinator resume stands in for the repair it is answering

A run whose review raised a blocking finding read as repair-owed while the coordinator's own crew resume was answering that finding. The reflex cannot dispatch a second repair for a run with a live worker — it is refused for exactly that reason — so the row named a duty nobody could act on, and the stop hook held every turn end on the refusal the reflex had already recorded.

Change. reckon/crew/obligations.py gains _coordinator_resume_in_flight, consulted in the repair branch of _review_duty_item before a row is built. It answers true when the run has an attempt whose own receipt shows its worker alive and whose kind is resume, and the round's recorded dispatch is not one of REPAIR_ROUND_OPENING_STATUSES — so the reflex's own running resume keeps the in-flight reading it already had, and only a resume that no repair record opened stands in for the duty. A recorded round naming a different head than the review's is not this round, so the duty is left standing. The suppression is scoped to the live attempt: once it ends, the duty is read again from what the run delivered, and a repair that landed a new head leaves the run owing its review rather than a repair of the old one.

While that attempt is live the obligations view reports no repair-owed row; once the attempt ends and the repair has landed a new head, it reports none either.
