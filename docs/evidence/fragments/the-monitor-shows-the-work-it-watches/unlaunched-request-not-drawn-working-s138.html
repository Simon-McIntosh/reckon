A request with no worker is drawn in its own phase, never as working

On 14 November five nova requests whose pointers read held or awaiting-upstream — no pid, no worktree, no launched_at — were drawn new → working and counted in the reported fleet count, aged 26–27 minutes at 15:12:34Z, and at 18:02Z sixteen batch requests, thirteen of them already dropped and archived, drew the same transition in one second. Two independent defects produced it. classify_pointer decided a parked phase only while its own branch matched and then fell through to the liveness arms below, which read the absence of a process, a stream and a manifest as a run that had started; the guard that spares an unlaunched pointer named the queued and held phases but not awaiting-upstream, so a parked request was read running. And the follower's arrival branch in fleet_transitions stamped every new run new → dispatched whatever its pointer said, which is why thirteen discarded requests opened as work in the same second.

A parked phase now holds only while the pointer records no worker: a pid or a launched_at means the request has launched, and its liveness rather than its old label decides its reading, so a phase label can be left behind. An unlaunched pointer skips the liveness arms and keeps its phase reading — the stuck verdict still speaks, because it is about the wait rather than about a worker — and the arrival word is taken from the state the snapshot itself supports, so a launched run still opens as a dispatch and a request that has not launched opens in its own phase. reckon/crew/ticker.py needed no change: its letter table already rendered queued, held and awaiting-upstream outside the working column, and it was receiving dispatched into it.

Gate. tests/test_a_request_that_has_not_launched_is_not_drawn_working.py holds one follower fixture over three unlaunched requests — one each in queued, held and awaiting-upstream — and one launched run with a pid and a launch clock. None of the three is classified working, each is drawn in its own phase and counted outside the working column, each arrival draws its own word, and only the launched run is drawn and counted as working. Three further cases launch the queued request (queued → working), age the parked pointers past the stall window (neither reaches needs you, while a silent worker with the same age does stall), and drop and archive a request (drawn dropped, never working).
