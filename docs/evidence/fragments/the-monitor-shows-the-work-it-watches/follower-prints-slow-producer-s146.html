A producer-slow event renders as its sentence, and pane_line still silences it

The follower's renderer in reckon/crew_follow_commands.py hands producer-health events to the sentence path only for the names its producer-health branch lists. producer-slow was not in that list when this work was briefed, so at the base revision a slow-tick notice fell through to the transition painter and drew --:--:-- ? unknown new → help. The listing itself landed earlier as 933066eb43, which makes producer-slow a member beside producer-lost and producer-restored; what no case held was the follower's own output path in this file, so a later edit dropping the name would have gone uncaught here. This node adds the missing cases rather than reimplementing a working guard, and leaves the source file untouched.

Base arm at 5cf298bc collected the five cases the file had then, all passing; the head arm passes. Ruff check and format are clean on the changed test path.
