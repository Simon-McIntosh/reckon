landing: the follower now stands a needs-you line. A new module, reckon/crew/needs_you.py, derives the owning session's runs whose state is in the fleet partition's blocked bucket (FLEET_BLOCKED_STATES) or unpromoted bucket (FLEET_UNPROMOTED_STATES) and composes the line from it: needs you: 1 unpromoted pta-adopted-read-cost 1h21m · 1 blocked fsa-repair 5m, or yours: 4 working · nothing needs you when nothing is outstanding. Each entry names the node and the span the run has held its state, read from the run's own stream so it carries the clock the pane already stamps its rows with; an unpromoted run whose review is already stored is marked reviewed. _follow_watch_lines in reckon/crew_follow_commands.py emits the line from inside the generator, beside _tick(), on any change of the set and again on a cadence that defaults to ten minutes, so a quiet pane is a heartbeat rather than a silence a dead follower also shows. The line does not restate the fleet's rules: it reads the snapshots, hands them to _partition_session_rows for ownership and _fleet_counts for the tallies, and takes the state words from the same FLEET_* buckets the pane's counters read, so the line and the counters cannot drift. A run the stream never dated ages from its own pointer. The state-age lookup returns nothing whenever a run has no stream, or no transition to its current state — and a stall writes no blocked row, so the fallback decides the age. That fallback must be handed the run’s pointer, which carries created_at, rather than the watch snapshot, which carries no creation instant; handed the snapshot it read an absent key, aged every such row at 0m, and sorted the row that most needs attention to the bottom of its group. _snapshots therefore returns the pointers beside the snapshots and the fallback reads the pointer’s own stamp. _needs_you_runs is a delegate to the module, so the row the follower prints at the end of an arming names exactly the runs the standing line names.

The ten-minute default, and where the interval now lives. The earlier attempt armed the line only when a caller passed --remind, which left every production follower silent — the review was right to block on it. --remind is now an override: an arming that passes no flag resolves the interval to DEFAULT_REMIND_SECONDS (600 s) from reckon/crew/needs_you.py, and the only call site in production is the crew follow command, so every armed follower draws both the change-driven line and the ten-minute heartbeat. Emitting on every change alone is what the first attempt measured at eleven added failures in frozen tests that read the follower's output as data, so the first scan of an arming records the set's signature without emitting: the row that opens the pane already names the fleet as it stands, and the line is news only when the set changes or the cadence falls due.
