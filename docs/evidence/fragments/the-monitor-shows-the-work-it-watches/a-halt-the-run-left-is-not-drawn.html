What changed

A held settle row is resolved on the later row that moves its run on to a live pane word, rather than left to expire. When that later row returns the run to the word the pane already shows (a redispatch or a resume inside the window), the held halt and the return are dropped together as one round trip; when it lands on a different live word, the held halt prints at once, ahead of it. A later row landing in a settled word — the terminal echo — still supersedes nothing. LIVE_PANE_WORDS in reckon/crew/ticker.py names the three words.
