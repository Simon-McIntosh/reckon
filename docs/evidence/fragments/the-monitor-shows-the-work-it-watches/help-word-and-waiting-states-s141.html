The pane says help where it needs you, and waiting where the run lifts itself

What changed. The needs you bucket held two different situations: runs that cannot move until the coordinator acts, and runs that move on their own once other work finishes. "you" did not say who, so the bucket read as work for a reader that nothing was waiting on. The bucket is now help, counted under h, and blocked-upstream, held, interrupted and ready moved to waiting, counted under q. SUPERSEDED_PANE_WORDS reads a stored needs you — and the older halted — as help, so a pane restored from history draws the new word and a record whose only change is the word draws no row. CARRIED_PANE_WORDS, which gates whether a row is drawn at all, carries help. No word set in ticker.py names needs you except the superseded mapping.

The fleet partition moved with it. recovery_watch.WAITING_STATES gained the same four states, so a row's word and a counter's letter name the same population: a held run now draws → waiting and counts under q instead of drawing → needs you beside a q figure that already counted it. skills/reckon-build/SKILL.md names help and h and states which four states waiting holds.
