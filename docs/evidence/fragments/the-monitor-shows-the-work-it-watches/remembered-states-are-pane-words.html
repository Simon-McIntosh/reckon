A remembered state renders as its pane word, not a raw internal state

The grid reads a row's left word straight from the state it remembers for the run, and _seed_ticker_memory in reckon/crew_follow_commands.py fills that memory on attach and reload from the follower's checkpoint-merged map, which can hold producer states. _remembered_word in reckon/crew/ticker.py maps a state to its pane word where the memory is taken in — a state already one of the seven words maps to itself, so _display_state's blanks for delivered, halted, landed and dropped are handled. A run remembered as completed_unpromoted now draws delivered on the left, where it drew the raw state before.
