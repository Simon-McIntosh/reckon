Keeping the patch surface still. The family reads the shared line printers _echo_follow_line, _dim_history_line and _import_root, the six _FOLLOWER_*/_SHIM_* environment names, and the three retry constants — all of which stay owned by reckon.crew_follow_commands. The moved code fetches each from that module at call time rather than importing it, because that module imports this one to re-export the family (an eager import would be circular) and because a caller patches such a name on the module that owns it.
