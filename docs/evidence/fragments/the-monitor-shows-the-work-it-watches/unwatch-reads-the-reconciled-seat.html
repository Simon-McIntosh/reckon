What changed

unwatch in reckon/crew/recovery_watch.py decided whether a held seat was this project's from the raw seat record's project field. A producer rewrites that record in place, truncating before it writes, so a reader in that window sees an emptied record and took the absent name for a foreign registration: the refusal refusing to stop watcher for project 'sample': the locked registration names ''. The project, and the identity the stop needs, now come from the reconciled reading watch_state uses — the live holder this project's lease names, with the pid start time taken from the producer's registration beside the seat. A seat that positively names another project, or a foreign host, is still refused, because that refusal is decided before any reconciliation.
