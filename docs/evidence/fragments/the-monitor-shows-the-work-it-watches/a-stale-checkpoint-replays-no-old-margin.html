A re-arm on a stale checkpoint resumes in baseline mode

What changed. A follower's durable checkpoint (reckon/crew/follow_checkpoint.py) recorded the stream's identity and the byte offset of its place, but never the moment that place was written, so a re-arm whose checkpoint was days old replayed every matching row written since — a burst of days-old transitions the pane never had on screen, which the Monitor then suppressed for exceeding its output rate. The record now carries a written_at stamp, and written_moment() resolves the record's age from that stamp or, for a record written before the stamp existed, from the checkpoint file's own modification time. In reckon/crew_follow_commands.py, _follow_resume_plan compares that age against the pane's history window — resolved through the same _follow_history_caps reader the history replay uses, so the margin and the history replay cannot disagree — and a checkpoint older than the window returns baseline instead of continue. The re-arm then reports each run's current state from live run state, suppressing through runs.read_delivered (the delivered-state record a fresh arm already reads) compared by _follow_gap_rows, and a run that has not moved is not announced again. A margin inside the window is delivered as before.

Measured (this node's own change). At head 91397e2ce, tests/test_a_stale_checkpoint_replays_no_old_margin.py is 7 passed, EXIT=0. The four cases of the section: (a) a five-day-old checkpoint at offset X with rows five days old must draw none of them and no row for an unmoved run; (b) a ten-minute-old checkpoint draws each margin row once; (c) a run that changed across a stale margin draws one row for its current state; (d) with ticker.history_window at one hour a two-hour-old checkpoint resumes as a baseline, and at one day the same checkpoint delivers its margin. A companion case shows the staleness decision calls _follow_history_caps and suppresses through runs.read_delivered, and a unit case ages an unstamped record by its file's mtime.

Negative control, observed to fail. The declared mutation removes the age check from _follow_resume_plan. With the shared test set at that head, case (a) (test_a_stale_checkpoint_draws_none_of_its_margin_rows) fails, as do case (c), the one-hour arm of case (d) and the mechanism case: the run reads 4 failed, 3 passed, EXIT=1 against the head arm's 7 passed, EXIT=0.
