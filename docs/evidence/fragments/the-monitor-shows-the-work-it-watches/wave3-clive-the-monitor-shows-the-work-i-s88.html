A worker that ends its first turn without acting is named as a premature end

A print-mode worker gets no turn after the one it is in. A run that opened its first turn, wrote one message and called no tool therefore stopped without attempting anything and without reporting a fault, and its session survived to continue it. The fleet read that run as halted, so the pane said a failure had happened and a coordinator went looking for one.

The classifier now reads that stream shape as a premature end. Its row carries the premature-end clause with the text the worker ended on quoted verbatim, and the remedy reckon crew resume --run <id> --advice continue. The same classifier produces the obligations item, so the duty a coordinator sees carries the same command. The reading is one recovery word of the classification module, which both surfaces consume; no second implementation was added.
