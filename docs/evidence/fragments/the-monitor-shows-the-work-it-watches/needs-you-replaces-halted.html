The pane draws needs you where it drew halted

Every run in the halted group is the orchestrator's move next: blocked, needs-help, held, stalled, stopped, failed, abandoned, refused at admission, and the rest of the group. halted read as a state the run sits in by itself, so the state word is needs you, its hue moved with the word in both themes, the carried-word set names it, and the counter block labels that bucket n — a letter no other counter uses. The group's internal states, the event count-field keys (blocked, unpromoted, waiting) and every rule keyed on membership are unchanged.

One mapping reads a stored word. A checkpoint, a stored history and a delivered-state record hold the word the pane drew when each was written, so a record from before the rename says halted for the same group. SUPERSEDED_PANE_WORDS in reckon/crew/ticker.py reads that word as the word the pane draws now, inside _display_state. Both the grid's remembered-word path (_remembered_word, which falls through to it) and the pipe re-arm's delivered-state path (_follow_resume_output, which maps each stored word through _display_state before comparing) therefore read it there, from one place. A run whose only change since the record is the word draws no row on the first re-arm after the upgrade.
