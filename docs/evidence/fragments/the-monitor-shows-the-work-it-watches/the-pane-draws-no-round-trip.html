RowPolicy holds a departure that returns to the pane's shown word

RowPolicy in reckon/crew/ticker.py now records the word the pane actually showed for a run (written where rows are released, never for a withheld row) and holds a row that takes the run away from that word into a settled state or the dropped word. If the run returns to the shown word inside the settle window the departure is dropped with the return, so the round trip queued → withdrawn → dispatched → queued draws no row; a departure that does not return is delivered when the window passes, and a coordinator duty arriving while the run is away prints ahead of the held departure. tests/test_the_pane_draws_no_round_trip.py passes its four cases, and the 31 test files importing reckon/crew/ticker.py pass with no added failure (444 passed).
