A follower stays while its session owes a review

live_work_populations in reckon/crew/station_subscriber.py is the one statement of the has-live-work rule: the station writes the reading a pane settles by from it on every tick, and a pane with no fresh reading asks the same function through population_has_live_work. It read every run in a terminal phase as drained, so a session whose last run had delivered settled its follower while the review that run owed was still uncomposed — and the reflex that composes that review lives inside that follower.

The rule now also counts a delivered run that still owes its review. The judgement is the obligations' own rather than a second rule derived here: the run is classified and its reading must be scoring, the classification the obligations map to review-missing, and its review tier is read through obligations._review_tier_for_duty — the resolver the duty itself uses, including its none exemption, so an evidence-only delivery owes nothing and does not hold the pane. Both settle paths read this one function, so a station reading and a fallback listing cannot disagree about which run holds a pane.

The new tests/test_a_follower_stays_while_a_review_is_owed.py drives _check_settle through _follow_watch_lines on an injected clock, with a temporary crew home and a handful of stubbed station, so each case measures the pane's own judgement rather than the predicate alone. Six cases, 6 passed: a station reading written by record_live_work from live_work_populations holds the pane over a delivered run owing a review; the same follower with no station reading holds it through the fallback listing; each arm settles once the review is stored; a delivery whose tier is none settles; and a session with nothing live or owed settles.

Two negative controls, both reproduced. Restoring the terminal-only rule (dropping the delivered_run_owes_review call) turns the station-reading and fallback cases red — they settle over the review they owe — and leaves the tier-none case green. Counting every delivered run without the tier check (return true for every scoring run) turns the tier-none case red, so the exemption is load-bearing.
