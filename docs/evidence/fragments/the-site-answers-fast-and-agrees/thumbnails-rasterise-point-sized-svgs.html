A point-sized SVG thumbnails as a raster, not the whole vector

An SVG whose width and height carry a physical unit — as matplotlib writes its canvas, in points — was rejected by the rasteriser with ValueError: SVG has an invalid size, so the thumbnail route fell back to serving the entire vector. The rasteriser is now given a dpi of 96, the CSS reference resolution the source's point size assumes, and such a figure rasterises to a bounded PNG.
