Discovery shares its covered-file observation

The discovery pass now carries one covered-file listing and its observed file stats through its change signature, resource inventory and figure rows. The metadata index stores a host-stable file identity beside each parsed discovery entry, so an unchanged entry uses the stat already observed by the signature walk. Figure paths come from the covered set. Resource scanning skips covered paths its classifier would discard before reading them.
