Revisioned shell assets

The served project shell puts ?rev= on all 34 authored script and stylesheet links when their revisions can be read. File links use file_revision, compiled JavaScript uses its JSX source revision, and the two runtimes use their pinned digests. A missing or unreadable linked asset keeps its bare URL, so that one asset cannot abort the shell; a missing asset keeps its existing 404 response. A valid asset's current URL answers max-age=31536000, immutable; its bare or stale URL answers no-cache with an ETag and returns 304 to a matching validator. Scripts and stylesheets above 1 KiB use the existing compressed-file cache for gzip variants; other file responses retain the 64 KiB threshold. The static shell renderer is byte identical at base and head.
