A capacity refusal resumes on another model of the same lane

A run whose latest attempt was refused because one model was at capacity is now resumed on another model of that same lane, keeping its session. Before this change the resume relaunched the recorded model, which was the one the provider had just refused, so the retry walked into the same refusal.

The refusal is read from the stream's own terminal event, in reckon/crew/dispatch_sessions.py. The scan walks the recorded stream backwards and stops at the first terminal kind it meets: only a turn.failed whose error detail begins Selected model is at capacity is a refusal. A stream that merely quotes the message in an item.completed and ends with turn.completed is an ordinary resume, as are a clean end and any other terminal failure, so prose never counts. The refused model is the attempt's recorded agent.model, mapped to its key through the lane's declared models.

The replacement is chosen by the same owner a named-lane dispatch already uses. lane_model_selection in reckon/crew/dispatch_picker.py gained an exclude argument: the excluded keys leave the lane's declared models, so the picker is never offered them, and an answer naming an excluded or undeclared model is not applied. The resume asks with the refused key left out and takes the named model, or falls back to the lane's first declared model other than the refused one when the ask holds, raises, times out or names the refused or an undeclared model. A lane declaring no other model resumes on its recorded model, exactly as before.

The swap is applied where the resume reads its model: the settings resume_plan builds carry the chosen model and its declared effort, and the session id is kept. The resumed pointer records the new model in agent.model and its key in model_key, and gains one model_changes entry naming the lane, the refused model and key, the chosen model and key, and the reason model-capacity. lane_changes and the lineage are untouched, and a crew resume --backend move still goes where it is told with no ask.
