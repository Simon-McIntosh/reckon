One catalogue resolver for historical lane and model identities

reckon/ledger.py::resolve_name reads the catalogue's alias table and lane declarations. Ledger reads, live classifications, stored reviews, review exclusions and crew views share its pair. The query field vocabulary accepts lane and model_key, and resolved pairs appear on compact run rows by default. Unknown names remain unknown; ambiguous bare models are refused with the declaring lanes named. A recorded model-specific alias retains its key when its historical model id has retired. A plain lane with an unknown model never inherits today's default.
