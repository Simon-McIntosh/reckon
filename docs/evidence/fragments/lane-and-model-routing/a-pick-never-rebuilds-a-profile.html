A pick reads a published run-time profile and never rebuilds one

A pick no longer calls run_time_profile. _cached_run_time_profile serves the persisted profile when its key matches the current stamp; when the stamp has moved it serves the last persisted profile if younger than 24 hours; otherwise it serves none. A served profile's age runs from the instant the refresh persisted it, recorded inside the cached value as persisted_at and, in-process, beside the memo's key. A value without persisted_at reads as older than the bound. A cold cache, a profile past its age, a ledger whose index yields no stamp, a value under another cache version, and a project id that cannot form a cache filename each serve none without reading a ledger. Rebuilding moves to refresh_run_time_profile, owned beside the cache and called by promotion for the run's project after the ledger append; a refresh that fails never fails the promotion. local_lane gains expected_wait_profile_age_s, the age of the oldest foreign profile that contributed to the wait, and the glossary defines it.
