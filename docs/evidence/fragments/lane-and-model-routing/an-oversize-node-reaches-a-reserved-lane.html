A node no unreserved lane can fit is offered the lane a policy reserves, with its tier and attempts terms waived

A node whose estimated context exceeds every unreserved lane's window used to be refused outright, because the only lane that could hold it is covered by a reserved-lane policy whose tier term it does not meet, so the work never entered the queue. candidates() in reckon/crew/picker/snapshot.py now re-judges the reserved candidates over the whole set once each candidate's own exclusions are computed: when no unreserved candidate is left and every unreserved one was removed on context-fit alone, the policy's tier and attempts terms are waived for that node. Nothing else is waived. The window ceiling and the budget verdict were already applied when the candidate's reasons were built, and a candidate held by one of those is left exactly as it was; the waived candidate is measured on its own context fit, so a reserved lane whose window the node also exceeds still cannot run it, and it is probed for serving like every other offered candidate. _reserved_lane_exclusion gains a waive_tier term for the re-judgement, the availability probe moves into _candidate_availability so the waiver path and the ordinary path issue one reading rather than two, and Candidate in reckon/crew/picker/types.py gains a new note field carrying offered because no open lane fits the node's context. The note is never written into reasons, which pick() reads as exclusions, so the exception is visible without excluding the candidate it describes.

The node's new test asserts six cases against snapshot.candidates, with codex the reserved lane and a local lane carrying its own window: a 300,000-token node declaring no tier is offered codex with the waiver note and an empty reasons while the local lane is removed on context-fit; the same node at 8,000 tokens keeps the reservation and is not offered codex; an oversize node is still refused when codex's window reading sits at its 60% ceiling, and the window term is shown to be the one holding once the tier term is waived; an oversize node whose reserved lane's own window is 250,000 tokens is not offered it, on its own context-fit reason; an oversize node whose unreserved lane is removed on availability: refused rather than on context fit gets no waiver; and the waiver reads the same lane derivation the policy is keyed by.
