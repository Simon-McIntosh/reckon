A bare dispatch names a fence far below its effort

A dispatch that names no --time-budget takes the resolved default, and the shipped implement figure is minutes where a plan section may declare hours. Nothing compared the two, so a section of about six hours was fenced at eight minutes and the worker stopped with most of its work undone. plan_dispatch now carries one warning when the resolved default is under a quarter of the node's estimate: the node's own --estimated-hours figure, else the hours its named section declares through _section_record. The plan's total is never read, because it is the same figure for every section of a plan. The line names the estimate, the resolved fence, the flight key that supplied it and the --time-budget to pass, appears in the dispatch result and in a dry run, and is printed to stderr while stdout carries only the JSON document. The dispatch is warned about, never refused, and an explicitly named budget produces no line however small it is relative to the fixture's six-hour estimate. A node the dispatch refuses carries no line either: it is never launched, so the fence it would have run under stops nothing, and the refusal's own document is what a caller must be able to decode.

The five cases the section names, each a dry-run CLI dispatch against a temporary repository whose plan declares twenty hours in total with one six-hour section and one quarter-hour section: (1) a bare implement dispatch of the six-hour section carries exactly one warning, naming 6h, 8m, roles.implement.time_budget and --time-budget; (2) that same line reaches stderr while stdout decodes as one JSON document with no bare notice on it; (3) the same dispatch with --time-budget 1h — still under a quarter of the estimate — carries none; (4) the quarter-hour section of the twenty-hour plan carries none, so the section's figure is read and not the plan's; (5) a node whose authority is a brief names no section and carries none. Three further cases cover what the section's wording implies but does not enumerate: the eight-minute fence the fixture resolves is read from the resolved flight layer rather than written into the fixture, so a change to the shipped figure moves the check with it; an --estimated-hours figure is read as the node's own estimate and stands alone; and a node refused for competence horizon carries no line on either channel while its refusal still decodes as one document.
