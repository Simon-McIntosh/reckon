Every dispatcher finds the router's key

The follower, the admission service and the MCP server each start with sys.path rooted at the checkout that supplied the import — reckon/crew/admission/service.py and reckon/crew/follower_reload.py both build that launcher — and that checkout is often a linked worktree. credential_path() in reckon/crew/picker/client.py used to resolve Path(__file__).resolve().parents[3] / ".env", which in a linked worktree is the worktree's own root. It now resolves the main checkout first: when the checkout root carries a .git file, main_checkout() reads the gitdir: pointer, reads that git directory's commondir file, and takes the parent of the shared git directory. A main checkout, an exported tree with no .git, or a pointer that cannot be read resolves to the checkout itself, so nothing else changes. RECKON_PICKER_CREDENTIAL still wins when it is set, and load_key() still names the environment and the file path it read.
