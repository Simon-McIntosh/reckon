A launched run reads launched, not idle

§3's first cause is repaired. GET /crew derived a row's phase in serve._crew_rows from the age of the run's stream file, which does not exist until the worker's harness starts, so a dispatched run read idle for its first 15–45 s. The row now reads the phase from the same classification the crew live view reads for the same pointer (reckon.crew.recovery.classify_pointer), so one run cannot render two ways; the stream reading stands only for a pointer the classifier cannot phase at all — one recording no phase and carrying no evidence of a launch. Commit 1f29f3112; the response's fields are unchanged and no field was added.
