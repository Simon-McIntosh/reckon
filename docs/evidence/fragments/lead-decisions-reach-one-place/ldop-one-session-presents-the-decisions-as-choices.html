And an answer written under a live run's environment is refused by the run-scoped write guard: crew decision choose --id plan:… returns was not locked: run_scoped_write while RECKON_RUN_ID is set. The rehearsal clears that variable for the child process; the presenting session the skill describes is a lead's session, which carries no run id.
