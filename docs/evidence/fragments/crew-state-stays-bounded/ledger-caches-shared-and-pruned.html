Discovery stats absent git markers without trying to open each one, retaining the existing focused-read file-open bound.

The existing gc.retention_sweep now calls _orphan_ledger_indexes and _expired_picker_views. It removes missing-source ledger indexes and picker budget views older than seven days, prints each removal, and appends it through the existing rotating retention log. It checks the configured cache and the fallback cache readers use inside a read-only configuration fence; an explicit cache override limits the sweep to that cache. Open process descriptors and SQLite write locks protect active ledger caches. Open descriptors protect picker views. A cache backed only by per-run files stays even when its aggregate is absent. Scheduled removals print without changing the existing garbage-collection JSON response.
