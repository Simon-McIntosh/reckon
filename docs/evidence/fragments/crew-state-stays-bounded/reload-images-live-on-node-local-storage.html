Reload images live under the node's runtime root

checkout_trust._committed_tree_cache resolves the image cache through reckon.crew.station_store.runtime_root_source — the station's own resolver, not a second one — and returns <runtime root>/reload-trees. When no node-local root is available it raises, naming the three candidates, rather than falling back to the crew home; an image on shared storage is exactly what the cache moved off. With every image node-local, the cross-node lease record is gone: _record_lease_node and _lease_nodes are deleted, pin_materialized_tree and refresh_materialized_tree_pin no longer write it, and _prune_must_keep loses its host branch. What remains is the same-node rule: an image whose .in-use mark exists is left to the pruner's flock, which is visible on this node and refuses while a reader holds one, and a tree with no mark yet — the publish-to-lease gap — is spared for the publish grace.

The new file's five cases fail at the base revision (5 failed, 8 passed) and pass at head (10 passed in the two-file suite: EXIT=0).
