Six dispatch fields live beside the run

Dispatch stores picker_selection, admit_request, argv, competence, peer_scopes and unreconciled_override in dispatch-detail.json. The live pointer carries that file's path. One accessor reads the stored path and falls back to inline values on old pointers; observation, resumption, admission, promotion and the server use it. A promoted ledger row retains its picker selection and unreconciled override.

Before the change, the test dispatch raised KeyError: 'dispatch_detail', and an AST check found four direct reads in source. The six existing test cases that read moved fields directly initially failed with KeyError; they now assert the same field values through the accessor. The final AST walk of reckon/ and tests/ found no direct live-pointer read of those fields.

The test compares a pointer without the six inline fields against one it writes with those fields added, keeping every other field and the JSON format the same. With a short temporary path, the pointer measured 13,464 bytes and the inline counterpart 24,764 bytes: the 11,300-byte difference equals the six fields' serialised size. With a long path, the figures were 16,539 and 30,308 bytes, a 13,769-byte difference equal to the fields' size there. Absolute sizes are diagnostic; the 12 KiB bound belongs to the whole section. The synthetic lane and quota documents are read and checked, and a corrupted quota document makes the test fail. The test guards the operator's real documents against reads and writes through queued admission stamping. The base arm passed 14 tests and the head arm passed 19, adding no failures. An in-harness diagnostic pointer measured 14,165 bytes because its remaining directive is large; later work in this section moves that field.

With the inline-pointer fallback removed from the accessor, the old-shape test failed on picker_selection with EXIT=1. The mutation was restored after the red run, and the final head arm has EXIT=0.

The new-shape test now captures all six values before the detail file is written and compares accessor reads with that independent copy. A corrupted picker backend makes the repaired test fail; with the repair reversed, the old test passes against the same corruption. On the changed Python path, ruff check --no-cache reported “All checks passed!” and ruff format --check reported “1 file already formatted”; both receipts have EXIT=0 in the run record.
