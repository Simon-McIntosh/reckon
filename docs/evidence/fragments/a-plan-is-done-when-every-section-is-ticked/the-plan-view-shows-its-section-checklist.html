The plan view shows its section checklist

The plan view renders the todos field the plan read carries, above the plan body, in docs/ui/plan.jsx. A new PlanChecklist component maps the payload rows straight to markup: one <li> per authored section in document order, each carrying the payload's link as an anchor to #<id>. A row's look is chosen from its declaration and nothing else is derived — done renders a checked box and its c-close-<id> body, deferred reads as deferred, anything else reads as open. The render is inserted directly before the plan body container (className="r-plan-html"), so it sits above the first authored section heading. Styles land in the plan view's own stylesheet, docs/ui/plans.css (.r-plan-checklist, .r-plan-todo, .r-plan-todo-box, .r-plan-todo-state). No payload field was changed; reckon/ is untouched.
