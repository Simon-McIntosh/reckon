A claim’s move-aside is not a staged write

The staged-write detector _staged_writes in reckon/interface_counts.py reaches one level of delegation for its move-aside exemption: it resolves the callee of every call, recognises a helper that exclusively creates one of its own parameters with O_CREAT | O_EXCL, and treats the argument a caller hands that helper as a file the caller did not stage, so a later rename of that path — whether performed inline or through a helper — is a move-aside rather than a publication of a locally written temporary. It still reports a locally written temporary handed to a renaming helper and a locally written temporary replaced in place, and behaviour in reckon/crew/resumption.py is unchanged, so claim_next_attempt is no longer reported. Measure: tests/test_staged_write_inventory.py — test_every_staged_write_reaches_the_owner passes at head with its expected set unchanged, and a new case pins a delegated move-aside unreported while a temporary handed to a renaming helper and a locally replaced temporary are reported; with the exemption removed the inventory test and the move-aside case both fail (2 failed, 48 passed).
