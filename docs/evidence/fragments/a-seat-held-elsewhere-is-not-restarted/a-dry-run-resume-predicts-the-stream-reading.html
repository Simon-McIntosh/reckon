A dry-run resume predicts the launcher's stream reading

The dry-run prediction _launcher_refusal in reckon/crew/resumption.py stopped at the window gate and never applied the launcher's last guard, so a preview offered a resume for a run dispatched on another host whose stream was still being written. The three-way process reading and the stream verdict are now one shared helper each (_observed_process_reading, _stream_reading_refusal), consulted by both _launcher_refusal and _observed_end_refusal, so the two doors refuse with one wording or both proceed.
