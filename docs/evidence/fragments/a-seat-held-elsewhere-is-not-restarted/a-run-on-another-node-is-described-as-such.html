A run on another node is described as on another node

The catch-all running arm of classify_pointer now tells apart the two causes of an unknown liveness. A pointer naming another machine gets a detail naming that host, with the stream state read from the same newest-stream reader the classifier uses: moving when it is inside the stall window, quiet otherwise. A pid-less run launched in the calling harness keeps its wording. The classification itself is unchanged — every case still reads running. A temporary crew home classifies a foreign run with a moving stream and finds the host named and no in-harness in the detail; a foreign run whose stream is past the stall window finds the host named and no claim of motion.
