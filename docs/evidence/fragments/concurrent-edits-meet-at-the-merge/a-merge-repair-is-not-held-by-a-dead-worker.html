A merge repair is released once the dead turn's process is gone

The repair reflex read a reviewed run's newest resume stream as a turn in progress whenever the stream carried an assistant record and no result line. That stream is only evidence about a process that is still there: a worker that died mid-turn left the same stream behind and no process, so the round was held for ever with the reviewed run has a resumed turn in progress — the reported state of a run whose recorded supervisor pid the kernel had already proved gone.

The busy check now reads liveness before the stream: a pointer pid or worker-record pid that the process table proves dead releases the round, so the repair is reached. Liveness the record cannot answer — a pointer written before the worker registered — keeps the old stream reading, because silence about a process is not proof of its death. A live pid still holds the round through the same check that always answered for it.
