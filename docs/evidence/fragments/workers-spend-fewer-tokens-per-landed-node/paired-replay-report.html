Each arm's verdict under §8's rule

The rule applied to the paired differences: adopt only when cumulative input per landed node falls by at least 5% against the arm's baseline with no fall in the gate pass rate. Two constraints precede the size test. First §14's separation test: an arm whose paired-difference 90% interval overlaps the same-arm interval — the spread the replicate clive run shows against clive on the same sections — is reported as not separated and is not adopted, whatever its point estimate. Second, the direction of the defect: fewer edit failures and less input per landed node are better, and a lower gate pass rate is worse, so an arm that spends fewer tokens by passing fewer gates reads as a failure rather than as a saving.
