A locked ledger store is retried

run_store.append retries an index write that lost a race for the store's write lock, with a backoff bounded by wall clock (INDEX_RETRY_SECONDS) rather than by an attempt count, so a lock held for milliseconds still writes its row and one held past the bound is raised instead of holding the promotion open. The retry sits below that seam, inside one call, so ledger._index_append still makes one append per run however many attempts a lock took — the concurrent-append test measures the seam's call count and fails on a retry placed above it. Only a lock is retried: _locked accepts an OperationalError that says locked or busy, and a duplicate-row or malformed-record refusal is raised at once because the same write would fail again. The one retry helper, _retrying, opens its connection with a short busy timeout (INDEX_BUSY_TIMEOUT_SECONDS) because a five-second driver wait would spend the whole bound inside the first attempt; every other connection — a refusal stamp, a reader, a corpus import outside the retry — keeps the driver's own patience, so nothing but the retried write changed its waiting behaviour.

The repair pass is run_store.import_ledger, which the promotion gate already runs: it inserts every committed run the store lacks and corrects a row that disagrees, so a run promoted with a failed index append is covered without a second implementation beside it. import_ledger writes through the same _retrying helper, so a lock met while it walks the corpus is waited out rather than surfacing as an uncaught OperationalError; its counts are recomputed per attempt, because a retried attempt re-walks the corpus and sync_run is idempotent.

Measure: the defect reproduced at base 327ce7a6bb — a write lock held for six seconds made the append return {"status": "failed", "error": "OperationalError: database is locked"} after a single 5.01 s attempt, with the row absent. At the repaired head 9812a25966, a 0.6 s lock writes its row on a later attempt (0.97 s elapsed, row indexed); a 5.0 s lock is reported failed and then appended by import_ledger (rows_imported: 1, row indexed); and an import begun while another connection holds the lock for 1.0 s finishes it (rows_imported: 1, 1.07 s elapsed). Negative controls: the same 0.6 s lock against a package whose retry bound is removed fails the append in 0.6 s with the row absent, so the passing arm is the retry rather than the store's own patience; the same 1.0 s lock against the pre-repair tree raises OperationalError: database is locked out of import_ledger after 0.2 s, so the passing import arm is the scoped timeout and the retry together; and repair_index/unindexed_run_ids exist in the pre-repair tree and are absent at the repaired head, so the deletion is what removed the duplicate.

Suite: the 262 modules that import the changed modules ran with pytest -n 8 on both arms — 22 failed, 2805 passed and 10 setup errors at base 327ce7a6bb; 21 failed, 2816 passed and no errors at the repaired head 9812a25966. No failure is added, and eleven base failure or setup-error ids do not recur.

No repository regression test could be added: this node's granted write scope carries no tests/ path, so nothing in the tree reddens if the retry is removed. The measures above are produced by probe_index_retry.py under the run directory and recorded there; adding the test belongs to a node whose scope includes tests/.

A regression test is owed and cannot be landed from this node: the fence grants no tests/ path, so the test below exists only as this record. It is written against the repository's own conventions (tmp_path, monkeypatch, a second connection holding the store's write lock) and it has been run both ways from a scratch tree: three passed at the repaired head, and two fail against a package with _retrying replaced by a bare RunStore() open — the seam test sees one attempt and the past-the-bound case returns written where it must return failed. Landing it is one file copy into tests/test_a_locked_ledger_store_is_retried.py by a node whose scope includes that path.

"""A locked run store is retried, reported, and repaired.

The index is a cache over the committed run files, so a write that loses a race
for the store's lock must not cost a run its row: it is retried with a bounded
backoff, a lock past that bound is reported rather than raised, and the missing
row is left for the import the promotion gate runs.
"""

from __future__ import annotations

import sqlite3
import threading
import time
from pathlib import Path

from reckon import ledger, run_store

PROJECT = "proj"
RUN_ID = "r-locked-append"


def _store(tmp_path: Path, monkeypatch) -> Path:
    home = tmp_path / "home"
    home.mkdir()
    monkeypatch.setenv("RECKON_HOME", str(home))
    path = tmp_path / "index.db"
    monkeypatch.setenv("RECKON_RUN_STORE", str(path))
    monkeypatch.delenv("RECKON_STATE_ROOT", raising=False)
    monkeypatch.delenv("RECKON_MOUNTS_PATH", raising=False)
    with run_store.RunStore():
        pass
    return path


def _record() -> dict[str, object]:
    return {
        "run_id": RUN_ID,
        "project": PROJECT,
        "member": "worker",
        "node": "a-locked-ledger-store-is-retried",
        "completed_at": "2026-11-03T07:20:00Z",
        "outcome": "completed",
    }


def _holding(path: Path, seconds: float) -> threading.Thread:
    """Hold the store's write lock for ``seconds`` on another connection."""
    holder = sqlite3.connect(str(path), isolation_level=None, check_same_thread=False)
    holder.execute("BEGIN IMMEDIATE")

    def release() -> None:
        time.sleep(seconds)
        holder.execute("ROLLBACK")
        holder.close()

    thread = threading.Thread(target=release, daemon=True)
    thread.start()
    return thread


def test_a_locked_write_is_attempted_again(tmp_path: Path, monkeypatch) -> None:
    """The retry is the mechanism, so the first refusal must not end the write."""
    _store(tmp_path, monkeypatch)
    attempts: list[int] = []
    real_append = run_store.RunStore.append

    def locked_once(self, project, record):
        attempts.append(1)
        if len(attempts) == 1:
            raise sqlite3.OperationalError("database is locked")
        real_append(self, project, record)

    monkeypatch.setattr(run_store.RunStore, "append", locked_once)
    monkeypatch.setattr(run_store, "_append_backoff", lambda _attempt: None)
    run_store.append(PROJECT, _record())
    assert len(attempts) == 2
    assert RUN_ID in (run_store.indexed_run_ids(PROJECT) or set())


def test_a_short_lock_is_waited_out(tmp_path: Path, monkeypatch) -> None:
    path = _store(tmp_path, monkeypatch)
    releaser = _holding(path, 0.4)
    try:
        outcome = ledger._index_append(PROJECT, _record())
    finally:
        releaser.join()
    assert outcome == {"status": "written"}
    assert RUN_ID in (run_store.indexed_run_ids(PROJECT) or set())


def test_a_lock_past_the_bound_is_reported_then_imported(
    tmp_path: Path, monkeypatch
) -> None:
    path = _store(tmp_path, monkeypatch)
    monkeypatch.setattr(run_store, "INDEX_RETRY_SECONDS", 0.2)
    releaser = _holding(path, 0.6)
    try:
        outcome = ledger._index_append(PROJECT, _record())
    finally:
        releaser.join()
    assert outcome["status"] == "failed"
    assert RUN_ID not in (run_store.indexed_run_ids(PROJECT) or set())

    source = ledger.run_path(PROJECT, RUN_ID)
    source.parent.mkdir(parents=True, exist_ok=True)
    source.write_text(ledger.serialize_run(_record()), encoding="utf-8")
    repaired = run_store.import_ledger(PROJECT)
    assert repaired["rows_imported"] == 1
    assert RUN_ID in (run_store.indexed_run_ids(PROJECT) or set())
