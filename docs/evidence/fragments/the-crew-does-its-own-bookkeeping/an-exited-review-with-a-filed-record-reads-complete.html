An exited review run with a filed record reads complete

classify_pointer in reckon/crew/recovery_classification.py gains _filed_review_record: for a run whose dispatch role is review and whose process is observed to have ended, it reads the per-attempt receipt the supervisor writes when it files a delivered review — attempt-<n>-review-filed.json, named by REVIEW_FILED_RECORD_NAME, beside the exit record — and requires the attempt the run's own marker (attempt.json) names, so a receipt filed by a superseded attempt cannot stand in for the attempt now running. When that receipt names a store entry whose record parses as a review, the run is classified promotable (the fleet state reads complete) whatever the manifest's status word still says, and the row's detail names both the receipt and the store record. An exited review run with no filed receipt keeps the reading it had, and a live reviewer still in its turn is never read as a delivery. The filed receipt is computed from the pointer and the attempt marker alone, before the arms that withdraw a predecessor's manifest word, so it survives the readings that drop that word.
