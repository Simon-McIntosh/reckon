A review run's promotion derives its own total and waits for its manifest

Two of the three refusals §1 records are repaired here. A review promoted with crew complete --run <id> and no gate flags no longer loses a record whose six dimension scores are all present but whose total line is absent: the delivery verdict applies the same arithmetic read_review already applies, so the record reads as the complete review it is. And a review promoted a few seconds before its worker writes manifest.md now waits a bounded twenty seconds for that file and, when it never appears, refuses naming the path rather than promoting a run whose own account of itself does not exist.

The third refusal still reproduces at the head this node started from. The derivation that replaces that command with the record's own check lives in reckon/crew/promotion_records.py, outside this node's write grant, so the repair is recorded here rather than applied.
