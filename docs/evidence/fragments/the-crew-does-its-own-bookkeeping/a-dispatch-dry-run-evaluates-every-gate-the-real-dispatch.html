A dispatch preview routes where the launch routes

Reproduced at base. At base 682bc6cd25, one node dispatched twice under picker routing whose answer was hold with the local lane among the offered candidates: the real dispatch exited 0 on backend clive, and the --dry-run preview of the same call exited 3 with budget-hold. The preview resolved the picker's hold itself instead of continuing the request onto the lane the launch continues it onto.

What changed. The hold continuation — a hold whose offered candidates include the local lane is a wait for that lane, not a refusal, unless a due or urgent request has a lifted serving lane to prefer — now lives in continue_hold_on_its_offered_local_lane in reckon/crew/dispatch_plan.py, and the preview calls it before resolving. The preview reports Jev's own hold answer beside the lane it continued on, with route_mode: overridden-hold, so the two documents read as one decision.

The plan-review gate already agreed. The gate the incident also named is evaluated inside the shared resolution step, so the preview already refused plan-review-missing where the launch refused it at base. That behaviour is now pinned by a test rather than changed, and the negative control proves the test can see the difference: skipping the gate for the preview's own flag turns the case red, with the preview passing through a gate the launch applies.

Measure. The new module's two cases pass at the committed head 7729d9a7e5: the plan-review case refuses with the same error key and exit 4 on both arms, and the routing case resolves backend clive, local: true, route_mode: overridden-hold and the picker's own hold answer on both arms. Against the base checkout the shared regression set is 5 failing tests at base and the same 5 at head, with zero added and zero fixed (1068 passed at base, 1070 passed at head; the two-test difference is this node's own module). One intermittent test id appeared in the first head run and passed on a rerun of the same list and on a targeted parallel run.. ruff check and ruff format --check report no findings on the three changed paths.

Scope note. The launching path still carries the same rule inline in reckon/crew/dispatch.py; it was left untouched and is recorded as a deduplication the coordinator may dispatch.
