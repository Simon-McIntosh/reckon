Scope and method

Nine reference files under skills/reckon-build/references/. A binding sentence states a rule a coordinator or worker must follow: it contains or implies must, never, always, refuse, or it is an imperative. Every other sentence is counted but not rowed.

The sentence counts are produced by sentence_counts.py in this fragment's figure directory: it strips fenced code blocks and headings, normalises table pipes and list markers, then splits on sentence-final punctuation. Row lines are the line number of the first line of the sentence.

A row is marked enforced only where a test drives the guarded action far enough to make the refusal or check fire; the test is named in the row and the focused gate that ran it is cited under Evidence. A rule whose guard no test exercises is not enforced, however clearly the code implements it.
