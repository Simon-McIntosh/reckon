§1 — Method and scope

The keyword set, imperative-verb table and abbreviation guard are imported from classify-rules-in-the-skill/scan_binding.py, the module that already owns them, so there is one definition of what reads as a rule. A sentence is binding when it carries that keyword set (must, never, always, do not, only, refuse, shall, mandatory, no longer, cannot, required, and the rest) or opens with an imperative verb from that table. Every binding sentence has one row in §2, located at the line its first character sits on.
