The 26 September pre-dispatch skill-load baseline

Baseline: a coordinator spends a median of 6,231 input tokens loading the reckon-build skill and its references before its first reckon crew dispatch call. Recorded from the transcripts under ~/.claude/projects read read-only, measured at revision a34a62bb. The section 3 rewrite is judged against this number, which cannot move because it is instead derived from the recorded usage totals of the sessions named below.

Method

The script docs/research/data/crew-contract-baseline/measure.py scans the coordinator transcripts read-only. Selection rule: a session is selected when, on 2026-09-26, it records at least one reckon-build skill load — a Skill invocation of reckon-build, an injected SKILL.md body, or a Read of SKILL.md or of a file under reckon-build/references/. The load window ends at the first reckon crew dispatch call at or after the first load, or at the end of the transcript when the session never dispatched.

Token accounting. Each assistant request records a usage block whose total input is input_tokens + cache_creation_input_tokens + cache_read_input_tokens. A load's cost is the rise in that total across the load — the next recorded total after the injected content lands, minus the last recorded total before it. Nothing is estimated from characters. A load is reported unmeasured, rather than as a zero, when no request precedes it (the skill was injected at session start) or when the context shrank across it (a compaction landed between the two requests and bundled the re-injection with its summary).

Positive control. The detector is run against the session known to invoke the skill (1d1d2f0d, where it sees the Skill load) and against 1225959a, a session that merely quotes a transcript containing the skill body inside a tool result; the quoted copy is rejected. Both checks print in the log.

Limitation

2026-09-26 was a quiet Saturday: four sessions loaded SKILL.md itself and a fifth (5b2accfd) loaded a reference. Both figures are printed in the log. Only three of the five admitted a token measurement, because two sessions were long-lived (started 2026-09-24) and their 09-26 load was a post-compaction re-injection, which the instrument cannot isolate from the summary it arrived with. The 26 September figure is therefore a small-sample baseline; the log carries every per-load figure and the reason for each exclusion so the after-side measurement can apply the same rule.

Word counts at the baseline revision

Measured by the done-when's own rule (whitespace-split words): SKILL.md 11,050 words; the ten reference files together 23,726 words; the two together 34,776 words, against the 12,000-word ceiling the rewrite must meet. These are the pre-rewrite figures and are expected to exceed the ceiling; the rewrite is what closes the gap.
