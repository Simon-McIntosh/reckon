The run-only scope measure charges merged content and nets its churn

_committed_scope in reckon/crew/promotion.py now measures a citation list of merges alone through each merge's first parent: the merge's changed paths and changed_lines are the content the merge brought, so a run whose work reached the record inside a merge is charged it rather than refused or recorded as zero. Mixed citation lists still read paths from the run's own commits, a trailing merge is still not charged, and changed_lines remains one net diff over the measured commits — confined to tests/test_run_scope_measure_nets_churn.py, where every expectation is the fixture repository's own git diff rather than the citation list the case passes in.
