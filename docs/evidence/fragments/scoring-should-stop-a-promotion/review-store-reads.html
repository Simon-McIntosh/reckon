The review store finds, scores and reads records by their own content

Three followups of the review store's read path were repaired in reckon/crew/review.py, each after a reproduction taken at the base revision and each with the mutation restored as the negative control.

  • A misfiled record is found. stored_record falls back to the store's records when nothing sits at the path the reviewed run keys, matches on the record's own reviewed_run_id (and the head it read, when one is named), returns the file it was read from and flags it with misfiled; a record the store filed as an incomplete partial is skipped.
  • The cap note names only an applied cap. annotate_added_failures writes the cap note only when the cap lowered the stored total, so a total already at the cap gains no note and a record whose total is null reads unscored; N added failures.
  • A revision= header is read. _LOGGED_REVISION_RE accepts revision=<sha> beside revision:<sha> and revision <sha>, and the sha reaches the annotated review's head_log_revision.
