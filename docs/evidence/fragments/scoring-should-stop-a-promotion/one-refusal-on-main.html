The change

reckon/crew/promotion.py. The independent preconditions of a promotion are swept by _require_independently, which keeps every product and raises one refusal carrying every failure in the order checked, the first kept verbatim so a caller matching on the leading refusal still matches. The landing checks move into _landing_preconditions, which both the promotion entry point and the locked body call, so their refusals compose into the same message and the row records the canonical revisions the citations resolved to. The changed-scope and role checks stay sequential after the citation they diff, and the suite-delta check keeps its own exception type. The unreviewed-review refusal names the reviewed head with --commit <head> when the manifest's commit list predates it.

A commitless declaration the declaration parser recognises now means no commits: the presented branch does not refuse it, and the places that judge the presented commits — the review tier and the landing resolution — read it through the same parser (_presented_commits_without_a_declaration), so the resolver is never asked about a sentence. A word that only begins with an absence word is still a citation attempt: nonesuch is refused.

One vocabulary for every unresolvable-commit refusal, and it is the resolver's: does not resolve to a commit object. The resolver is the last judge of a citation and the presented refusal was already worded with it, which leaves the declared branch's an object as the outlier; the two expectations pinning it in tests/test_commitless_review_promotes.py are updated in the same commit.
