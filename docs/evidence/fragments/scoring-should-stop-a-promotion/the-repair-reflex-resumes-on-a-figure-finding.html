The repair reflex reads the figure review

The defect

A run that drew a figure carries two stored reviews at one head: its text review and its figure review, filed under the figure rubric at its own path. compose_repair_for_run read only the text review, so a blocking finding the figure reviewer raised opened no round at all — the run composed None and the figure defect waited for a coordinator while a text defect went straight back to the node that drew it.

The change

reckon/crew/repair.py gains review_with_figure, which reads the figure review for the run and head the text record names and appends its findings after the text record's, re-keying the figure record's own finding_dispositions onto the appended positions so a figure finding already disposed reads as disposed rather than being repaired again. compose_repair_for_run composes from that merged record, so the round's brief and the resume advice the reflex builds from it name the figure and the finding. The reader stays pure: the union is made once at composition, not inside review_findings, which the findings surface walks per stored record and would double-count if it read the companion itself.
