crew dispose answers a figure finding

The defect

A finding is answered by one verb: crew dispose writes a fold or an exemption under finding_dispositions on the stored review record, and the promotion guard and the repair reflex both read that key. A run is reviewed under more than one rubric, and the figure review is filed beside the run's text review rather than in place of it — the store keys a figure record at <run>.figure.at-<sha>.json next to the text record's <run>.at-<sha>.json. The disposition writer selected its record through stored_record with no rubric, and that selection returns text-review records only, so a figure finding had no writer at all: the command either answered the text review or reported an index the record it rewrote did not carry.

The receipt had the same shape: it was composed from stored_record_for_disposition, which took no rubric either, so even a correct write would have reported the text record's answer. A run with a clean text review and a wrong figure finding was stranded — the finding refused promotion and the operator's own verb could not retire it.

The change

crew dispose takes --rubric, and --rubric figure answers a finding on the run's figure review. The rubric is threaded through the two functions that already exist rather than a second writer being added: record_finding_disposition passes it to the stored_record selection it already made, and stored_record_for_disposition passes it to the same selection, so the record read, rewritten and read back for the receipt is the one family the caller named. The index the caller sees printed is counted against the selected record's own findings, so the number in the receipt and the entry the writer keys cannot disagree.

Three states stay as they were. Omitting --rubric answers the run's text review exactly as before, because an omitted rubric is the selection every existing caller already made. A run carrying no figure record is refused naming that absence rather than writing somewhere else. And --dimension is refused beside --rubric figure, because a figure review records rubric verdicts rather than the six scored dimensions, so a dimension named against one names a space the record does not carry.

The gate

The new module builds its stores through the store's own writer (reckon.crew.review.store_review) rather than writing records by hand, so the rubric field the store writes and the field the selection reads are the same fact. Both records — the text review and the figure review — live in a temporary configuration home under the test's own temp tree, the reviewed run's pointer names a synthesised checkout seeded by the fixture, and the module asserts the operator's real store gains no directory for the fixture project.

The measure reads back through the two readers a consumer uses: the rubric-selected read_review, and repair.blocking_findings — the list a promotion's refusal is built from — which no longer carries the answered finding. The text record is asserted to carry no disposition after the figure write, and the figure record is asserted to keep its own findings, so the rewrite is a splice rather than a replacement.
