The figure rubric's unreached parser is removed

The defect

reckon/crew/review.py carried a second pattern for the RUBRIC verdict line, _FIGURE_RUBRIC_LINE_RE, beside the shared _PLAN_RUBRIC_LINE_RE the plan-review, health and delivered-report readers already use. Its only reader was parse_figure_review, which had no production caller: a figure review is filed as a structured record through store_review, the same store a text review uses. The parser was dead code that would have to be kept in step with the grammar the module already owns.

What changed

Both parse_figure_review and _FIGURE_RUBRIC_LINE_RE are deleted from reckon/crew/review.py. FIGURE_REVIEW_ITEMS stays: the dispatch composes the figure review's done-when from it in reckon/crew/recovery_review_subject.py, and the prompt test checks the prompt against it. The shared _FIND_RE stays for the claims reader that still uses it.

In tests/test_figure_review.py the prompt test is renamed test_figure_prompt_and_parser_cover_every_visual_rule → test_figure_prompt_and_brief_cover_every_visual_rule, for what it still covers, and its three parser assertions are dropped. It still asserts the prompt names every FIGURE_REVIEW_ITEMS entry and its read-only rules and that the composed brief carries its phrases. Every other test in the file is untouched.

Measure

tests/test_figure_review.py: 7 passed, 0 failed (EXIT=0). The renamed prompt-and-brief test still checks every visual rule against the prompt and the brief; the record tests still store and read a figure review through store_review and read_review under rubric: "figure" and keep text and figure records on separate paths.

Negative control. Removing one FIGURE_REVIEW_ITEMS entry (data_ink) from reckon/crew/prompts/figure_review.md made the renamed test fail on assert item in prompt: 1 failed, EXIT=1, test id tests/test_figure_review.py::test_figure_prompt_and_brief_cover_every_visual_rule — so dropping the parser assertions has not removed the prompt's guard. The prompt was restored before the commit.

ruff check reported all checks passed and ruff format --check reported both changed Python files formatted (EXIT=0 for both).
