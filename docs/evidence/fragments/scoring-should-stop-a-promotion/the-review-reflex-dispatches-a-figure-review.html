The review reflex dispatches a figure review

What changed

dispatch_review_for_run detects committed additions or changes to supported images below a figures directory and dispatches a second review with the figure rubric. Lane selection requires the image modality. The composed brief includes the visual rubric and says the reviewer writes only its review record; changed SVGs are rendered to PNG attachments.

review.py parses the figure verdicts and stores them at a path keyed by rubric, run and reviewed head. Text review reads continue to select text records, and select_review_for_head skips a figure-only record. The generated figure review's completion condition names all six rubric items as a measurable deliverable.
