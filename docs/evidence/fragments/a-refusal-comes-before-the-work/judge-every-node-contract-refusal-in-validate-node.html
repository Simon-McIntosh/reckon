§2 — validate_node carries every contract refusal on every path

validate_node is now the single judge of the whole node contract. It gained repository and override arguments, and it appends the negative-control finding (negative_control_finding) and the gate-population finding (gate_population_finding) to its own list beside the six properties it already reported. The execution-fit comparison it already made now honours the caller's override through assess_execution_fit, and it refuses on not fit.allowed rather than fit.conflict, so --allow-execution-mismatch survives the move into the shared judge.

All three callers pass the same inputs. plan_dispatch passes the resolved lane's execution_capable, its execution override and the repository, and its three duplicated refusal blocks are deleted; it keeps its execution_fit value because that is the audit label the resolution persists. queue_requests, which a batch reaches, now calls validate_node beside admission_domain_findings, resolving the role overlay against the lane the request records so the verdict does not depend on which lane admission later binds. queue_edit._contract_findings passes the record's repository and the same resolved role.

Five negative controls

Each mutation in plan §2 was applied in turn and each reddened exactly the case it names, with the tree restored between runs: dropping validate_node from queue_requests stores the compound-goal entry; leaving the negative-control refusal outside validate_node stores the check-with-no-negative entry; leaving the gate-population refusal outside it stores the unmatched-glob entry; calling it without execution_capable stores the incapable-role entry; and dropping the override refuses the overridden dispatch.

A queued request keeps its recorded override

queue_edit._contract_findings now reads the execution override the request recorded — dispatch_options.execution_override, the allow_execution_mismatch option a queued pointer carries, or the resolved execution_fit.override on a launched pointer — so an edit no longer refuses a request that was legitimately stored with --allow-execution-mismatch.
