An admission pass, a landing pass and a dispatch each read plan state once

One admission pass now enters metadata_index.discovery_file_scope and resources.resource_scan_scope once, and derives a project's readiness once however many requests and refs name it. Plan state is read through the memoised read_state_and_text_file pair seeded from metadata_index.discovery_state, so a ref no longer re-parses the plan text it names. land_once and plan_dispatch — the path crew dispatch --dry-run resolves through — enter the same boundary, and the landing pass closes it before it merges.
