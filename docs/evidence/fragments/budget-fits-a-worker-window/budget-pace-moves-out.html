The pace and lift family moves out of budget.py

The pace report, the pace row and the pace hold (group_pace, pace_row, pace_hold, _pace_releases_at), the seven lift-reading helpers, the credit-lift verdict and the seventeen helpers only those call move to reckon/pace_report.py. _credit_lift_verdict moves to reckon/crew/budget_lift.py, beside the credit-lift record form it reads, and its DEFAULT_CREDIT_RESERVE_FRACTION is deleted from budget.py in favour of the definition that module already carried; reckon.budget re-exports it. The call graph was checked before the move: every one of the seventeen helpers is referenced only by family members, and the only moved name referenced from outside the family is _scale_for_banked_reset, which one test reads as budget._scale_for_banked_reset and which stays a real binding in reckon.budget.

reckon.budget imports the family at module level, so group_pace, pace_hold, _lift_history, pace_row and _scale_for_banked_reset all remain bindings there. preflight keeps calling group_pace, pace_hold and _lift_history by bare name, so a patch installed on reckon.budget still steers it, which is what the four picker tests and test_reserved_lane_window_reading rely on. pace_report imports neither reckon.budget nor reckon.crew at module level: it resolves each budget name inside the function that uses it, and reaches the crew package the same way, because reckon.crew's package initialiser loads reckon.budget and would otherwise run against a partially initialised module. The two names read only in annotations sit under TYPE_CHECKING.

Measure: at head the width test no longer names reckon/budget.py; its remaining offenders are exactly the base arm's less budget.py (reckon/crew/review.py at 52,989 and reckon/ledger.py at 51,666, both 52,989/51,666 at base too). By reckon.crew.routing._tokens_for_bytes: reckon/budget.py 56,488 to 36,942, reckon/pace_report.py 20,502, reckon/crew/budget_lift.py 15,174, all under the 45,000/40,000/40,000 bounds. The gate ran 226 tests in both arms: 10 failures at base, the same 10 at head, zero added. ruff check reports 0 findings on budget.py and pace_report.py and 1 on budget_lift.py, against 1/–/1 at base, so no changed path increased. Declared negative control EXIT=1: restoring reckon/budget.py's base content in a scratch copy makes the width test name it again at 56,488.

Two gate test files outside the fenced five patched reckon.budget._account_surface_readings, the module that looked that helper up while pace_row lived there. They are repointed at reckon.pace_report, where pace_row now resolves it; the fixtures and assertions are untouched. The four picker test files were left alone; all four pass unchanged.
