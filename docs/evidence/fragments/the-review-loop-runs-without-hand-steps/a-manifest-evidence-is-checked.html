A manifest's evidence is checked

audit_manifest (reckon/crew/reports.py) gains two findings. Each file named in test_logs must carry its literal command near its head — judged by promotion's own gate_command_prose, so an abbreviation like <five tests> is refused identically at either surface — and must end with an EXIT=<n> line read through _terminal_exit_status. Added comment or docstring lines in production Python source that cite a plan section (§ plus a digit) are refused, naming the file and line; test source and string literals are exempt, and an unarmed check — no resolvable base, no repository — refuses nothing. Both are entries on audit_manifest's existing finding list: no new refusal family, no new option.
