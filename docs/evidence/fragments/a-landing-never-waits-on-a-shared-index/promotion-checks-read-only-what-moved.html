Summary

The figure-twin check now reads the commits a run cites rather than every path that appeared between its base and the head. On a checkout of 5,000 tracked files the check issues one diff-tree per cited commit and one cat-file per candidate SVG, and names no path outside those commits.

Measure

  • Fixture: a promotion over 2,000 ledger rows and a checkout of 5,000 tracked files.
  • Ledger loader: called once (ledger.load_open counted).
  • Figure-twin check: the twin is refused, and the git calls it issues are commit-scoped; the base-to-head diff --name-only and the ls-tree -r --name-only HEAD are gone.
  • Negative control: restoring the base-to-head check makes the run-commit test fail, naming those two calls.

Remaining

Two whole-tree reads survive in a promotion from modules outside this node's write scope: _uncommitted_paths in promotion_evidence.py (a --no-commit promotion) and the worktree audit's snapshot in promotion_records.py. They are recorded in the node's manifest under outside_scope.
