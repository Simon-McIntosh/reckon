A promoted landing survives a pointer that moved again

A crew complete --land that cannot remove its live pointer marks the pointer and leaves the merge to the landing pass. That pass read the mark as its only evidence that a landing was owed, so when a resumed attempt rewrote the pointer and dropped the mark it did nothing at all: the ledger row read landed, the reviewed head was on no branch, and the pointer stayed held.

The pass now takes the pending record's own pointer snapshot as the promotion's claim that it owed a merge, and finishes the landing whenever the promoted row's reviewed head is off the branch. A record written without a pointer snapshot still leaves a live unmarked pointer to its own attempt, which is the boundary the existing guard exists for.
