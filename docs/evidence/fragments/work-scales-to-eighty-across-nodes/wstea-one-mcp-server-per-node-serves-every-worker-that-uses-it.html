One MCP server per node serves every worker that uses it

Mechanism

A flight may declare a server under shared_mcp_servers, keyed by the name a node names in its MCP set. The first launch on a node starts the server on the MCP network transport and publishes its endpoint in a node-local runtime record, holding an exclusive lock for the server's lifetime. A later launch on that node finds the record and hands its worker the endpoint as an HTTP server declaration instead of a command, so the worker connects to the node's one process. A server the node cannot bring up leaves the worker with the stdio declaration its set already resolved, so a node-side fault degrades isolation rather than removing tools. The shipped flight defaults declare the reckon server shared.
