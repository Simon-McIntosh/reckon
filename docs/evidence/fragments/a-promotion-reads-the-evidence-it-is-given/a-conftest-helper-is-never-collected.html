A conftest helper is never collected as a test

What changed. tests/conftest.py defined test_temp_config_home, a helper that other test modules import, under a name pytest collects. Collection therefore took it for a test and errored at setup on its prefix parameter, which pytest tests/conftest.py reported as ERROR tests/conftest.py::test_temp_config_home. The helper is renamed make_temp_config_home and its three callers (tests/test_watch_arming_isolation.py, tests/test_budget_group_declaration.py, tests/test_bookend_reserve_by_group.py) use the new name. The noqa: PT028 the old signature carried existed only to excuse the collected name and is dropped with it. The conftest stays in the armed command, so its genuine test, test_shared_home_fixture_never_targets_the_real_store, keeps running.

The guard. A new test, tests/test_a_conftest_helper_is_never_collected.py, runs pytest in a subprocess and asserts two facts against its real output: the collected node ids from --collect-only tests/conftest.py include the genuine guard test and contain no helper, and a plain run of tests/conftest.py reports no ERROR.

Measured

Base arm at 3118c2969a, resolved over its own tree (the new test file is absent there and so is dropped from the command): 25 passed, 1 error, the error being tests/conftest.py::test_temp_config_home. After arm over the same four files plus the new test: 27 passed, exit 0. The delta is the error id removed and no new failure.

Negative control. Restoring the test_ name on the helper makes both cases in the new test fail: 2 failed, with the subprocess output recording ERROR tests/conftest.py::test_temp_config_home and fixture 'prefix' not found.

Ruff by delta. The staged paths carry one finding before and after — the pre-existing F841 at tests/conftest.py:1057, which this section leaves untouched. No finding is added, and the dropped noqa: PT028 is not missed because the renamed signature is no longer collected.
