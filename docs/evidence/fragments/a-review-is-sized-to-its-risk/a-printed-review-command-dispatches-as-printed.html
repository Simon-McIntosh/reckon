a-printed-review-command-dispatches-as-printed — every printed run-review command dispatches as printed

A run review's brief is a composition keyed on the reviewed run, but only the dispatch that launched the review wrote it. The readers that print the review command — the review-missing obligation, the classifier's next_action, and dispatch's unreconciled-runs refusal — name the path without writing it, so a command retyped verbatim was refused the brief ... is not readable whenever no reflex had composed one, and after the reviewed head moved it digested a stale review-brief.md naming the superseded revision.

materialize_run_review_brief composes the brief from the reviewed run's record when the named path is that run's own review-brief.md; _brief_digest calls it before taking the digest, so dispatch composes the text itself — naming the head the run's tree carries now — and every other brief (a coordinator's, a plan review's, a review run's stored copy) is left untouched. No CLI option was added; the read path still writes nothing.

Measure. In tests/test_a_review_receives_its_rubric.py, for each of the three run shapes the printed command — built with no prior composition — is accepted by crew dispatch --dry-run, the reviewed run's directory holds no review-brief.md after the read, and a case moves the reviewed head and asserts the dispatched brief names the new head.
