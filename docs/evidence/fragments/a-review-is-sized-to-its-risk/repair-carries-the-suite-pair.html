What changed

All of the change is in reckon/crew/recovery.py. _reviewed_run_suite_command returns the reviewed pointer's own suite_command or, when that is empty, the argument vector of the project's standing review.suite declaration joined into the same string form a recorded suite command carries.

_config_carrying_suite returns a copy of the resolved flight config whose gates.suite_command names that value, leaving the caller's mapping untouched. dispatch_repair_for_run hands that config to the launch, which is where dispatch reads the command it records on the repair's pointer.

Evidence
