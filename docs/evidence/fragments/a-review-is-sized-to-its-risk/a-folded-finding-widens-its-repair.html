a-folded-finding-widens-its-repair — a folded review finding lets its run's fence widen

crew widen refused a run whose manifest reads complete, on the reasoning that a finished run has no scope decision outstanding. A review that read the run can leave exactly such a decision: a dimension scored below its declared floor, disposed as folded back into the run's own node. The repair resume is the only moment to grant the wider fence — after it the run reads working and a widening refuses a live worker — so the repair ran outside its fence and the path could only be accepted at promotion, after the work was done and reviewed against a scope that never named it.

_widen_folded_disposition reads the run's own review record and returns the dimension whose entry is of kind folded and names the run's own node id, or None. That read admits the complete refusal only, and only for a fold naming this run's node; a failed run, a fold naming another node, and a fold over a worker that is still running are all refused as before. The grant is recorded in the command's reply under folded_disposition, naming the dimension and the node, so the widening names the finding that needed it. No field was added to the live pointer, so the session id, the recorded commits and the worktree are carried through unchanged.
