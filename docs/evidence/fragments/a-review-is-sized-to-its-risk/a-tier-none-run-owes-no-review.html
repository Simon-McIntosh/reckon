a-tier-none-run-owes-no-review — a tier-none run owes no review duty

The review sweep reads a run's tier through promotion's resolver and skips the review of a run that changes no runtime source, recording the skip on the run's pointer. The coordinator's obligations view read the tier not at all, so it held such a run at review-missing with the review dispatch as its next action — a duty nothing could ever satisfy, which the coordinator could clear only by running a review the tier rule had exempted or by acknowledging the duty by hand.

_review_duty_item (reckon/crew/obligations.py) now reads the tier through reckon.crew.recovery._sweep_review_tier, the very resolver the sweep uses, so the two surfaces cannot disagree about which run owes a review and the tier's inputs — changed paths, changed lines, spec level, capability risk — are never re-derived in the duty. A tier-none run reads the kind a reviewed run with a passing review would get, carrying its tier on the duty, and stays in the list rather than falling out of it. A run whose tier requires a review keeps today's reading.

Measure. In tests/test_a_tier_none_run_owes_no_review.py a temporary crew home holds a documentation run and a runtime-source run, both live and both classified scoring (whose unqualified reading is review-missing). The documentation run's obligation is present with kind review-ready and review_tier: none; the runtime-source run still reads review-missing in the same pass, so the quietening is keyed on the tier and not on something the read did to every run. Gate: 1 passed, EXIT=0. Negative control — the tier read removed from the duty — fails that test with assert 'review-missing' == 'review-ready', EXIT=1. Ruff check adds no finding; ruff format adds none beyond the one pre-existing unformatted line already present at base.

Blocker. Two pre-existing cases in tests/test_crew_obligations.py — out of this node's write scope — build runs that declare only seed.txt, no runtime source, so §10's tier read correctly flips them from review-missing to review-ready: test_obligations_reads_scoring_without_observing_or_dispatching and test_a_review_of_an_earlier_head_is_still_missing. Base passes that file (9 passed, EXIT=0); the change makes it 2 failed, 7 passed. Their fixtures need a runtime-source path (and a matching commit) to keep asserting the unreviewed reading, which requires a write scope this node was not granted.
