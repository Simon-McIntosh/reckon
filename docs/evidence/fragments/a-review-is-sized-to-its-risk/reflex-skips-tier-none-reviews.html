The review reflex dispatches no review for a tier-none run

A scoring run that changes no runtime source — documents, evidence, research data, figures — is landed by promotion with the review gate standing down, and the tier none is recorded on the ledger row as the reason no review exists. The reflex in reckon.crew.recovery.dispatch_awaiting_reviews did not consult that tier: it composed and launched a review for every scoring run, spending a member and a lane on a diff no reviewer was owed.

The change

  • reckon/crew/recovery.py resolves each scoring candidate's tier through reckon.review_tiers.review_tier — the same resolver promotion calls, on the same four inputs — and skips the review dispatch for a run whose tier is none, recording the skip on the run's pointer (review_dispatch.status = "skipped") rather than leaving a silent absence. A scope that cannot be measured is read as the fuller tier, so a run whose change is unreadable is still reviewed.
  • tests/test_reflex_skips_tier_none_reviews.py drives the sweep with the dispatch stubbed for a docs-only implement run and a run changing reckon/ source, asserting the documentation run composes no review while the source run is still dispatched in the same sweep.

Gate

Two files, run in the node's worktree: tests/test_reflex_skips_tier_none_reviews.py and tests/test_review_role_is_not_reviewed.py — 8 passed, EXIT=0. The module under test resolved to this worktree's own reckon/crew/recovery.py. Verifying the merged result belongs to a separately dispatched test node; this gate measures only this node's own change.

Negative control

Declared mutation — remove the tier check from the sweep — applied in place and the new case run against it. The sweep then composed a review for the docs-only run and the no-review assertion failed (AssertionError: ['r-docs-only', 'r-source'], EXIT=1). The check is load-bearing: it fails on the mutation and passes without it. The mutation was reverted before commit.
