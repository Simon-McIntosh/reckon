§2 — The tier gate's suite fallout, reconciled

The review tier is decided at completion from what a run actually changed, so a run that touches no runtime source promotes with no stored review. Seven tests outside the fourteen review and promotion files the gate's own node was checked against promoted report-only or non-runtime runs through the retired role rule, and were turned red when the gate began reading the tier instead. Each is reconciled with the tier contract: no assertion is deleted and none is weakened.

The mechanism the reconciliation turns on is the empty-scope boundary. A run that cites no commit has only its manifest's changed_paths to measure, and a manifest that declares no path — a bare none or an empty list — is read as silence about what changed, not as the claim that nothing changed. Silence is granted the fuller review, so a report-only run declaring an empty scope is refused for a review it does not owe. Naming the artefact the run delivered, outside the repository, measures a scope that holds no runtime source and resolves the run to the tier that owes no review.
