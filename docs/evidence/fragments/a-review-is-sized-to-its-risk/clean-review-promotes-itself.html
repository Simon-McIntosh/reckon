A clean review promotes itself

The reflex sweep gained an accepting branch beside the promotion refusal that stops a run landing without a review: a promotable run whose stored review reaches the acceptance floor with no finding has its recorded gate confirmed and re-run at the merged head, and on both passing is promoted with promoted_by: review-acceptance on the ledger row. Acceptance never merges: it requires every commit the manifest names to be an ancestor of the branch the checkout carries, and an unmerged run stands down naming the commits it found off the branch.

Gate

Four named tests in tests/test_review_acceptance_promotes.py, run in a synthesised repository: a clean run promotes from the sweep with no coordinator command; a review carrying one finding does not promote; a gate failing at the merged head does not promote; and a run whose commit is not on the branch is not promoted. ledger.py declares promoted_by in RECORD_FIELDS and emits it on every row (null when absent).
