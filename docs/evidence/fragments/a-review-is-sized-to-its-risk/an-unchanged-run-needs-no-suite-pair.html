an-unchanged-run-needs-no-suite-pair — an armed run that changed nothing promotes without a suite pair

An armed promotion required a complete baseline_suite and after_suite pair so it could measure the delta between them. A run that changed nothing has no delta for a pair to measure, so the requirement refused exactly the run whose own tree proves it is unchanged: a decline-only repair that answered every finding in prose, or a report-only node that cited no commit, had no baseline to record and was turned away with missing baseline_suite, after_suite.

reckon/crew/promotion.py now exempts that run. _evaluate_suite_delta returns a delta of status: "unchanged" with the suite_command, added_failure_ids: [] and a reason, in place of the missing-suite refusal, when _run_changed_nothing holds. The predicate reads the run's own declarations and then the worktree, which cannot be spoofed: the fresh manifest must claim no changed path and name no commit other than the base the run was dispatched against (_manifest_declares_no_change), and, when the worktree still exists, its HEAD must equal the recorded base with no tracked file modified against it (_worktree_unchanged_since_base). A run whose head moved past its base, or whose manifest names a changed path or a commit past the base, is refused exactly as before. reckon/ledger.py counts the new status beside clean, refused and waived in its suite-delta tally.

Measure. tests/test_an_unchanged_run_needs_no_suite_pair.py passes 3/3: a decline-only armed run with a suite_command and no suite fields promotes with suite_delta status unchanged; a run with one commit past its base and no suite fields is still refused with missing baseline_suite, after_suite; and a run whose empty manifest is contradicted by a worktree whose head moved is still refused. The gate ran only the named file, no call reached SLURM.

Negative control. Against a scratch copy of the tree with the unchanged-run exemption removed, the decline-only case fails with missing baseline_suite, after_suite (module under test resolved to the scratch promotion.py, confirmed on the log's header). The red log is negctl-unchanged-run-exemption-removed.log under the run directory, its first line the declared mutation: remove the unchanged-run exemption; the decline-only case must fail with the missing-suite refusal.

Scope. The required ledger tally change adds an unchanged key to the always-present suite-delta dict, which the pinned exact-dict assertion in tests/test_ledger.py::test_ledger_summary_counts_suite_delta_outcomes then contradicted; that one-line assertion was updated in the same commit so the tally change lands without a failure on the wider suite. No other file outside the node's fence was touched.
