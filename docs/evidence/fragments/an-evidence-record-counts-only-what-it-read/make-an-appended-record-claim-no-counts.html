make-an-appended-record-claim-no-counts — a record an append creates states no counts and no verdict

_render_document in reckon/evidence.py gains a created_by_append parameter. When it is set, the head and body summary read Landing record for <plan title>: evidence appended by section. and the plan-verdict meta is omitted; every other meta the renderer writes is unchanged, including reckon-type evidence and plan-evidence-for. The one caller that needs it, _landed_record_shell in reckon/_store.py, passes it. That shell is the empty frame append_evidence creates when no record exists, and it has read no ledger and no plan comments, so it can no longer publish “0 committed run(s), 0 section-anchored comment(s), and 0 landed commit(s)” over sections that later land in it. A synthesis, which reads both, still writes the count sentence and the verdict exactly as before.
