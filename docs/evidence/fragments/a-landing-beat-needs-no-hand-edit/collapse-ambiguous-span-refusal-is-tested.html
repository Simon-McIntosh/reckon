§3 — collapse_section refuses a card span it cannot delimit unambiguously

tests/test_edit_plan_collapse_section.py gains two cases, one per ambiguity check in _landed_card_span. test_a_span_reaching_a_second_heading_is_refused_and_leaves_the_file_unchanged splices a bare second <h2> into a collapsed section's card span, away from any structural boundary, so it trips only the second-heading check. test_a_span_reaching_a_structured_region_is_refused_and_leaves_the_file_unchanged splices an empty <section data-reckon="evidence"> into the span, so it trips only the boundary check and carries no second heading. Both collapse a plan synthesised under a temporary directory, then assert collapse_section returns op_error whose detail names the reason (cannot determine the extent of 's2' unambiguously) and that the file is byte-identical afterwards. The two checks share one message, so neither assertion tells them apart. The gate ran 31 tests across tests/test_edit_plan_collapse_section.py, tests/test_edit_plan_append_evidence.py and tests/test_edit_plan_section_writes.py — zero added failures by id over the 29-test base arm — and two mutations were run against them. Deleting only the second-heading check turns the heading case red while the region case stays green; deleting only the boundary check turns the region case red while the heading case stays green. No production code changed.
