The stop hook reads the session snapshot, and a lane-refused review reads queued

The stop path now decides from the same published snapshot as the prompt path: a fresh snapshot blocks exactly when it lists outstanding obligations, and a not-fresh one — no producer, a producer on older code, or a stale snapshot — sends the hook to the derivation, imported lazily and run under a 5 s budget that a test overrides through RECKON_STOP_DERIVATION_BUDGET_SECONDS. When the budget runs out the stop is allowed with one line naming the not-fresh reason, so no producer state can trap a coordinator. A review whose dispatch the lane refused as lane-paused, read from the attempt record the reflex writes and within half an hour of the refusal, now reads review-queued: it names the refusal instant and the session's published worker slots, is listed on the prompt path, and does not hold the stop open; past the bound it reads review-missing again and blocks.
