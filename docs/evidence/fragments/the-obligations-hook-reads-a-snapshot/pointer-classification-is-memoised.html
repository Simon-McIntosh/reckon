Pointer classification is memoised

Status: partial. The mechanism is implemented and committed; the node's gate was not completed inside its time fence, so the figures below are the base arm only.

recovery.classify_pointer now resolves its expensive reads through a memo persisted beside the pointer, live/<run-id>.classification.json, keyed by the stat identity of every file the classification reads: the pointer, the manifest, the stream the observation consumes, the run directory's own exit.json, worker.json and attempt.json, and the review store's candidates for the run. A key that still matches serves the memo — the manifest text, the stored review and the stream's budget block. A key that has moved recomputes, and a stale reading is never served.

Stream observation resumes from a byte offset persisted in the same memo. _backends.observe_log accepts a resume state and reads only the records written past its offset, and both dialects' event folds now take and return their state, as does the timestamp split that refines throughput. A fold resumed from state produces the observation the whole stream would.
