The session-end reap signals a producer whose test tree was pruned

preserve_seat_records in tests/conftest.py copies every seat record into <basetemp>/_seat-records so the session-end reap (reaped_watch_producers) can still find a producer after a passing test's tree has been pruned. The copy could never be signalled: reapable_watch_pids binds a record to a producer by comparing the home derived from the record's own directory (directory.parent.parent) against the RECKON_HOME in the producer's /proc/<pid>/environ, and a mirrored record's derived home sits under _seat-records/ while the live producer names its original home. Only the per-test reap, reading originals before the prune, ever signalled; the session-end reap reached nothing but its /proc leak scan, which fails the session instead of reaping. A second gap compounded it: _set_aside_seat_record_mirror deleted the previous aside before renaming the current mirror, so the mirror restored for the session end held only the last test's records.

A mirrored record now carries the home it was written under (preserve_seat_records writes a home field into each copy), and watcher_record_pids reads the home off the record, falling back to the directory only for an original record that carries none. The set-aside merges each cycle's mirror into the existing aside instead of replacing it, so records whose original trees the prune has removed survive to the session-end reap.

Measure. tests/test_the_session_reap_signals_a_pruned_producer.py starts a stub producer whose RECKON_HOME lies in a tree pruned after the mirror is taken, sets the mirror aside and restores it the way the session fixtures do, and asserts the pid appears in the list the session-end reap signals (reapable_watch_pids) and ends by that SIGTERM; a second case prunes the first cycle's home before a second cycle arms and asserts both cycles' records survive.
