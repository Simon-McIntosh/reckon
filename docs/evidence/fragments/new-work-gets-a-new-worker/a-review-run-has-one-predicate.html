One review predicate, and each review keyed by what it reviews

What changed. The second copy of the review predicate is gone. reckon/crew/dispatch_sessions.py no longer defines _is_review_run; _task_identity imports the owner, reckon.crew.recovery._is_review_run, inside the function, because recovery loads modules that import from dispatch_sessions. The old copy read the role from the record root alone, so a record whose review role sat only on its node was a review to recovery but not to dispatch, and its task keyed as a plain node. The re-export at reckon/crew/dispatch.py is removed and its one reader imports the owner directly.

The second defect, and its fix. The review branch of _task_identity stripped only REVIEW_NODE_PREFIX (review-of-), but plan reviews are minted plan-review-of-<slug>. Their source came out empty, so every plan review in a project keyed ("review", project, "") — one shared key across every plan. A run whose node id starts with PLAN_REVIEW_NODE_PREFIX now keys ("plan-review", project, <slug>), the slug taken from round_node_source(node_id, PLAN_REVIEW_NODE_PREFIX). A review whose reviewed run cannot be resolved from its node id keys by its own node id, ("review", project, node_id), never by an empty string.

Measured. The defect reproduces at the base before the repair: a node-only review role reads False to dispatch against recovery's True and keys ("node", "reckon", "", "implement-fixture"), while plan-review-of-alpha and plan-review-of-beta both key ("review", "reckon", ""). At the head the same records key ("review", "reckon", "implement-fixture"), ("plan-review", "reckon", "alpha") and ("plan-review", "reckon", "beta"). The gate tests/test_plan_review_prefix_is_one_constant.py, tests/test_a_resumed_head_is_reviewed.py, tests/test_session_resumes_only_its_own_task.py and tests/test_dispatch_reads_the_resolved_session.py is 31 passed, EXIT=0 at the head against 25 passed, EXIT=0 at the base — the six non-failing tests are the new whole-key cases, and no failure is added against the base.
