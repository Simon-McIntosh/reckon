A run review is delivered only by its own record of the head it read

_delivered_review_record accepts a record as a run review's delivery only when all four hold: the record sits at the head-keyed path the review's dispatch declared, the head it describes is that head, compared with review_described_head and same_revision; its review_run_id, when it carries one, names this review run; and its mtime is after this node's dispatch instant, read with run_record_times and falling back to the stamp the run id encodes. The legacy unsuffixed path and the any-head glob no longer count at all. A run review declaring no head-keyed path is refused by promote_review_run_itself with a reason naming the missing head; plan reviews are untouched. Delivery is decided in that one function, so every reader that asks whether a review has delivered reads this answer rather than restating the conditions; the watcher adds one refusal this function cannot express, that of naming an unnamed head. The run-versus-plan review distinction is read from _is_run_review_node in recovery_review_subject.py, beside the broader _is_review_node it narrows, so one module owns the rule.

The new tests/test_a_review_promotes_only_its_own_verdict.py fixes the four refusals and the delivery they guard: a predecessor round's complete record at the legacy path is no delivery, and the run's own record at the head-keyed path both reads as delivered and promotes on its ledger row with reviewed_head_sha equal to the dispatched head and the round's total; a record at the head-keyed path describing another head, naming another review run, or written before dispatch is no delivery; and a review declaring only the legacy path is refused naming the head. Six further test files move the round they deliver to the head-keyed path of the head its review is dispatched to read, each keeping what it asserts: a delivered review ending its turn, a review run promoting itself, a run review carrying no run id of its own, a review run's outcome defaulting to its stored review, and a promotion committing an unnamed round under its derived legacy id.
