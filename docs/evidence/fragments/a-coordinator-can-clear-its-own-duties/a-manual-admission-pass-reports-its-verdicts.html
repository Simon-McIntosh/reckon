A manual admission pass reports its verdicts

What changed. The bare reckon crew admit verb is the fleet's admit service: it repeated its pass on a cadence and discarded each pass's result after recording it, so a coordinator running it by hand saw nothing and could not tell a working loop from a waiting one. The loop now publishes every pass as one JSON line on stdout — the same record admission-verdicts.jsonl holds for that pass.

  • reckon/crew/queue_admission.py — _pass_verdict_record builds the pass's record once, so the published line and the logged line are the same object and cannot drift; _record_pass_verdicts writes it through the crew-home log as before and returns it; _publish_pass_verdicts prints it as one JSON line from admit_until_stopped. A pass that examined no queued pointer still prints nothing, which is the silence it also records. --once is untouched: it returns its pass to the verb, which reports it as before.
  • reckon/crew_run_commands.py — the crew admit help now names the loop (the bare form repeats the pass until stopped and prints each pass's verdicts), the single manual pass (--once), and how long one pass may take: it is bounded by the lane and fleet gate reads it makes, each under a five-second deadline. The incident behind this section was a manual run that emitted nothing for five minutes and died on timeout 300, so the help now says plainly which form returns and that a caller wanting one uses --once rather than a timeout around the service loop.

Measure. tests/test_a_manual_admission_pass_reports_its_verdicts.py, three cases over a temporary crew home and a real checkout the shared dispatch path launches into. The bare verb is driven for two passes over two queued requests: the first pass has no room, so both are held for their session's allowance; the second has room for both, and the shared dispatch path launches one and refuses the other on scope against a live run that already holds the path it claims. Each pass prints one line naming both requests, the printed lines are asserted equal to the log's own rows for the same passes, and the refused row carries the refusal's detail — the class, the holder's run id and the contested path. The second case shows --once still answers with its single pass's result and no loop line; the third reads crew admit --help for the loop, the single pass and the pass bound.
