an-exclusion-is-not-a-fit-input — an exclusion clause charges nothing, a declaration still charges

A brief that keeps a worker off a large file by naming it in an exclusion (Exclude package/large.py from declared inputs) carries the same “declared input” keywords a read declaration does, so the fit estimator read the exclusion as a declaration and charged the excluded file at full size — the refusal the plan records, a done-when naming eleven peer-held paths refused at 232,650 tokens against a 172,800 window for source the node would never open. Reproduced at base 626dcd594 with the census probe's own fixture (package/large.py 200,007 bytes, package/target.py 10 bytes): plain-exclusion: tokens=3 named_count=0, declared-input-exclusion: tokens=57148 named_count=1 named_counted=[True], positive-input: tokens=57148 named_count=1 named_counted=[True].
