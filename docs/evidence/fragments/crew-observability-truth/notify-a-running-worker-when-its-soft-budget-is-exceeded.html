A run past its soft budget is messaged, and nothing signals it

The overrun was computed exactly and delivered to nobody. The watch producer now measures every live pointer against its soft limit — 1.5x the declared allowance, denominated in generated tokens when the run declares a token budget and in wall clock otherwise — and, once per run, writes one message into that run's own directory (budget-notice.md) naming the allowance, the elapsed span, the overrun and the measured cause. The message asks for the manifest the worker already holds. Nothing signals the process: the run keeps its process, its phase and its session. Promotion carries the same measurement onto the committed row under budget_overrun, budget_overrun_seconds, budget_overrun_tokens and budget_overrun_notice, so the verdict survives the pointer that promotion deletes — the ledger side of the pair that was absent from all 800 committed rows.
