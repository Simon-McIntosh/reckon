Context-window refusal names the window

A context-window refusal is an exit-5 CompetenceLimit. Its message was rendered through the neutral-hour template, so a token refusal reported a competence horizon of 0.0 worker-hours that nobody measured and advised splitting into zero-hour nodes. CompetenceLimit now chooses its message from the verdict's reason: a token refusal names the estimated tokens, the window, the shortfall and the verdict's own D08 recommendation; an hour refusal keeps its text. with_context_fit no longer writes 0.0 placeholders, so an unmeasured horizon stays absent from the verdict.
