A reload marks the format switch only when the ticker's grid moved

Landed. reckon/cli.py gains _ticker_layout_signature(), a hash of the ticker's fixed grid geometry (the ordered column widths, the gutters and the minimum width). The signature travels to the replacement image on the _tick on-poll payload, so the reload branch compares the departed image's grid with its own and sets both layout_changed and pane_line on the follower-format-changed event: an unchanged grid still reaches the JSON stream but prints no marker and records none, and a changed grid prints exactly one. The producer-reloading note adopts the same pane_line convention already used by the stop and reload-failed lines — inside its window it is JSON-only, and only an overrun emits it with pane_line True once, ahead of the cycle advice.
