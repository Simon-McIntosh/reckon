A sub-floor disposition is written by a command

A coordinator retires a sub-floor review dimension through reckon crew dispose instead of editing the review store by hand. The command writes one entry through record_dimension_disposition, and every refusal is the store's own — so an unknown dimension, a kind outside the closed set, a fold naming no node and an exemption carrying no reason all exit non-zero with nothing written and the obligation row standing.

What landed

  • reckon/cli.py — a crew dispose subcommand taking --project, --run, --dimension, --kind, and whichever of --node / --reason the kind requires. It writes through review.record_dimension_disposition and re-reads the stored record for the receipt, so the reply repeats what the store now holds rather than what the call intended (reckon/cli.py:3793).
  • reckon/crew/review.py — the writer's gate for the closed set is now the reader's own predicate dimension_disposition_valid. A second copy of the vocabulary in the writer could accept a kind the read-back then ignores, which stores a row that reads as answered and stands.
  • reckon/crew/review.py:1166 — the floor comment that described a floor of zero as reporting every dimension now describes what a floor of zero does.
  • tests/test_sub_floor_disposition_has_a_writer.py — 10 cases: the two accepted kinds, five refusals, a hand-planted unknown kind, the shipped floors, and the temporary config home.

The floor comment

A floor of zero reports nothing, because every stored score is at or above zero — so reading an undeclared floor as zero would claim a standard the configuration never declared while changing no verdict. The sentence said the opposite of what the code does:

before: “A floor of zero would report every dimension of every review, so the absence of a declared floor is read as the absence of a standard rather than as a standard of nothing.”

after: “A floor of zero would report nothing, since every stored score is at or above zero — so reading an undeclared floor as zero would claim a standard the configuration never declared while changing no verdict.”

No behaviour changed with the sentence: sub_floor_dimensions already skipped a dimension the map does not name.

The test stands its world up in a temporary config home

The fixture writes mounts, a live pointer, the reviewed run's tree and the stored review under a temporary RECKON_HOME, and patches the derivation's clock. The last case resolves every root the command uses and requires the path it reports inside the temporary home — an absence check against the real home would itself be a read of it.
