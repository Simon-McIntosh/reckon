A wait probe's reference is resolved, not inferred from its characters

At base the proxy accepted the constant. _WAIT_PROBE_EXTERNAL_REFERENCE is the pattern [0-9/$`], and at the base revision the measured facts are: it matches git rev-parse HEAD2, and _wait_probe_cannot_fail(["git","rev-parse","HEAD2"]) returns False — that is, a constant whose only claim to a reference is the digit in its name reads as able to differ (logs/base-proxy-check.log). git rev-parse HEAD was refused by the same reading and HEAD2 was not, so the reading was distinguishing a character and not a reference.

The rule now resolves the reference and names the kind it found. A token counts only when its place in the vector names it as one of the four kinds a wait rests on: a job id or a port from the flag that names it (-j 1271081, -p 2222) or from the operand's place in a command that takes one by position (nc -z a-host 8765); a pid from a numeric operand of a process command (kill -0 <pid>); a path from a token that resolves on the filesystem. Two shapes are read through rather than taken at face value. A shell keeps its program in one token, so bash -lc 'q=$(squeue -h -j 1274028); …' — the spelling the fleet actually declares — is read as the shell vector it is; and a file-test operand is the path being waited for, so test -f DONE stays declarable while the file does not exist yet, which is the whole point of that wait.

The mutation was then reverted and the same gate re-run at 156 passed, 0 failed with git diff empty, so the green head arm is the tree as committed and not a tree still carrying the control.

What the resolution does not decide. A token that resolves on the filesystem counts as a path reference whichever operand it is, the command token included, so an interpreter named by absolute path resolves the probe through its own path — measured on the probe shape the follower tests declare, [sys.executable, "-c", …], which has to stay declarable. A relative path is resolved from the reader's working directory rather than from the declaring worker's worktree, so a path a wait is for belongs in the file-test form, and the refusal message names that form.
