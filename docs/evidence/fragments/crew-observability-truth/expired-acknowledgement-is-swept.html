expired-acknowledgement-is-swept — crew ack names the promoted path, and an expired deferral is swept

The crew ack help and docstring described a live run only, although a promoted run's deferral has been accepted since 6417983b9; the help now says the run may be live or promoted, and the docstring says where each deferral is written. recorded_promoted_acknowledgements also read every file under the crew home's acknowledgements/ directory on each obligations read and removed none once its until had passed, so the directory grew and every expired deferral was parsed on every read. The reader now removes a file whose until has passed as it reads it, judged against the obligations reader's own clock so a sweep never discards a record the reader still withholds a duty for; a deferral whose instant cannot be read is left alone, because a removal has to prove expiry before it acts.
