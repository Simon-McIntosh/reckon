a-wait-ages-on-its-stream — the age follows the stream, and a probe must be able to differ

The followup settled two readings and marked one dead end: a verdict handed out when a declared wait merely carried a probe that runs with a terminal that can be reached. The two observed blocks — ["echo","pending"] and ["git","rev-parse","HEAD"], both against exit:0 — satisfy that falsifier unconditionally, so the repair would have shipped fixing nothing.

The probe is now read for whether its result can differ. A printer or null command is refused outright, because in a shell-free vector it can only write its own arguments; any other probe must name something outside the worker — a job id, a pid, a port or a path (_wait_probe_cannot_fail in reckon/crew/recovery.py). The refusal keeps the declaration, marks it invalid and names the probe: wait_probe ['echo', 'pending'] cannot fail: it names nothing outside the worker — no job id, pid, port or path …, so the shape is repairable from the row and the resume sweep skips it with condition-declaration-invalid instead of lifting a wait nothing ended.
