A failed run costs its own turn

The review pass isolates each pointer's review, acceptance and repair handling. Its report names exceptions under failed with the run id, exception type and message, and missing live pointers under vanished. The review self-promotion branch checks the live pointer before promotion can reconstruct it from durable records. The resume sweep contains unexpected exceptions from its review and plan-review passes separately, so either pass can fail while the other finishes and a report is returned. The station prints station-sweep-run-failure with the project, session, run id and error; its existing whole-session exception diagnostic remains.
