crew watch requests the node station before it takes the producer seat

reckon crew watch now requests the node station through dispatch_watch._ensure_node_station before it claims the producer seat. The call sits after the --ensure branch and before either the following loop or the single-event watch(), so every route that holds the seat passes it. Outside a fleet allocation it is a no-op, and a station already holding the node is left alone.

The station restart test was asserting on stored events before every stream's consumed offset had advanced. The two are written in one tick but not atomically together, so the test read a half-applied tick and failed on the offset assertion. It now waits for both facts — two stored events and every stream offset past its initial value — before asserting either.
