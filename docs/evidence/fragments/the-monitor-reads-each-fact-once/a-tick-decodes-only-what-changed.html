A tick decodes only what changed

The defect. StationStore.tick folds every stream a pointer names, and for each of those streams it asked _pointer_for_stream which pointer owned it. That helper scanned the store's pointer rows and decoded each row's fields document until it reached the row naming the stream, so the tick decoded the whole fleet's fields once per stream, on every tick where any stream had grown — which is every tick of a live fleet. The answer it was buying back — the stream's path, and the backend and dialect to read it in — had been written to that row by the pointer's own ingest, which runs only when the pointer itself moved.

What landed. Those three scalars are now columns on the pointers table, written beside the fields by _write_pointer_row, and _pointer_streams answers both the paths and the scalars in one query that decodes no stored document. The fold takes its record from that pass (ingest_stream(path, record=...)) instead of looking it up per stream. pointer_is_current compares the stored signature as the text it was written as rather than decoding it back into a list, removing the last decode a tick over an unchanged fleet paid per pointer. A store written before the columns existed has them added and backfilled once, at connect, so a store already on disk never pays that decode per tick. _pointer_for_stream survives only as the fallback for a caller folding a stream it holds no pointer for.

At head

The same harness at head 33f28354f7 reports no _pointer_for_stream and no _pointer_streams entry at all. Tick 1 decoded 294,622,004 bytes where base's decoded 372,393,182 — 77.8 MB less — and its largest caller is the one that has to remain: parse_events, reading the streams' own new bytes (131,884,178 of them).

The gate, and what fails at base

tests/test_a_tick_decodes_only_what_changed.py builds a temporary crew home of four pointers, each naming one recorded stream, settles the store with one tick, and then ticks again. Its ledger records the text of every document decoded, so each assertion is against the bytes the tick read rather than against a call count. Over an unchanged fleet the second tick decodes nothing and reads no stream byte; a pointer that moves is decoded exactly once, by its own ingest, and the tick after it decodes nothing; one byte appended to one stream is read once at its offset, with no fold from the start; and a store written in the previous schema still folds a codex run in codex after the backfill. Gate: 4 passed, EXIT=0 (gate-head.log).

The same file against a tree extracted from base 2780ddad, with the file copied in, fails where the test names the defect: 3 failed, 1 passed, EXIT=1 (negative-control-base.log). The three, by name — test_a_tick_over_an_unchanged_fleet_decodes_nothing ("the tick decoded documents nothing had changed"), test_a_tick_over_an_unchanged_fleet_reads_no_pointer_document ("a moved pointer was not decoded exactly once by its own ingest") and test_one_byte_appended_to_one_stream_is_decoded_once ("the tick decoded the fleet's pointer fields for one appended byte") — are each the decode the base tick pays for a change that did not happen. The fourth, the old-schema store, passes at base by construction: the base fold reaches the dialect through fields itself, so a store without the columns still folds correctly there, and that is exactly why the head owes it a backfill. The module the run imported is the base tree's own reckon/crew/station_store.py, named on that log's header.

What this node did not change

The tick still decodes every pointer's fields twice more, once in Station.tick (reckon/crew/station.py, outside this node's write paths) and once in StationStore.classify_tick (in this node's file, but reading it requires the classification inputs to be restructured to accept only the pointers that moved) — 5.2 MB each per tick at head. The classifier's own line scans of stream files (recovery_wait) still read what they did, as does parse_events for the bytes that genuinely arrived. The band this node removed is the one the census named as decodable for no change at all.
