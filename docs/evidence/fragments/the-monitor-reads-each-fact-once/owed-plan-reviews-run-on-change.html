Owed plan reviews run on change

What landed. The sweep no longer runs the owed-plan-review pass every tick. reckon.crew.plan_review now keeps a footprint of what the pass reads — each plan registered for the project with its edit identity, the review store's record count and a digest of its record names, the run store's stamp, the ledger's write generation, and the identity of every live authoring run — and owed_plan_review_pass_due answers on that footprint: the pass is owed when there is no record of a previous pass, when any part of the footprint differs from the record, or when sixty seconds have passed since it. reckon.crew.resumption.sweep consults that answer and calls compose_owed_plan_reviews only when it is due, then records the pass in plan-review-reflex/<project>.pass.json. The record is written after the pass rather than before it, because the pass answers notes into the records it reads and a footprint taken first would make the next sweep run it again.

Why change and interval, not either alone. A footprint alone would starve a pass whose inputs the reader cannot see; the interval alone would spend a full pass every minute on a quiet project. Both are measured below: the quiet sweeps cost one pass, each input that moves costs exactly one more, and the interval costs one pass in between.

Dry runs weigh and record nothing. A preview sweep still composes the reviews a reader asks for, but it writes no pass record, so previewing a project cannot spend the interval a real pass was owed.

The measure

Thirty one-second sweeps over an untouched project run the pass once, on the first, and the other twenty-nine run none.

Each of the three inputs costs exactly one pass when it moves: a plan edited on disk, a review record created in the store, and an authoring run appended to the store. A sweep between two of them runs none, so the change is what the gate answers rather than a pass riding along with the previous one.

With nothing changing, the clock alone asks for one more pass: sweeps one to fifty-nine run none, the sweep at sixty seconds runs exactly one, and the sweep after it runs none again — so the interval costs one pass a minute rather than one a sweep.

The gate is measured against the behaviour it replaces in the same test file: a gated arm and an ungated arm sweep ten times over the same project, and every review the ungated arm composes is composed by the gated arm inside the interval, while the passes the two arms share agree on what they composed and what they skipped, compared after the recorded ages are normalised.
