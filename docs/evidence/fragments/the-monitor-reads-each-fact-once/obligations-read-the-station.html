Obligations read the station

The station now computes each live session's obligations into its node-local store once per change, and the prompt hook reads that answer instead of deriving the fleet on every prompt's opening. An unchanged fleet writes nothing: the payload identity is compared with ages stripped, so a minute passing is not a change, and the export is republished only when a session's document actually moved, at most once every 10 s. A heartbeat frozen at the last write would make a healthy quiet station read as stopped off the node, so the file is also republished when the station's beat has moved and the carried one is 90 s old: above the sixty seconds an unchanged fleet writes nothing in, and well below the 120 s stale window, so a live beat never reaches it while a stopped station moves no beat and is still left to age into a stale reading. Off the node the hook reads the exported snapshot and judges it by the station's heartbeat, reporting the snapshot stale with its age past the 120 s window rather than serving a stale list as current. The hook's answer from the station equals the derivation on a fixture fleet; a stale station heartbeat is reported with its age; an unchanged fleet writes no new snapshot over 60 s. The crew read view answers in the same order, so the two surfaces report one session's duties from one computation.

The crew view obligations half of the section is wired in the same order as the hook: the view in reckon/mcp_views.py answers from obligation_snapshot.read_station_answer(project, session) when the station holds a fresh answer for that session, and falls back to obligations_module.obligations(...) otherwise, projecting both sources through the same field filter so a narrowed read means the same thing whichever served it. A station whose heartbeat has stopped falls back to the derivation here rather than passing its last answer off as current, because the view's payload shape carries no field to report an age in. Three negative controls now stand behind the evidence: dropping the export's change check fails only the no-write case, making the view always derive fails only the view case, and stopping the export consulting the carried heartbeat fails only the heartbeat case.
