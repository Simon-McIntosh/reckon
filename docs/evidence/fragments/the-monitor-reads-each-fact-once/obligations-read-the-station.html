Obligations read the station

The station now computes each live session's obligations into its node-local store once per change, and the prompt hook reads that answer instead of deriving the fleet on every prompt's opening. An unchanged fleet writes nothing: the payload identity is compared with ages stripped, so a minute passing is not a change, and the export is republished only when a session's document actually moved, at most once every 10 s. Off the node the hook reads the exported snapshot and judges it by the station's heartbeat, reporting the snapshot stale with its age past the 120 s window rather than serving a stale list as current. The hook's answer from the station equals the derivation on a fixture fleet; a stale station heartbeat is reported with its age; an unchanged fleet writes no new snapshot over 60 s.
