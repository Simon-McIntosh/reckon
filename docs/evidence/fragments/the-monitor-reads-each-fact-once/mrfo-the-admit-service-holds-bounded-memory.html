The admit service's memory stays bounded

A pass decodes every live pointer and the run documents behind it, then frees them. The allocator keeps the emptied arenas for the next request, so the service's resident set tracked the reported defect: 22.1 GB resident after three hours and thirty-two minutes. The service now hands a pass's freed pages back after every pass and drops the process-wide parse memo when its reading is still above the stated bound of 2 GB.
