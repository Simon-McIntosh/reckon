The arm that decides a sweep is due now beats off the tick

The defect. The station ran the review reflex inside its own tick. Every sweep that reviews a delivered run was requested from the tick body, so a tick that spent minutes in its per-project-refresh stage armed no sweep for the whole of that stage, and a run delivered while the stage ran was reviewed only after it finished. The reflex's window is two minutes, so the stage alone was enough to miss it, and the coordinator saw the miss as an overdue review with nothing naming the cause.

What landed. reckon/crew/station.py gains ReflexBeat: a daemon thread started beside the heartbeat and the lease renewal, which reads the live pointers on its own cadence (REFLEX_BEAT_SECONDS, 30 s), groups them by project and requests a sweep per session. It detects movement from a cheap signature over each pointer — its run id, its phase, and the identity of its manifest file (mtime and size) — so a delivery is seen on the next beat rather than on the next tick, and an unchanged fleet requests nothing. Station constructs it with the clock and cadence the station already uses, and run_station starts it with the other threads and stops it in the same finally. The tick keeps its own sweep request, so the cadence a tick previously supplied still holds when the arm is quiet.

What an overdue duty says. reckon/crew/obligations.py reads the station's own tick papertrail (obligation_snapshot.read_station_answer) when a review duty is past the window, and when a tick has been held in one stage for longer than that window it names the stage, how long the tick has run there, and the command that dispatches the review. Past the window with no held stage it keeps the earlier wording. The inspect the follower instruction is gone from the held case, because the coordinator cannot act on it: the pointer it was told to inspect carried no stage and no age.

Gate. tests/test_a_slow_refresh_does_not_hold_the_review_reflex.py runs the station through run_station with one tick, the entry point a real station takes, so the arm that decides a sweep is due is started and stopped by production code and not by the case. It parks that tick in its refresh stage with a gate the case controls, delivers a run into a temporary crew home while the tick is parked, and asserts the reflex reaches that run's review dispatch inside the window with the tick still unfinished. The second case builds a delivered run, writes a station store whose tick has sat 185 s in per-project-refresh, and asserts the overdue duty names that stage, its age (3m 5s) and the dispatch command, and no longer says inspect the follower.
