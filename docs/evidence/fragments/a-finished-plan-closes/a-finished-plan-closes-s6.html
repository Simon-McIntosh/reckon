The instrument and its control

The census reads the roadmap's own row rather than re-parsing declarations: pending_work[].readiness, progress_pct, closure_blockers and deferred_remainder — the §2, §4 and §5 payload. Each row is classified by one function into violation, stated, blocked-on-finished-gate, or not-finished (terminal, deferred or incomplete). The script is embedded in this record below, so the measure is reproducible from the repository: extract the pre block to a file and run it with the revision's tree on PYTHONPATH.

The classifier's control is five constructed rows, run as --self-check: a closable plan with only the close op reads violation; the same plan holding a plan-terminal gate with a measure reads stated; a deferred-only plan, a shipped plan and a live plan still admitting work read not-finished; a finished plan reading blocked on a gate reads blocked-on-finished-gate. All five matched, so the predicate both fires on the defect and stays silent on the three acceptable shapes. The live corpus exercises the same discrimination on real rows: open-work-is-capped is the passing stated case, and 27 deferred-only and 182 still holds are excluded.

The persisted self-check log reads ok closable-unclosed, ok stated-open, ok deferred-only, ok closed, ok blocked-on-finished-gate and exits 0. It is not green by default: disabling the blocked-on-finished-gate branch of classify() and re-running the same five rows reddens that row (want=blocked-on-finished-gate got=violation) and exits 1.

The control arm the measure requires is a census run at the base revision 893e18cc82. It was run from a git archive of that revision rather than from the worktree, and reads the same live mounts as the head arm. Its summary line reads mounts=19 plans_scanned=226 and finished_open=18 violations=17 stated=1 blocked_on_finished_gate=0 errors=0, with terminal=0 deferred=27 incomplete=181 excluded. It differs from the head arm's first reading by one mount and one plan (nova:separatrix-spline-extraction, four followups and the close op), because a mount was added to the mount set between the two runs and the plan finished in between, and the census scans mounted plan documents, not their history. That agreement is what a control over a docs-only change should show: the classifier's verdict does not depend on the revision it runs from. §1's 21-plan reading is a measurement of live state and cannot be re-created from a commit, so neither arm reproduces that historical figure; both report the corpus as it stands at run time.

The census script

The committed instrument, verbatim. Save the block to census_closable.py and run it with the target revision's tree on PYTHONPATH and as the working directory: PYTHONPATH=<tree> python census_closable.py for the census, or --self-check for the five-row classifier control. The output path is set at the top of the script. 

"""Re-run the finished-plan census with the closable readiness.

Two questions, both across every mounted project:

  A. Is any plan at 100 % that is neither closed nor holding a plan-terminal
     gate whose measure states why it stays open? A plan whose only open
     sections are deferred is visibly not at 100 % — the deferred remainder is
     the surface's own label — so it is not counted here.
  B. Does any plan read ``blocked`` on a gate whose every gated section is
     resolved, i.e. a gate over finished work holding the plan?
"""

from __future__ import annotations

import json
import sys
from pathlib import Path

sys.path.insert(0, str(Path.cwd()))

from reckon import metadata_index  # noqa: E402
from reckon.doccheck import _load_mounts  # noqa: E402
from reckon.lifecycle import TERMINAL_STATUSES  # noqa: E402
from reckon.mcp import _roadmap  # noqa: E402

OUT = Path(
    "/home/ITER/mcintos/.config/reckon/crew/runs/"
    "r-20261123T163803959609-a-finished-plan-closes-s6/census-out/census.json")


def _plan_terminal_gates(blockers):
    return [
        b
        for b in blockers
        if b.get("kind") == "gate"
        and str(b.get("transition") or "plan-terminal") == "plan-terminal"
        and str(b.get("measure") or "").strip() and "resolve" not in (b.get("ops") or [])
    ]


def classify(plan: dict) -> dict:
    """Classify one roadmap row against the section's two census questions.

    Returns a dict with ``kind`` taken from ``not-finished``, ``violation``,
    ``stated`` or ``blocked-on-finished-gate``, so a caller counts and names
    the rows without re-deriving the predicate.
    """

    status = str(plan.get("status") or "").strip().lower()
    if status in TERMINAL_STATUSES:
        return {"kind": "not-finished", "reason": "terminal"}
    readiness = str(plan.get("readiness") or "")
    pc = plan.get("progress_pct")
    deferred = plan.get("deferred_remainder")
    blockers = plan.get("closure_blockers") or []
    is_finished = deferred is None and pc == 100.0
    if is_finished and readiness == "blocked":
        return {
            "kind": "blocked-on-finished-gate",
            "project": plan.get("project"),
            "slug": plan.get("slug"),
            "gates": [
                {"id": g.get("id"), "gated_sections": g.get("gated_sections")}
                for g in (
                    *(plan.get("gate_blockers") or []),
                    *(plan.get("section_gate_blockers") or []),
                )
            ],
        }
    if not is_finished:
        return {"kind": "not-finished",
                "reason": "deferred" if deferred else "incomplete"}
    stated = _plan_terminal_gates(blockers)
    base = {
        "project": plan.get("project"),
        "slug": plan.get("slug"),
        "status": status,
        "readiness": readiness,
        "closure_blockers": [
            {"kind": b.get("kind"), "id": b.get("id"), "ops": b.get("ops")}
            for b in blockers
        ],
        "stated_reason": [
            {"id": b.get("id"), "measure": str(b.get("measure") or "")[:140]}
            for b in stated
        ],
    }
    return {"kind": "stated" if stated else "violation", **base}


def main() -> int:
    mounts = _load_mounts()
    buckets: dict[str, list[dict]] = {
        "violation": [], "stated": [],
        "blocked-on-finished-gate": [], "not-finished-terminal": [],
        "not-finished-deferred": [], "not-finished-incomplete": [],
    }
    errors = []
    scanned = 0
    with metadata_index.discovery_file_scope():
        for project in sorted(mounts):
            try:
                report = _roadmap(project, None, None, 5)
            except Exception as exc:  # noqa: BLE001 — one project must not hide the rest
                errors.append({"project": project,
                               "error": f"{type(exc).__name__}: {exc}"})
                print(f"ERROR {project}: {type(exc).__name__}: {exc}", file=sys.stderr)
                continue
            if not report.get("ok", True):
                errors.append({"project": project,
                               "error": str(report.get("detail"))})
                continue
            for plan in report.get("pending_work") or []:
                scanned += 1
                row = dict(plan, project=project)
                c = classify(row)
                key = c["kind"]
                if key == "not-finished":
                    key += "-" + c["reason"]
                buckets.setdefault(key, [])

                buckets[key].append(c)

    violations = buckets["violation"]
    stated = buckets["stated"]
    blocked = buckets["blocked-on-finished-gate"]
    payload = {
        "mounts": len(mounts),
        "plans_scanned": scanned,
        "finished_open": len(violations) + len(stated),
        "finished_stated": len(stated),
        "finished_violations": len(violations),
        "blocked_on_finished_gate": len(blocked),
        "excluded_terminal": len(buckets["not-finished-terminal"]),
        "excluded_deferred": len(buckets["not-finished-deferred"]),
        "excluded_incomplete": len(buckets["not-finished-incomplete"]),
        "errors": errors,
        "violations": violations,
        "stated": stated,
        "blocked_over_finished": blocked,
    }
    OUT.parent.mkdir(parents=True, exist_ok=True)
    OUT.write_text(json.dumps(payload, indent=1))

    print(f"mounts={len(mounts)} plans_scanned={scanned}")
    print(
        f"finished_open={payload['finished_open']} "
        f"violations={len(violations)} stated={len(stated)} "
        f"blocked_on_finished_gate={len(blocked)} errors={len(errors)}"
    )
    print(
        f"excluded: terminal={payload['excluded_terminal']} "
        f"deferred={payload['excluded_deferred']} "
        f"incomplete={payload['excluded_incomplete']}"
    )
    for r in sorted(violations, key=lambda x: (x["project"], str(x["slug"]))):
        ops = sorted({op for b in r["closure_blockers"]
                      for op in (b.get("ops") or [])})
        print(f"VIOLATION {r['project']:18s} {str(r['slug'])[:54]:54s} "
              f"{r['status']:12s} readiness={r['readiness']:9s} ops={ops}")
    for r in sorted(stated, key=lambda x: (x["project"], str(x["slug"]))):
        print(f"STATED    {r['project']:18s} declared in {r['slug']} "
              f"gate={r['stated_reason'][0]['id']}")
    for r in sorted(blocked, key=lambda x: (x["project"], str(x["slug"]))):
        print(f"BLOCKED-ON-FINISHED {r['project']}:{r['slug']}")
    return 0


def self_check() -> int:
    """Prove the predicate fires where it must and stays silent where it must."""
    cases = [
        ("closable-unclosed", dict(
            project="p", slug="a", status="active", readiness="closable",
            progress_pct=100.0, deferred_remainder=None,
            closure_blockers=[{"kind": "op", "ops": ["close"]}]), "violation"),
        ("stated-open", dict(
            project="p", slug="b", status="active", readiness="closable",
            progress_pct=100.0, deferred_remainder=None,
            closure_blockers=[
                {"kind": "gate", "id": "g-keep", "transition": "plan-terminal",
                 "measure": "kept open for the December review"},
                {"kind": "op", "ops": ["close"]}]), "stated"),
        ("deferred-only", dict(
            project="p", slug="c", status="active", readiness="closable",
            progress_pct=100.0,
            deferred_remainder={"count": 2},
            closure_blockers=[{"kind": "section", "ops": ["descope"]}]), "not-finished"),
        ("closed", dict(
            project="p", slug="d", status="shipped", readiness="closed",
            progress_pct=100.0, deferred_remainder=None,
            closure_blockers=[]), "not-finished"),
        ("blocked-on-finished-gate", dict(
            project="p", slug="e", status="active", readiness="blocked",
            progress_pct=100.0, deferred_remainder=None,
            closure_blockers=[],
            section_gate_blockers=[{"id": "g1", "gated_sections": ["s1"]}]),
         "blocked-on-finished-gate"),
    ]
    failed = 0
    for name, row, want in cases:
        got = classify(row)["kind"]
        ok = got == want
        print(f"{'ok ' if ok else 'FAIL'} {name}: want={want} got={got}")
        failed += 0 if ok else 1
    return 1 if failed else 0


if __name__ == "__main__":
    if "--self-check" in sys.argv:
        raise SystemExit(self_check())
    raise SystemExit(main())
