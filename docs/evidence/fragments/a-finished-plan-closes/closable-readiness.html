A plan with nothing left to build reads closable

The readiness ladder in reckon/roadmap.py gains the value closable, decided by plan_executable_remainder in reckon/_schema.py — the one existing reader of "does a declaration still admit work". A plan that carries declarations and has resolved every one of them (done, descoped or deferred) reads closable: it leaves ready_now, the blocked set and the critical path, so the ready counts coordinators rank no longer carry finished plans.

closure_blockers is widened for such a plan from plan-terminal gates to every remaining obstacle — deferred sections, open followups, open execution gates and plan-terminal gates — each carrying the ops that clear it, and the list ends with the close op. One row therefore carries both what stands between the plan and its close and the write that closes it. A plan that still declares implementable work keeps the plan-terminal-gate list unchanged.

A plan that persisted no section classification is the legacy population and keeps whatever readiness the ladder would otherwise give it. This is load-bearing rather than incidental: readiness_from_state reports an absent declaration set as an empty mapping, so a discovery row cannot tell a plan that never classified its sections from one that classified none. The closable branch requires a non-empty declaration set, and a fixture covers the empty-map shape.
