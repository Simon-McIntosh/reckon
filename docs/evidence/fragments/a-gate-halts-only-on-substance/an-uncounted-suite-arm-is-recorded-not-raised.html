An arm that never counted is unmeasured, not malformed

What this node changed. A run gated on a GPU records suite arms that abort inside their backend compilation at base and head alike, so neither reaches a pytest summary: each arm carries completed false and a null failure_count. Promotion judged the pair and then called int() on that null, so a completion whose waiver was already recorded and whose waived-count review was already filed raised TypeError out of ledger.normalized_suite_observation instead of landing.

An arm that never reached a summary states exactly what it observed — that no count exists — so the record now says so. The ledger's normalised arm carries completed: false, failure_count: null, unmeasured: true and the waiver's own reason as unmeasured_reason. A pair the completion waived is therefore written as two unmeasured arms beside the waiver that permitted it, which keeps "measured zero" and "never measured" apart in the row. A counted pair normalises to the shape it carried before this change, key for key.

The refusal is reachable. With no waiver the same completion refuses rather than raising, and its detail names the arms that never counted and the option that would record them: baseline_suite and after_suite never reached a pytest summary, so no failure count exists to compare: re-measure the arm, or state why it cannot count with --waive-suite-delta '<why>'. The refusal's fields are the four an uncounted arm is missing and nothing else, so a waiver of the pair covers exactly those fields.

The control is the raise itself. The check declares that at the base revision a waived completion over arms with null counts raises TypeError from normalized_suite_observation, and the captured log shows it: the same test file carried into a checkout of the base revision fails the landing case with TypeError: int() argument must be a string, a bytes-like object or a real number, not 'NoneType' at ledger.py:563, and fails the no-waiver case because the refusal there says nothing about a summary it never reached. The counted case passes at both revisions, which is the third arm's claim: nothing measured changed.
