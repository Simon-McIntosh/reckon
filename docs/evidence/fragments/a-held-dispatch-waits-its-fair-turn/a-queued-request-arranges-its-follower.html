A queued request arranges its session's follower

A held dispatch previously stored its queued pointer and returned before ensuring the producer or asking the calling session host for a follower. The new FIFO-backed regression reproduced both effects: the host received no request, and the first admission pass launched no run.

The held and launching paths now use one helper to ensure the producer and ask the calling session host. A queued request leaves its session attached before dispatch returns, so the first admission pass can launch it.
