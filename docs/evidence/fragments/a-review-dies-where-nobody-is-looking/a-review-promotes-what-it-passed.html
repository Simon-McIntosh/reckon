A review's promotion scope is the declaration its manifest was checked against

Read at base 3d8e1a680, changed at b8e32ac96. A review's whole deliverable is the record it stores beside the run it read — an absolute path outside every repository, granted by its dispatch — with the copy the store keys by the revision it read. The check a worker runs against its own manifest accepted that grant; the scope test promotion applies hours later reported both paths as stray. One delivery, two verdicts, so the same node that repaired its manifest to satisfy the early check would be refused by the late one.

What disagreed. Both surfaces answer one question — is this changed path contained by a declared write root — and each had its own implementation. The write-time audit resolves a declaration that names a location outside the repository to no repository-relative root and then compares the absolute path it already is, so the declaration still decides what it grants, and it admits the revision-keyed record written beside a declared store path. Promotion skipped any declaration that resolved to no root and compared nothing against it, so an out-of-repository grant read as no grant at all and the paths it named were stray.

The rule now. reckon/crew/promotion.py's _outside_declared_scope delegates to reckon/crew/reports.py's path_within_declared_scope instead of repeating the containment test, so one implementation serves both surfaces and a change to either cannot move them apart. The declaration is still resolved against the run's recorded worktree before the comparison — a grant made under a worktree that has since been reclaimed keeps its mapping — and a path under no declaration is still reported, which is what the controls below pin.

What this does not close. Promotion consults the scope test only for the paths a run's cited commits changed, so a review that cites no commit has its declared changed_paths judged by no scope rule at promotion at all — replayed at base, a commitless review naming its store record is promoted with the scope test never called. The two surfaces now agree wherever that test runs, which is what this node measured; a promotion-time judgement of a commitless run's declared paths would be a new refusal with a fleet-wide blast radius and is not part of this change.
