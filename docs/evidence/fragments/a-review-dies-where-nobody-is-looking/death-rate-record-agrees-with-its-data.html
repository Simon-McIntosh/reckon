The measure

The scanner already accepted --since; the run that last produced the committed file did not pass it. One deviation, reported: the after block's death count is written in the same headline shape as the before block — deaths.headline beside within_window_all_efforts — rather than as a bare count. The controls

The after block's fixed control is out of window by construction. r-20260928T044354744785-review-of-reflex-keys-on-reviewed-run-and-head is a review at the before effort that predates the window; the block reads it as dead on its first attempt and completed on its resumed attempt, so the control aims the classifier and not the window, and the block's controls_note says so.

The death count is a liveness reading and is stated as one: an attempt without a result record is counted dead only once its process is gone, so the file states a measurement at one moment rather than a frozen fact, and a later rescan reads whatever has ended since.

What this does not establish

The after window is not a post-repair rate: the review-reliability repair has not landed, and the window measures the configuration the effort move created.

One attempt's place in the window rests on its file's mtime rather than on its own records, so its day is the file's clock and not the stream's.
