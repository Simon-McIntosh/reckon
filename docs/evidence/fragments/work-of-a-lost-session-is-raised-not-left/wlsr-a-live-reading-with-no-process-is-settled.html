A live reading with no process is settled

A pointer in phase starting or working that no worker is behind kept reading live for as long as the record survived: its launch writer set the phase, nothing advanced it, and the run counted as live in the lane's figures while its reviewed head could not be reviewed again. The classifier is the one place a run's phase, classification and process liveness are judged, and the reading is added there, composing into the same result rather than a second opinion.

Two measurements decide it. The launch step is asked of the scheduler by its own listing (squeue --steps --jobs <job>, with the job taken from the run directory's recorded launch argv), and the step is paired by the run's id, which the launch composes as the step's name — so a shared reservation's other steps are never read as this run's. The stream's silence is measured by the existing attempt-capped reader, which keeps a run resumed minutes ago young however old its predecessor's stream is. When the step is gone and the silence passes the new flight setting settle.quiet_after_hours (default 6.0), the run is classified interrupted — the phase that already exists for a worker that ended without delivering — with settled carrying the step state, the measured silence, the bound and the stream path.

The reading cannot over-fire. Any positive liveness reading leaves the pointer alone, a step the scheduler still lists leaves it alone, a scheduler that cannot answer leaves it alone, a run younger than the bound leaves it alone, and a launch that composes no step falls through to the liveness readings that can describe it. No phase is added; one flight setting is.

Six cases pass in a temporary RECKON_HOME against a stubbed scheduler, with the pointer, the run directory and the stream's mtime synthesised: a starting pointer with no step past the setting settles, a working pointer whose step is gone and whose stream is stale settles the same way, a working pointer whose step is still listed is untouched, a starting pointer younger than the setting is untouched, a worker alive and quiet is untouched, and a settled run appears exactly once in its owner's obligations as turn-ended-early.
