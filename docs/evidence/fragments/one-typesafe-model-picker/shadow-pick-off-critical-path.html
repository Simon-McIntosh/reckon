Explicit lane shadow pick after launch

Deterministic and explicitly named lanes now launch without awaiting their advisory picker. The detached picker has a five-second bound covering input construction and the pick, then writes its selection or a recorded fallback to the live run pointer. Picker-routed dispatches still resolve their pick before launch. A slow-client test holds the picker pending while dispatch returns, then confirms that the pointer and the ledger record builder read the later selection; a real detached-process test confirms the process writes the pointer.
