Composed new-work dispatches leave the lane to the picker

The obligations hook no longer rewrites a printed remedy's --backend into --local. A remedy that dispatches new work — dispatch, review-plan, shadow — has its lane flags removed, so the picker routes the node or holds it; a remedy that continues a run (resume, redispatch, repair) is left as composed, keeping the lane the run was carried on. The build, create and edit skills now state the same default: the lane is the picker's to choose, naming a lane is the exception, and an unnamed review runs locally or holds through review_excluded_backends.
