The picker's budget view is cached on its input files

Base 7c882130d, head d1c0ec689. The picker's budget view is composed through the stamped pick-input cache that the context census and the estimated-hours read already use, keyed on the stamps of every file it reads - the paid-lanes document, the banked-reset record, the lane documents and the ledger index. Time-derived fields (ages, elapsed fractions, seconds to reset, stale flags) are recomputed from the interval since the build on every call, so a cached entry never serves a stale age.
