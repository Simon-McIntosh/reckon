Return time and live lane load in the picker state

A new module reckon/crew/picker/lane_context.py renders, per offered candidate, the recorded return time for a job of this node's shape and the local lane's live load. The state template carries both blocks so Jev can weigh how soon a job would return on each lane.

What landed

  • return_times(profile, node, candidates) reads run_time_profile and, per candidate, reports the median (p50_s) and 90th-percentile (p90_s) wall_seconds for runs matching the node's role and spec_level on that backend, the runs behind them, and the node's size size_key/size_bucket (declared time_budget preferred, output tokens otherwise).
  • Each block carries the budget reading's budget_source (account-surface, ledger or null) and budget_age_s, with stale true when a ledger-only reading is older than budget.evidence_shelf_life_minutes.
  • local_lane() reports running, waiting, headroom, worker_slots, tokens_per_second and read_at, every unpublished field null.
  • prompts.render builds the blocks so every state caller carries them; state.jinja renders both, and questions.jinja states that expected return time and the local lane's current load are criteria beside fit, burn and recent outcomes.

Checks that could have failed

tests/test_picker_return_time.py synthesises ledger rows and a lane document in a temporary directory and passes all 8 tests: the nearest-rank p50/p90 figures and the size bucket, group selection by role and specification level, a ledger reading past its shelf life marked stale, a fresh ledger reading and an account-surface reading not stale, a missing lane document yielding nulls, a published lane document read, and a representative nine-candidate state at 2296 characters, or 574 tokens at four characters per token, below the 1,500 bound with a real five-key congestion block (running, waiting, admission_verdict, stale, slots_state). The state also keeps each candidate's established eight keys, so the added blocks do not disturb the existing contract.

Declared mutation — swap p50_s and p90_s in return_times — produced assert 400 == 250.0 and exit 1 at tests/test_picker_return_time.py::test_return_time_figures_and_size_bucket, while the unmutated head passes. Log: negative_control.log.
