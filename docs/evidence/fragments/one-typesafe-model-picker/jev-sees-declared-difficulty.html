The picker now resolves both facts from the plan the node names. _declared_difficulty in reckon/crew/picker/__init__.py runs the same routing.resolve_section_routing the dispatcher uses to read the section's effective capability at the attempts it has earned, and routing._estimated_hours (already cached on the plan's stamps) to fill the estimate when the node carries none. Its cost is recorded in the pick's own stage times as capability_ms; it is guarded, so a resolution that fails leaves the field null and never fails or stalls the pick. A capability the request already carries, or an estimate the node itself carries, is never overridden.
