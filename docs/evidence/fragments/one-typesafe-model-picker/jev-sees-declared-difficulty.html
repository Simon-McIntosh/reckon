The picker now resolves both facts from the plan the node names. _declared_difficulty in reckon/crew/picker/__init__.py runs the same routing.resolve_section_routing the dispatcher uses to read the section's effective capability at the attempts it has earned, and takes the estimate in precedence order: the node's own figure, else the effort the section's own record declares (data-effort-hours, read through routing._section_record, labelled source section), else the plan's declared total (routing._estimated_hours, labelled source plan). The plan is resolved once and serves both the section record and the routing resolver. Its cost is recorded in the pick's own stage times as capability_ms; it is guarded, so a resolution that fails leaves the field null and never fails or stalls the pick. A capability the request already carries, or an estimate the node itself carries, is never overridden, and the source is rendered unconditionally as null when nothing resolved, so the node's shape does not vary with which facts a pick could read. The budget-source glossary now names the document reading a published paid-lanes figure carries.
