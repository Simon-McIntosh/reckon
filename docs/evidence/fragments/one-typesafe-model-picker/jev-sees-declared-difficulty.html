Jev sees the difficulty a node's plan section declares

A dispatch builds PickRequest with no capability and a node whose estimated_hours is unset, so the rendered state Jev weighs carried an empty capability and a null estimate. Measured on the live pointer of r-20261008T004354567004-cfs-edge-term-tangents (nova, converged-forward-solve §2): capability = None and estimated_hours = None, against a section that declares class orchestrator, reasoning deep, verification strict, risk critical and effort. Jev routed that critical, deep, ten-hour node with the same distribution as two easy nodes. Reproduced through the state render before the change: capability {}, estimated_hours null.

The picker now resolves both facts from the plan the node names. _declared_difficulty in reckon/crew/picker/__init__.py runs the same routing.resolve_section_routing the dispatcher uses to read the section's effective capability at the attempts it has earned, and takes the estimate in precedence order: the node's own figure, else the effort the section's own record declares (read whenever the node names a section that declares one, whether or not the plan declares a total at all, labelled source section), else the plan's declared total (routing._estimated_hours, labelled source plan). The plan is resolved once and serves both the section record and the routing resolver. Its cost is recorded in the pick's own stage times as capability_ms; it is guarded, so a resolution that fails leaves the field null and never fails or stalls the pick. A capability the request already carries, or an estimate the node itself carries, is never overridden, and the source is rendered unconditionally as null when nothing resolved, so the node's shape does not vary with which facts a pick could read. The budget-source glossary now names the document reading a published paid-lanes figure carries.

On the reported node the state now carries capability class orchestrator with reasoning deep, verification strict and risk critical, and estimated_hours 10.0 labelled with its source section — the effort §2's own record declares, not the plan's 48.0 overall. The plan's total stands only where the section declares none or the plan does not record the section at all.
