Verdict. The router should POST the TypeSafe body to https://openrouter.ai/api/alpha/decisions with pinned model typesafe/jev-1.13. It obtains the selected option from answers.route.choice, confidence from answers.route.confidence, and the auditable distribution from answers.route.probabilities. The Decisions surface is preferred over the equivalent System One surface because OpenRouter documents it as the plain-HTTP endpoint; System One is the compatibility endpoint for the TypeSafe SDK. Neither typesafe/jev-router nor chat-completions can supply this typed contract.
