The picker surface enters the skill and source contracts

Four changes close the gate. The picker no longer carries a hard-coded set of refused backends or models: every configured backend is budget-probed and a candidate is excluded only when its live serving observation reads not-served, so eligibility cannot disagree with what the lane actually serves and no model identifier is named in source. The pick help line now names the state it reads, the compact CLI inventory names the verb and says it reads routing state and dispatches nothing, and the role digests regenerate byte-identically from the canonical policy.

The gate over the skill-contract, help-census, worker-digest and picker test files moves from five failing ids at the base revision to none: five failed and 127 passed at the base, zero failed and 133 passed at the head, with zero failure ids added. The declared negative control — restoring the hardcoded refused-model set in the picker snapshot — fails the routing-identifier test as required.
