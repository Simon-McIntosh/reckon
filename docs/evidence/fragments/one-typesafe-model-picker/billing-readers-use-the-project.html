Every billing reader resolves with the row's project

The promotion writer (reckon/crew/promotion.py, _complete_locked) now passes the record's project into ledger.build_record, so the stored row's budget block is resolved against that project's flight layer at write time. The picker's outcome summary (reckon/crew/picker/outcomes.py) now passes each row group's project into ledger.is_subscription_backend, so its per-backend subscription label honours a project override. Tests are in tests/test_billing_readers_use_the_project.py.
