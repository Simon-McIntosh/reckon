Jinja prompt precedent

/home/ITER/mcintos/Code/imas-codex/imas_codex/llm/prompt_loader.py binds PROMPTS_DIR to Path(__file__).parent / "prompts". _get_jinja_env uses a custom PromptsLoader that searches prompts/shared/ then prompts/; render_prompt calls env.from_string(prompt_def.content) and template.render(full_context). Its stricter path, _strict_jinja_env/render_prompt_strict, uses ChoiceLoader(FileSystemLoader(shared), FileSystemLoader(root)), StrictUndefined, rejects unknown or missing context keys, and renders with env.from_string(...).render(full_context). Reuse the strict pattern for picker prompts so a missing live fact cannot silently become an empty string.

Dependency gap: jinja2 is absent from reckon's pyproject.toml dependencies. It appears in uv.lock only transitively, so the router must add it as a direct project dependency before importing it.
