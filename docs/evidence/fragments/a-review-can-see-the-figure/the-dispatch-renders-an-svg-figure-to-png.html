SVG attachments are rendered for dispatch

Dispatch now renders each SVG image to a 1400 px wide PNG in its run directory, records that PNG as the run image, and carries the same path through resume. PNG inputs retain their original path. The thumbnail route and dispatch use the same renderer in reckon.figures.
