§3 — the lane discriminates five known pairs on paired inputs

The five known pairs of §3's table were presented to the local lane one figure at a time, each judged against its rule alone. The ten figures under docs/figures/figure-review-pairs/ were copied to neutral names in a fresh shuffle so a role cannot be read off a file name, with each copy's sha256, pair, role and rule recorded in the shuffle key beside the run. A good/bad pair discriminates when the bad figure is answered FAIL and the good one PASS on its own rule.

All five pairs discriminate on PNG input. The bar-and-gradient pair (FAIL: vertical bar gradient, drop shadow and drawn gridlines; PASS: flat bars, one dotted limit rule, direct value labels), the contrast pair (FAIL: a mid-grey marfe label on saturated blue; PASS: the same label near-white), the legibility pair (FAIL: tick labels far below the axis titles; PASS: tick labels at the axis-title size), the plot-versus-table pair (a continuous curve against a rendered table of ρ and electron-temperature values), and the physics pair (FAIL: a colour bar with numeric ticks and no quantity or unit; PASS: the same plot labelled poloidal flux [Wb]).

The format boundary in §3 was measured rather than assumed. The same reader opened two of the pair figures as SVG and received the document as XML text — prolog, <svg>, path and glyph data — with no rendered image. An SVG figure is therefore not delivered as a picture, which is the fact behind the locked render-to-png decision: the repository keeps one SVG per figure and the dispatch rasterises it before attaching it.

The observer is this run's own lane model, which is the lane under test, and the harness refuses nested agents inside a crew run, so no second independent judge could be spawned; the image-withheld controls could not be re-run on the same terms for the same reason. Each verdict is recorded beside the observation it rests on so a reader can confirm it against the image itself, and §21's five image-withheld controls remain the control evidence for this lane. The full record, with the shuffle key, sha256s and per-figure observations, is the run's measurement/report.md, reproduced in the landed record.

The profile is enabled for this lane on all five rules, on PNG input: no pair failed to discriminate, so no rule is carved out of the evaluation.
