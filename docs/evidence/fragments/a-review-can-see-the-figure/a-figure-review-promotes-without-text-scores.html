§18 — a figure review promotes without text scores

A figure review judges the rendered artifact, so it does not score the six text dimensions. The review-store contract required every text dimension as a key on any parsed record, and ledger_block in reckon/crew/review.py then called int() on each value. The first live figure review stored its scores as six nulls and could not be promoted: crew complete raised TypeError: int() argument must be a string, a bytes-like object or a real number, not 'NoneType' in ledger_block, reached from _complete_locked in reckon/crew/promotion.py.

Reproduced before repair, quoting the run: a figure record with the six dimensions present as null returned review_record_refusals empty and made ledger_block raise the TypeError above; a figure record with no scores key was refused with ['missing scores'] at a parsed status, and a fully scored text record (six 10s, total 60) was accepted and kept its scores and total.

review_record_refusals now decides the score requirement by rubric: a record whose rubric is the figure rubric needs neither a scores mapping nor the six dimensions inside one, whether it omits scores or holds them as null; a text-rubric record is refused for a missing dimension exactly as before. ledger_block keeps only the dimensions whose value is an integer, so a figure record reduces to status parsed with empty scores and a None total. Its docstring now names the figure rubric as the one parsed record that carries no text scores, and keeps the older sentence for every other unscored record, which still keeps a status other than parsed.

After repair, the same figure record with six null scores and the one with no scores key both return review_record_refusals empty and reduce to {'status': 'parsed', 'scores': {}, 'total': None}; the text control is unchanged. The promotion case promotes a figure review run through the same harness tests/test_a_promoted_code_review_is_stored.py uses — a temporary repository and crew home, a figure round stored at the head-keyed figure path, a review-of-<subject>-<head[:12]>-figure pointer — through crew.complete, and the promoted ledger row's review block reads status parsed with empty scores and a None total.

The gate is PYTHONPATH=$PWD <venv>/python -m pytest -p no:cacheprovider -q tests/test_a_figure_review_promotes_without_text_scores.py, run in the node worktree: 7 passed, EXIT=0.

The declared negative control makes ledger_block call int() on every score value again.
