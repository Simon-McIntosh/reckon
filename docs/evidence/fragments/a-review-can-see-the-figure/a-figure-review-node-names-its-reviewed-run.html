§17 — a figure review's node id names the run it reviews

round_node_id in reckon/crew/repair.py now takes an optional rubric and writes it after the head suffix, so a round's id is <prefix><source>-<head[:12]>-<rubric> (or the bare <prefix><source> when no head is written, since a rubric suffix with no head before it would read back as part of the source). round_node_source strips a trailing -figure only when a 12-hex head suffix immediately precedes it, and reads the head after that exactly as before; round_node_head_suffix recovers the head and permits only an optional trailing rubric suffix after it. A source whose own name ends in the rubric word with no head written is read whole. _trailing_rubric_start and _head_suffix_at carry the two shared predicates, so the writer and both readers parse one grammar.

_review_dispatch_fields in reckon/crew/recovery_review_subject.py now mints the figure node id through round_node_id(…, rubric=FIGURE_REVIEW_RUBRIC) rather than appending -figure itself. Every reader that already went through the round rule — _reviewed_run_id_for_node in reckon/crew/dispatch_admission.py, the delivery reader in reckon/crew/recovery_review_delivery.py and the session lookup in reckon/crew/dispatch_sessions.py — now resolves a figure review's node id to the run it reviews.

For source s at head h the minted id is review-of-<s>-<h[:12]>-figure; round_node_source returns s and round_node_head_suffix returns h[:12]. A text round's id (review-of-<s>-<h[:12]>) and a bare review-of-<s> resolve as before, and review-of-plot-figure resolves to plot-figure.
