The published rule

_crew_result_ok in reckon/cli.py reads the result before _emit_crew_result publishes it. An explicit ok wins, including false. Otherwise a nonempty result is true only if its outcome fields do not name an error, refusal, skip, finding, unusable measurement, timeout, budget overrun, absent or nonzero exit status, ran: false, measured: false, completed: false, a held preflight, a watcher-seat skip, held or refused picker action, failed validation, review refusal or deferral, or stopped/skipped project split. A bare drained: false and a placement reservation's held: true remain measured facts, not command failures. The emit helper gives a false result exit 1, preserving preflight's established exit 3 for a hold.
