An empty worktree field is absent, never the current directory

Landed at 2d7ddd40e and cae89858e on reckon/crew/promotion.py, with tests/test_empty_worktree_field_is_absent.py added and the gate-evidence fixture in tests/test_gate_evidence.py given a real worktree path.

_run_promoted_revision and the review gate in complete() each built Path(str(record.get("worktree") or "")). Path("") is Path("."), which is a directory, so a live pointer carrying no worktree resolved its promoted_revision — and a legacy review's reconstructed head — from whatever repository the process happened to start in. Both readers now resolve their tree through one helper, _record_tree, which reads a blank worktree field as absent and falls to the recorded repository; a record naming no existing directory resolves no tree and _run_promoted_revision returns the empty string rather than a confident wrong answer. The gate-evidence fixture writes worktree: <fixture repository> so its selection no longer depends on where the suite was started.
