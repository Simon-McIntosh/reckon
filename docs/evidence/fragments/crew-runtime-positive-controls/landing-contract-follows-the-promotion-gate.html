A landing contract a role's own promotion refuses

The landing contract is a named slot in the composed prompt like its siblings, and it decided on one fact: whether the worker can write its assigned worktree. The promotion gate decides on another: whether the role may land repository paths. For the test role the two disagree, because the shipped flight configuration gives it a worktree-full sandbox while the gate refuses every repository path a verifier commit touches. The contract now reads both the writability fact and role_may_write_repository_paths, the predicate the refusal already reads, so the two surfaces decide by one criterion: a role that may not land repository paths is not given the contract, and a role that is given it is not refused for following it. A verifier whose fence withholds the landing fragment therefore reads no landing contract rather than the run-record carrier.
