A worktree release is whole or not at all

One helper, _release_worktree_whole, owns removal for every site: it renames the tree onto a same-filesystem trash directory, deletes that tree's own administrative directory to deregister it alone, then deletes the copy with no deadline. A global git worktree prune is deliberately not run, because it would also drop the registration of a peer tree whose directory vanished outside git — another session's record, which crew gc reports and leaves in place.
