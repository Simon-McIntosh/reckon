A presented commit is refused in the commit-object vocabulary — evidence

The presented-commit branch of the promotion gate-evidence guard refuses an identifier that resolves to nothing, but it worded that refusal “does not resolve to an object” while the commit resolver words the same complaint “does not resolve to a commit object in the run repository”. One defect refused in two vocabularies means a caller matching the phrase catches one refusal and silently misses the other. The presented refusal now uses the established phrase, with its behaviour unchanged: it still fires by value where the presentation is read, still names every unresolved entry beside the tree they were resolved against, and still stays silent when the worktree cannot be read, so a run whose tree is gone is not refused for a citation no store was asked about.
