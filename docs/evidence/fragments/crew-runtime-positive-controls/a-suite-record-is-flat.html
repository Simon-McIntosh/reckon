A suite record keyed by arm is refused where the worker can fix it — evidence

audit_manifest in reckon/crew/reports.py is the write-time judge crew check-manifest calls, and it folded both suite fields through the canonical observation before any shape was judged: _validate_suite_observation fills revision, command, exit_status, log_path, completed and failure_ids from the mapping it is given, leaving absent fields empty. A record keyed by arm therefore read as an observation whose every field was empty. Two shapes were delivered this way on 2026-10-03: r-20261003T130535115617 keyed by the terminal each arm rendered under (dumb, colour) and r-20261003T132224666771 keyed by the measurement each arm took (population, named_alone, ...). The suite-shape findings ran only under status == "complete" and suite_armed, and check-manifest calls the audit unarmed, so the defect passed the worker's own check and surfaced only at promotion, where the keyed record reads as an arm that declares no completion and the run is refused with no readable comparison arm is recorded — after the worker's process has ended, when only a coordinator can restructure the record. review._gate_log_path reads only a flat log_path, so the added-failure count of both runs also read as unmeasured.

The audit now refuses the shape where the author can still fix it. baseline_suite and after_suite are checked at the top level against the flat record the dispatch template defines (revision, command, exit_status, log_path or log_digest, completed, failure_ids), and a mapping that is not one adds a finding naming the field and the keys a flat record carries. The check runs for every status and without the armed flag, so crew check-manifest reports it before the worker finishes; the armed block skips a record the shape check already refused, so a keyed record is described once, by its shape, rather than field by field against empty values. Only mappings are judged: a field written as a prose not-run statement keeps its present treatment, and a flat record passes unchanged.
