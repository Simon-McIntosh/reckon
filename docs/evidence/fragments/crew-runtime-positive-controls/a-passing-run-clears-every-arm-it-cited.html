Execution evidence

A passing run clears every arm it cites

A release now reads the manifest rather than a directory name: every absolute path the manifest cites under the node-local temp root is removed, after the cited logs inside it are copied into the run directory, and every path kept is reported with its reason.

What the release does

The manifest is scanned for absolute path tokens. A cited directory is removed when it sits under the node-local temp root (the parent of the run's own worker scratch directory), is not the run's own scratch subtree, does not contain or sit inside the repository, the worktree or the run directory, and is not cited by another run holding a live pointer. Cited log files inside a removal target are copied to <run>/cleared-arms/<arm-name>/<relative path> before the tree is removed, so a gate log survives the arm it measured. The release record carries arms_removed_paths (path and byte count per removal), arms_kept (path and reason) and arms_logs_copied, and all three persist to the ledger through the existing release mapping.

Reproduction and measure

The focused test tests/test_a_passing_run_clears_its_arms.py synthesises a config home, a repository with a worktree, a temp root holding a cited arm, a cited control tree, a shared basetemp cited by a second live run, and a cited tree outside the temp root. At base 6a04552fda5ac51df83f38b37a13ca2658236f79 it fails at assert not base_arm.exists() with EXIT=1: both cited arms remain. At head 5b21b59c5 it passes in 7.64 s: the two temp-root arms are removed with the removed byte counts recorded (11 and 14), the shared basetemp is kept naming the citing run, the path outside the temp root is kept naming the temp-root reason, and both cited logs are readable under the run directory. Fifty-one focused promotion and dispatch tests pass in 90.72 s.

The arm population is the 58 test files that import reckon.crew.promotion, run once per arm with the same six-way parallelism. The base arm, whose tests and package resolve from a base-tree extraction, completed 497 passed, EXIT=0 in 535.90 s. The head arm completed 1 failed, 496 passed, EXIT=1: the failure is tests/test_dispatch_returns_without_worker.py::test_a_discarded_run_is_not_recreated, a file this node does not touch. It then failed again alone in 16.52 s at head, so it is not a load artefact, and the same test passed inside the base arm. The node therefore reports inconclusive rather than passed: the change is not yet excluded as the cause, and the discriminating run — that one test file alone against the base tree — was not spent before the time fence.
