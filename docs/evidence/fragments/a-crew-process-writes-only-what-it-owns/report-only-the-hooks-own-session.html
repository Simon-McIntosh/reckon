The obligations hooks report only their own session

Session resolution in _session_from_followers (reckon/hooks/coordinator_obligations.py) walked one registration list and returned the first row whose follower descends from the hook's harness process. A session host that holds another session's follower therefore looked like that other session whenever its registration sorted earlier, so the UserPromptSubmit and Stop hooks showed, and blocked on, duties the invoking session did not owe — including a promotion of another session's run. Resolution now scans every registration for the harness session id first and falls back to the descent walk only when the harness session names no registration of its own. A harness that exports no session id keeps the descent behaviour exactly as before.

Reproduced at base revision 0ae9e71d32 before the change: two registrations in one temporary crew home, both armed by the caller, the foreign one sorting first, and harness session harness-session-a resolved to aaa-session-b. tests/test_the_obligations_hook_reads_its_own_session.py shows the three cases the section names — the harness session wins over an earlier descending row; a Stop hook in A is silent while a blocked run only B owns holds its turn open; and with no harness session the descent fallback still resolves. At head all three pass (3 passed); the same file copied into a scratch tree of the dispatch base fails the first two (2 failed, 1 passed), which is the defect reproducing. The declared negative control — one scan returning the first descending registration before reaching the exact match — makes the first case return the other session, logged red. The ten other test modules importing this hook module ran at head: 72 passed, and their one failure (test_the_prompt_path_loads_no_derivation_module) fails identically at base, so the change adds no failure. ruff check and ruff format --check add no findings on the two changed files; the two S105 findings in the hook module predate the change and sit outside its lines.
