Of the 956 unledgered run directories past retention (29.6 GB), every one is attributed unknown: their live pointer is gone and their manifest carries no project key, so no sweep can name their project, and each is reported keep with that reason and left on disk. The 2,410 run directories and 21.75 GB that the run store lost across the window were not this pass's. Its own snapshots, taken either side of the --apply call, show no run directory removed, and its report named none reclaimable for reckon. The loss falls between the two jobs and coincides with the run-lifecycle sweep under crew-state-stays-bounded. Within that interval the two files that cursor that sweep were rewritten: ~/.config/reckon/crew/retention-cursor.json at 04:30:16Z, holding {"after": "r-20260907T191107338286-n-sli-the-reasonless-failures-are-triaged"}, and ~/.config/reckon/crew/cleanup-cursor.json at 04:41:42Z. The first of those falls 11 minutes before the apply job's pre-apply snapshot and inside the interval in which the 2,410 directories left, and it is the only evidence of a moving cursor in that interval. That is an association, not a proven cause: a cursor advancing during the interval does not prove that sweep removed exactly those directories. The figures are recorded here because the node's fence asks for counts before and after, not as a reclamation this pass can claim.

The before-measure recorded a remover already at work. Its du -sk of the run store reported rc=1, and its two stderr lines name run directories that ceased to exist part-way through the walk: r-20261115T024952708941-review-of-archive-pulse-schema-179e16f1bee2 and r-20261115T034245513789-review-of-a-local-worker-compacts-and-continues-measured-bbfc8256932e-figure, the second written at 03:42Z, eleven minutes before the measure. Nothing this node ran had removed a run directory at that point: its report-only pass was still running and removes nothing by design. So a second process was deleting from the same store while the before-state was taken. That is why the two readings are not two samples of one undisturbed population, and why the drop is attributed to that process rather than to this pass.
