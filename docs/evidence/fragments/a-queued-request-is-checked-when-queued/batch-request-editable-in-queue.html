A batch-made request can be edited in the queue

A request queued by --batch now stores the manifest path its worker delivers to, so crew queue edit judges it on the same contract as a single dispatch. Before the change the edit was refused with the exact message the report quoted: the edited request fails its contract checks and was not stored — independently-verifiable: no manifest path is named, so completion could only be judged by reading the implementation.
