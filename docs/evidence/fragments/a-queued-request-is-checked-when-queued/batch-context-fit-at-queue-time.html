A batch entry's context fit is judged at queue time

A batch entry is now measured against the window of the lane it resolves for before anything is stored, so a request that cannot fit is refused in its own batch row — naming the estimate, the window and the file that dominates the estimate — instead of sitting in the queue until the first launch attempt refuses it on a pointer nobody is watching. Before the change _queue_batch reached queue_requests, which ran only the admission domain findings (declared inputs, stated comparison) and never the context estimate, so an entry of 334k tokens against a 230k window was reported as queued and refused hours later.

The measurement is the router's own fit verdict (routing._context_fit_verdict), reached through a four-field stand-in for the resolved dispatch it normally reads, so the queue-time figure and the launch-time figure cannot disagree about which window gates the request — the minimum of the lane's declared usable_input_window and its recorded effective_input_window. A path declared a regenerate path is charged the flat reference cost rather than its size, which is what distinguishes a node rewriting a large generated record from one loading it; that is the case this check existed to get right.

Negative control

Removing the fit check from the shared function (return None at its head) turns the gate red: 1 failed, 2 passed (EXIT=1), and the failing arm reports the oversized entry as {'ok': True, 'queued': 1, 'refused': 0} — exactly the behaviour the check exists to prevent.

What this node did not do

The plan has the check run inside the shared node-contract function §2 extracts, which both _queue_batch and a single queued dispatch would call. §2 is not in this node's base revision, and the single queued dispatch lives in reckon/crew/dispatch.py, outside this node's write paths, so the check is a named function beside the admission findings and only the batch path calls it. Folding it into §2's function is a one-line call there; a single queued dispatch still reaches the context verdict at launch, as before.
