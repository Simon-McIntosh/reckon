A review waits for its repair

dispatch_review_for_run reads the run's newest stored review through review_lifecycle.lifecycle — the one derivation of whether a stored review is still open — before it composes anything, and refuses the round when that review carries a blocking finding no disposition answers. The refusal names each undisposed finding through repair.blocking_finding_dispositions, with the crew dispose --finding <index> --kind folded|exempted command that answers it, so the coordinator lifts the refusal instead of losing a round to findings the previous review already raised. A review whose run has landed, whose review has been superseded, or whose blocking findings are all disposed falls through to the dispatch unchanged; a plan review and a review of a review carry no node's findings and are left alone. No new duty kind and no second derivation are added: the state comes from lifecycle; the enumeration and the command come from the disposition reader the writer accepts.

The refusal holds a round the repair machinery has already answered unless that machinery records what it answered, so the repair reflex folds too. When dispatch_repair_for_run reads the run's stored review as describing a revision the run has moved past — the round it resumed has landed — it records each open blocking finding of that round as folded into the round, named by the round's node id, through the same disposition writer crew dispose uses. The fold is taken only where the run's own repair-dispatch record says this reflex resumed that round, so a head moved by anything else leaves the findings undisposed and the refusal standing. Both records a round stands for are folded, each finding keyed by the index of the record it lives on, so a figure review's blocking finding is answered on the figure record rather than at a position in the text review's list. Folding at composition time was tried first and rejected: while a round is in flight its findings must keep reading as work, or the retry that resumes a turn which ended unanswered can no longer compose the round it retried.

One source for the dispose command text: review_dispositions.dispose_commands renders the fold and the exemption beside the writer that stores them, and both the duty row in obligations and the refusal in recovery_review_dispatch call it. The selector the two spaces do not share — --finding <index> against --dimension <name> — is passed in, so one function covers both and the duty row's rendered commands are unchanged byte for byte.
