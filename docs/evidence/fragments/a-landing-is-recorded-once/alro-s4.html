§4 — A plan does not close over a section with no landing line

The terminal guard list in validate_landing_patch now carries _require_every_landed_section_answered, so the close op and the merge-patch writer refuse together. A section declared done that states a done-when must hold a landing comment on the section or a committed run record naming it; the refusal names every section it refuses on. A done section that states no done-when is outside the rule. The check is keyed to the transition into a terminal status, so a plan that has already landed stays editable.
