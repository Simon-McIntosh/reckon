What changed

The composed implementation prompt and its brief carrier now state a per-node evidence fragment as optional, naming the two cases it is still written for — a negative result, and a mechanism that does not fit a landing line — and stating that nothing splices a fragment into a plan's landed record. The same clause was mirrored into the build skill, its worker-protocol, sprint-orchestration and coordinator references, and into the edit, create and sprint skills. The closure overview gained a fragment link on each landed node's row, read from the file's presence and carrying none of its text. The manifest check's figure clause now accepts a named figure whose path the run's commits add or modify, so a node that redraws a figure already present at its base is no longer refused.

Measure

The new file tests/test_a_per_node_fragment_is_optional.py holds eight cases: the prompt presents the fragment as optional and names both cases (both carriers), a landing line with no fragment passes the manifest check, a landing line with its own fragment passes, the landing beat records a landing with no fragment in the tree, a section ticked with a close comment that links no anchor is accepted, the overview links a landed node's fragment and contains none of its text, and an existing fragment still renders through the served page's own composer. The figure file gained a redrawn-figure case. Negative control: with the mandatory fragment clause restored to the prompt, the optional-fragment case fails.

Wording held for the pins

Four tests pin the landing sentence by literal — the parity derivation slices the prompt's own constant, the small-node rule must sit directly beneath it, and the ship contract checks the orchestrator stays the only plan-state writer — so the optional clause was written inside that region, ahead of the placement sentence, rather than beside it: every sentence those pins quote is unchanged, and all four pass. The snapshot in tests/test_brief_prompt.py is generated from the composer under the pinned interpreter rather than edited by hand, so it shows the placement and the wording the prompt emits — the splice sentence after the small-node rule, where the product puts it. The exit-record rule beside it is pinned in the wording the prompt actually carries, which is that rule restated, so the pin guards the clause it names instead of a sentence nothing emits; the file's 23 cases pass at this head where 21 passed and 2 failed at the base revision, and reverting the snapshot commit turns the byte-identity case red again.
