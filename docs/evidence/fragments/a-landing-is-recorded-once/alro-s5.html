Closing a sprint writes one page

Closing a sprint now writes docs/evidence/archive/<sprint>-closing.html with one row per member plan. A row states the plan's status, sections landed, runs, worker time and headline result, all taken from reckon.evidence.read_section_landings — the reading each plan's closure overview renders — so the page and the overview cannot state different counts for the same plan. Figures come from the reading's landed figures, whose src is the figure inventory's own row builder, and a row links the plan document only when one exists; a plan with no overview is listed with its status and no link to a record that was never written.

The close guard that refuses a plan over an unlanded section now reads the run ledger once per close rather than once per unanswered section, and refuses a plan state naming no project or slug instead of reading it as a plan with no run record.
