The overview quotes the landing the landed run recorded

_landing_comment reads a section's landing from the run that landed it rather than from whichever comment came last. A c-close-<section> comment still wins where one exists; otherwise the landing is the c-run- comment whose id is derived from the section's latest implementing run, using the prefix constant the promotion writer owns. A review of that run writes a comment on the same section under the same prefix, and the previous fallback quoted that review as the landing — so a section landed by promotion now quotes its own run's landing, and a section whose last comment is a review's still quotes its close comment.

_done_when quotes the whole done-when paragraph. Section bodies are read paragraph by paragraph instead of being flattened, because a declaration cut at its first full stop loses everything after an abbreviation or a dotted path: a done-when naming reckon audit-doc and a record file name was previously quoted only as far as the dot in .html.

The totals block also reads the plan's committed review records under docs/state/<project>/reviews/plan/<plan>/ and states the findings raised and how they were disposed — folded, exempted or still open — each figure cited to the review run that recorded it. Dispositions are read through reckon.crew.findings, which owns their encoding. Two smaller defects close with them: _run_figures holds a figure to the plan's own figure directory using the plan_slug it already took, and the figure address is taken from figure_row, the inventory's single row builder, rather than rebuilt beside it.

Two guards changed under review. The review-comment case now reads a section whose only comments are the landing comment of the run that landed it and a review written after it, so reverting the landing rule reddens it rather than passing on a close comment that both rules would have returned. And a section body is assembled only from the block elements that carry paragraph boundaries — p, li, td; a body authored in a div carries none, and flattening it handed the done-when reader the whole section as one line, so such a body now yields no done-when and a case holds that refusal.
