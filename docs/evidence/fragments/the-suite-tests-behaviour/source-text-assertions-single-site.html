Source-text assertions become behaviour assertions or are deleted

The 14 in-scope test files carried 14 sites reading a module's source (inspect.getsource, __file__).read_text). Ten were removed: four deleted where the behaviour was already asserted elsewhere, and six rewritten to call the code and assert its effect (a sentinel shared parser for the timestamp readers, a sentinel document renderer, and a report-and-apply comparison for the worktree reclamation set). Four remain: three guard a structural invariant no behaviour can show (no literal "ok": True beside a result dict, subprocess use confined to the runner, and which functions read changed_lines), and the fourth is the declared-mutation harness, which imports a mutated module image rather than asserting on source text. Gate: grep -n -e inspect.getsource -e '__file__).read_text' over the 14 files counts 4 against 14.
