Remote reads finish within a bound and retry a blocked SSH route

reckon/crew/merge.py now gives each ls-remote and fetch a 30 s wall-clock limit. A 10 s SSH connect timeout is appended to an explicit GIT_SSH_COMMAND, or added to plain SSH only when no SSH transport is configured. A configured core.sshCommand or GIT_SSH keeps control of the transport, relying on the wall-clock limit. A subprocess timeout returns a failed result that the remote ancestry reader reports as on_branch: null, cause: unreachable. Port-22 connection refusals, timeouts, unreachable networks and missing routes select the existing port-443 retry for both reads and fetches.
