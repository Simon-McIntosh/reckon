A mention costs a flat reference, and a prohibition costs one too

What changed. The context census in reckon/crew/routing.py charged a repository path in a brief at the file's full size whenever it charged it at all, and charged a mere mention nothing. It now charges every path the brief names in prose one flat reference cost — _REFERENCE_COST_TOKENS, 4,000, the same constant a regenerated write path already paid — because a worker either does not open such a file or opens it only to locate it. The three rates are now distinct and named by provenance on each record: declared (a write path or a declared input) pays its size, reference and regenerated pay the flat cost, and granted (the fragment dispatch reserves for the node) pays nothing.

A path in a negative clause is the case the estimator can be certain of, and it is charged as a reference outright: the sentence says the worker will not open the file, so its size was never a load. The declaration reader already withholds such paths from the declared inputs; they now re-enter the estimate at the reference rate rather than at zero. One resolved path is still charged once, at the first provenance that claims it, and write paths are described first, so a contradictory brief that both declares an edit and forbids the read pays the load and never less.

Measured

The differential case estimates one brief twice, identical but for a prose mention of a 1,200,000-byte module. The unnamed brief charges 0; the named one charges 4,000; the file's own size would have been 342,858 tokens. The three briefs recorded from the refusal payloads in the plan's section 1 are re-estimated from their own figures: the declared-write-path brief stays at 161,013 of its 480,000 window, and the two briefs that named the same module in prose fall from 326,217 and 508,965 to 4,000 and 186,748, both inside the lane.
