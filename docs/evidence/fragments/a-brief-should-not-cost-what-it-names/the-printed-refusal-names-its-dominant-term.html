The context refusal dispatch prints names its dominant term

What changed. CompetenceLimit (reckon/crew/node.py) rendered the context-window refusal as the estimate, the window and the shortfall only, so a coordinator under budget pressure was left guessing which input to cut and rationally cut the only field they control. reckon/crew/routing.py already renders that refusal in full — the figures, the contributing files, and how the contribution arrived — into the payload's detail. The printed message now is that rendering, imported where it is used, rather than a second sentence assembled beside it: one renderer feeds the line an operator reads and the payload a reviewer inspects, so the two cannot drift. The origin matters because the remedies differ — a declared write path cannot leave the brief, while a mention can be cut or replaced by a reference — and a refusal in which no repository input is charged says so, because that absence is itself the answer that tells a coordinator the brief is not the problem. A verdict carrying no fit (a hand-built refusal, or one that fell through on another measure) has nothing to borrow and states the figures it carries, so the queue-edit and horizon messages are unchanged. reckon/crew/routing.py is not edited.
