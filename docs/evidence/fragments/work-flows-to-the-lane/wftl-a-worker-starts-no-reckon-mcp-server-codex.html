Workers omit the coordination MCP server

Claude and Clive workers use a private, explicit MCP configuration that excludes Reckon and preserves other user servers and allowed project servers. Codex workers disable Reckon with an override that keeps existing HTTP or stdio transports valid and supplies a complete disabled transport when absent. Omp workers exclude Reckon in their run-owned agent store. Fresh launches, resumes and unfenced launches retain these exclusions; operator configuration is unchanged.
