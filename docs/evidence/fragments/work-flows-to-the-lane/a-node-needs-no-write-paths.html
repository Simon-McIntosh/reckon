Dispatch and the queue accept a node that declares no write paths

A node's worktree is its scope, so the queue no longer asks a node to predict its fence before the code is written. Three points changed and one stayed.

  • reckon/crew/dispatch_batch.py queues an entry that states no write paths when its section states no write-paths sentence, instead of refusing it. The section's sentence still supplies the fence when it states one, and an entry that gives its own paths still wins.
  • reckon/crew/node.py::validate_node no longer fails the scoped property because a node enumerates no exclusive write path. A declared node is judged exactly as before.
  • reckon/crew/node.py::negative_control_writes_a_check reads a node with no declared paths from its done-when: a node whose measure names a test file owes the negative control a declared node owes for the same measure. A declared node keeps the write-path trigger it had.

tests/test_a_node_needs_no_write_paths.py drives all of it through a temporary repository and crew home, over the shared dispatch fixtures the contract and queue suites already use. Six cases hold:

CaseWhat it shows
a batch entry with no write paths is queuedstored with an empty fence
a section stating no write-paths sentence is queueddispatchable from a batch, no path derived
a queued node with no write paths is launchedthe admission pass launches it; the grant it receives is only the node's landing fragment and figure directory
a direct dispatch with no write paths is launchedthe launch door stores and launches it, same grant
a done-when naming a test file owes a negative controlthe mutation is refused at queue time when it is not declared
a declared node is queued with its own pathsstored fence is exactly what the entry declared

Both suite arms ran on all_debug over an extraction of their own revision. The after arm at 868f65ccc reports 6 passed and exits zero; the base arm at 6cb753ef86 collects no test at all, because this node's test file is created by the change, so it measures nothing rather than passing something.

The declared negative control was applied and reverted: restoring the requirement that a section state a write-paths sentence reddens four cases, naming test_a_batch_entry_with_no_write_paths_is_queued, test_a_batch_entry_takes_a_section_that_states_no_write_paths, test_a_queued_node_with_no_write_paths_is_launched and test_a_no_write_paths_node_with_a_test_done_when_owes_a_negative_control. The log is kept in the run directory.
