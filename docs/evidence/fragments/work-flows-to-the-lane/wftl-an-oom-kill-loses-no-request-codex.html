An interrupted admission pass retains every request

Admission now retains its handover until the launched pointer carries its admission stamp. Each handover identifies the admitting process by host, pid and kernel start time. A fresh pass recovers a dead local owner's request under the admission and pointer locks: it restores an absent pointer, adopts an existing worker or supervisor, or returns an unspawned request to the queue. A recorded discard or promotion still ends the request. An owner whose death cannot be proved keeps its handover.

The supervisor checks the current attempt again immediately before spawn. Spawn and the worker receipt share the pointer lock with recovery, so a replacement pass cannot mistake the interval between them for an unlaunched request. A superseded supervisor refuses before opening the stream and writes no exit over the replacement attempt. Worker receipts also identify the supervisor, allowing recovery to retain the process identity used to stop the whole run.
