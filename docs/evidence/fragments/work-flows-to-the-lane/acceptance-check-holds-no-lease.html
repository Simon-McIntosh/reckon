An acceptance judgement leaves coordinator completion available

The bounded sweep workers keep their in-process run claim while judging, and leave the cross-host promotion lease available. Acceptance takes that lease after the commit checks and integrated gate replay pass. Under the lease it re-reads the live delivery, its current head, stored review, manifest and gate evidence before calling completion. A coordinator that completed the run during judgement therefore leaves no second promotion.

A refusal is persisted in the run directory through the shared JSON writer. Its key covers the run and attempt, worktree and checkout heads, review content, manifest and gate-log identities, gate command and commits, and the remote branch tip and commit availability. An unchanged refusal returns its recorded reason without repeating commit ancestry checks or gate replay. The remote tip is still read outside the lease, so a push from another checkout can release the refusal.

Measurements run on all_debug, one arm at a time; importer arms use four workers. Logs carry the revision, command, imported module and working directory, and end with the process exit status.
