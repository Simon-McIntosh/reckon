An execution identity is judged on the host that published it

What changed. reckon/crew/dispatch_claims.py wrote claims/exec-<pid>.identity as a bare token, so both readers of that file — the identity sweep and the dispatch-claim reclaim — judged the recorded pid with the reading node's kernel. The claims directory sits under a crew home every login and compute node shares, and a pid is meaningful only on the node that issued it, so a sweep run here found a live holder on another node dead, removed its identity, and left a later dispatch free to reclaim a claim that holder still held.

The file now carries the publishing host above its token. Two readers parse it through one pair of helpers, parse_exec_identity and read_exec_identity, so the format cannot drift between the writer and the sweep.

The sweep. sweep_exec_identities in reckon/crew/gc.py removes a file whose host is the one running the sweep and whose process is gone or reused there, as before. A file naming another host is kept while it is inside EXEC_IDENTITY_FOREIGN_HOST_MAX_AGE_SECONDS and removed beyond it; a file whose age cannot be read is kept. The bound is a day: the only process that publishes an identity is a dispatch composing a launch while it holds a claim, and the admission pass releases a launch that outlives its token, so a foreign file older than that names a holder that has gone. A file written before the host was recorded carries the token alone, reads as unknown host, and is judged on local evidence exactly as before.

The reclaim decision. _claim_holder_is_alive reads the holder's identity file before it touches the kernel, and a holder whose identity names another host counts as present: this kernel cannot show a pid issued elsewhere gone, and reclaiming on that evidence would leave two dispatches holding one path. The token comparison that distinguishes a re-executed holder is unchanged, and now compares the token half of both sides.

Every arm is a log whose first line names its revision, tree and command and whose last line reads EXIT=<code>. Both arms ran on all_debug, one at a time, no -n.
