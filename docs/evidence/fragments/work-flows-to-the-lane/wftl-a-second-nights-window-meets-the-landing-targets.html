What the instrument cannot read, stated

Neither admission instrument retains a four-hour window. The crew-home verdict log is trimmed to its last mebibyte — 1,047,468 bytes holding 115 passes when read at 22:18Z, about one hour at the pass rate this fleet was writing — and the admit service's own log is trimmed to its last four mebibytes, which had already lost 23:00–03:00 by the time this census ran: at 03:03Z it began at 2026-11-17T21:21:19Z. The window was therefore measured from a spool: the census's --spool-to mode copies every pass the sources hold that the spool does not, keyed on the pass's own instant and lane, and it ran every 90 seconds from 22:26Z to 00:25Z, when the copy loop's service was reaped, and again at 03:03Z. The spool holds 1,183 passes spanning 2026-11-17T18:19:51Z to 2026-11-18T03:03:16Z, of which 618 fall inside the window; the largest interval between consecutive passes inside the window is 409 s (23:33:39Z to 23:40:28Z, a lull with nothing queued), and every 15-minute bucket in the window holds between 17 and 61 passes, so the gap between the last scheduled copy at 00:25Z and the closing copy at 03:03Z lost no pass either source still held. The spool is 10.5 MB and lives in the run directory, not the repository.

The identity figure is a reading of a live directory, and the census now says which it is: a window whose close lies within an hour of the run reports reads_live_state: true (this window does), while a later run over an older window reports false and counts only what survived, because maintenance removes an ended run's identity. That is why §9's window reads 0 today and read 27,854 when its own census ran. On this window the directory was read live: 176 entries, none an identity. The 176 entries also show the directory was listed rather than skipped, and with 150 synthetic identities placed in a temporary claims directory the same code reports 150 against the bound of 100, so the zero is an absence rather than a blind filter.

Verdict

Two of the section's four figures hold: no admission pass held a request on a shared-root claim, and the claims directory held no identity file at the window's close.
