A worker's fence admits its whole worktree but the paths git cannot merge

A node that declares no write paths is granted its whole worktree, because a worktree isolates every edit and the merge reconciles them. What remains sealed is the set git cannot merge textually: a plan document, generated state, a cumulative evidence record, a figure topic directory and a dependency lock. The fence overlays each of those read-only after the run's writable grants, since a grant is the last word on its own path, and the composed launch records the pattern that governs each sealed path so a refusal can name it. A node that declares write paths seals none of them, and its fence is composed exactly as before. Dispatch and both resume paths pass the patterns only when the node declares nothing.
