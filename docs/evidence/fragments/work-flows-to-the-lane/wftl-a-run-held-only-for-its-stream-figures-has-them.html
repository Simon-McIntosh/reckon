A run held only for its stream figures has them recorded

At assigned base bc378cd9a3ce, 2,709 ledger rows across the four projects carried neither tool_steps nor orientation_input_tokens, and retention withheld every one of their run directories as missing-derived-figure. An independent on-disk census counted, per project, the rows whose run directory still holds a stream and whose run directory holds none; every one of the 2,709 rows holds a stream, and none has lost it.

The backfill that derives both figures from a run's own stream — scripts/derive_run_figures.py — had been run for reckon's own rows only. Run for these four, it filled 1,298 rows in nova, 1,081 in imas-codex and 326 in imas-ambix, with zero skipped for a missing stream and zero unmeasurable. imas-standard-names' 4 rows were not filled by that pass: the first attempt against that checkout's read-only working tree had already written them (gate-fill-attempt.log, rows_filled 4), so the full pass that followed reported rows_filled 0 for the project (gate-fill.log). The two passes together leave 2,709 rows carrying their figures, so the recorded count equals the census's stream-present count and the recorded-absent count equals its no-stream count of zero.

tests/test_a_held_runs_stream_figures_are_recorded.py plants three old runs in a temporary crew home. The first has its stream on disk and must read back on its row the two figures the routing derivation computes from that stream (1,200 charged input tokens before the first declared-scope edit, three completed tool items); the second has no stream and must record both figures as a present null rather than a zero, which retention then treats as reapable; the third is the negative control, where skipping the write leaves retention withholding the same directory.

What remains. The ledger writes are uncommitted: they live only in each project's working tree under docs/state/<project>/, and this run's git grant reaches its own worktree alone, so a mutating git verb aimed at another checkout is refused. Counting the rows that carry a non-null figure gives, at each checkout's HEAD against its working tree, nova 828 vs 2,126, imas-codex 278 vs 1,359, imas-ambix 273 vs 599 and imas-standard-names 3 vs 7 — differences of exactly the per-project fill counts above.
