A run held only for its stream figures has them recorded

At assigned base bc378cd9a3ce, 2,709 ledger rows across the four projects carried neither tool_steps nor orientation_input_tokens, and retention withheld every one of their run directories as missing-derived-figure. An independent on-disk census counted, per project, the rows whose run directory still holds a stream and whose run directory holds none; every one of the 2,709 rows holds a stream, and none has lost it.

The backfill that derives both figures from a run's own stream — scripts/derive_run_figures.py — had been run for reckon's own rows only. Run for these four, it filled 1,298 rows in nova, 1,081 in imas-codex, 326 in imas-ambix and 4 in imas-standard-names: 2,709 rows, with zero skipped for a missing stream and zero unmeasurable, so the filled count equals the census's stream-present count exactly and the recorded-absent count equals its no-stream count of zero.

tests/test_a_held_runs_stream_figures_are_recorded.py plants three old runs in a temporary crew home. The first has its stream on disk and must read back on its row the two figures the routing derivation computes from that stream (1,200 charged input tokens before the first declared-scope edit, three completed tool items); the second has no stream and must record both figures as a present null rather than a zero, which retention then treats as reapable; the third is the negative control, where skipping the write leaves retention withholding the same directory.
