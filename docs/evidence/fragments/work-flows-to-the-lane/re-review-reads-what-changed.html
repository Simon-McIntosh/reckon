A re-review reads only what changed since the review before it

What changed

A run that is reviewed, repaired and reviewed again was composed a brief by the same reflex that composes its first: the whole run, its goal, its gate and its declared checks. Nothing in it named the head the earlier review stood on, the commits the repairs added, or what that review had found. A second reviewer therefore re-read work already judged, and could not say whether the repairs answered anything.

reckon/crew/recovery_review_subject.py gains reviewed_commits, which lists the revision and subject of every commit in older..newer through git, and _re_review_block, which composes four parts: the previously reviewed head, the commits since it, each earlier finding with the disposition recorded against it, and the ask that every earlier blocking finding be answered against the new head. Findings are read from the stored record of the head the earlier review read, enumerated in their stored order so each index resolves through reckon.crew.findings.finding_disposition — the shared renderer, so a disposition kind another node adds flows through unchanged. Two failures stay distinct from "nothing changed": git failing to list the range and an unreadable record are each stated in the brief rather than rendered as an empty section.

The block is composed only when the reflex passes the light re-review's own head-move decision as delta, so a first review's brief is byte-identical to the one it carried before. The head-move decision is unchanged: a move that changes no runtime source still carries the review forward, and only a move that does composes this brief.

Measure

tests/test_a_re_review_reads_what_changed.py builds a real git repository holding a run reviewed once and repaired by two commits, stores that review with two findings and one answer against each, and composes the brief through the reflex's own head-move call and the composer it dispatches with. It asserts the brief names the previously reviewed head, exactly the two repair commits and no other, both findings with their dispositions, and the ask; and that the same run composed as a first review names none of them.
