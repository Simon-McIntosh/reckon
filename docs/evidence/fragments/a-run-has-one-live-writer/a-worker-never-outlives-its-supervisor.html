A worker never outlives its supervisor

signal_worker gains reach_run: it ends every process a run owns, found by descent from the run's recorded supervisor and worker pids and by RECKON_RUN_ID in each process's environment, and returns the pids ended. Every run-ending caller inherits the reach, because the identity-checked signal takes the run id from the run directory it is handed and reaches the whole run from there; a caller holding only a pid to stop, with no run of its own, keeps the single-pid behaviour. An unreadable environment and a bare worktree holder are never signalled. crew stop reports the pids ended, the survivors and the worktree holders; the supervisor's exit record names the pids its signals reached; a run whose supervisor and recorded worker pid are gone but whose environment mark lives reads alive, so it is no longer classified complete or scoring.
