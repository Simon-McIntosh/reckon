A deadline needs no time zone

The deadline statement now hands the worker one command that answers how much time is left, so it never compares two clock readings. time_fence_statement in reckon/crew/prompts.py states the command and tells the worker to judge the deadline only by it, naming file times and log stamps as readings that may print in the host's local zone. The command reads the deadline's epoch through date -d … +%s and subtracts the current epoch, so its answer carries no zone; where a hard stop differs the command prints the seconds to each.

The first attempt now takes the grace multiple from its single owner: dispatch.py passes resolved_grace_multiple(config) — the resolver the watchdog and the resumed fence already read — instead of parsing the raw fences.budget_grace_multiple a second time in prompts.py, so the first attempt's hard stop and the watchdog agree on the instant.
