Contain the served entry point's memo write within its own test

Mechanism. serve.main runs on the fixture's daemon thread and assigns the discovery walk-reuse window at reckon/serve.py:3399 (_SIGNATURE_TTL_S = _served_signature_ttl(), global declared at :3397). The fixture stopped the server and the fleet watch but never joined that thread, so a write could outlive the fixture's teardown. The fixture no longer relies on monkeypatch's undo for this global — monkeypatch restores _SIGNATURE_TTL_S to whatever it read at setup, which cannot be ordered against the daemon thread's write.

Fix. _ServedEntryPoint.stop() joins the served thread (bounded by _THREAD_STOP_S) before teardown returns; the fixture then restores the module to the library default 0.0 and asserts it is 0.0. Only tests/test_server_listens_before_it_watches.py changed, 32 insertions and 1 deletion.

Measure. At base, the pair (tests/test_server_listens_before_it_watches.py and tests/test_tag_inventory.py, one process, -p no:xdist) passed 3 of 3 in each order and the base failure did not reproduce; a probe logged _SIGNATURE_TTL_S=60.0 inside the server test's call. The write was measured at t=0.009 s, before the fixture's teardown at t=0.039 s, and the thread had stopped by then — the surviving write is the race the unjoined thread permits. After the fix the pair passed 5 of 5 in each order, and a probe logged _SIGNATURE_TTL_S=0.0 after every server test's teardown in all 10 runs. Dropping the fix in a scratch tree fails the teardown check on all three server tests and then fails the tag-inventory test on the live memo (KeyError: 'invented-during-test').
