Contain the served entry point's memo write within its own test

Mechanism. serve.main runs on the fixture's daemon thread and assigns the discovery walk-reuse window at reckon/serve.py:3399 (_SIGNATURE_TTL_S = _served_signature_ttl(), global declared at :3397), value 60.0 via _SERVED_SIGNATURE_TTL_S (:953). The fixture stopped the server and the fleet watch but never joined that thread, so the assignment could outlive the fixture's teardown. The fixture no longer relies on monkeypatch's undo for this global: monkeypatch restores _SIGNATURE_TTL_S to what it read at setup, which cannot be ordered against the daemon thread's write.

Fix. _ServedEntryPoint.stop() joins the served thread (bounded by _THREAD_STOP_S) and asserts it is no writer that remains (assert not self.thread.is_alive()); the fixture then restores the module to the library default 0.0 after that join. An earlier teardown assertion compared the memo with the 0.0 the fixture had assigned on the preceding line and could never fail; it was removed. Only tests/test_server_listens_before_it_watches.py changes.

Measure. Log paths below are relative to the run directory. In a scratch tree whose serve.py defers the memo assignment until after its servers stop serving, the three runs are: base, logs/repro-base.log, 1 failed, 3 passed — the tag-inventory test starts with _SIGNATURE_TTL_S=60.0 and test_discovery_derives_tag_inventory_from_every_resource_type fails on the live memo; control (the join removed, the thread-alive check kept), logs/repro-control.log, 1 failed, 3 passed, 3 errors — the check assert not self.thread.is_alive() fails each server test, then the tag test fails; fix, logs/repro-fixed.log, 4 passed, the tag test starting at _SIGNATURE_TTL_S=0.0. The gate in the worktree — tests/test_server_listens_before_it_watches.py with tests/test_tag_inventory.py, one process, -p no:xdist, five runs in each order — is 10/10 EXIT=0, the memo 0.0 after every server test's teardown.
