Read the served checkout's identity from its package

Mechanism. The stale-code guard asks, on every MCP call, whether the checkout's code has moved behind the running image. reckon/mcp.py:_import_root() returns the checkout root (Path(__file__).resolve().parent.parent) and reckon/served_code.py:moved_checkout passed that root to checkout_trust.source_code_identity(package_dir), which identifies the package directory and derives the source root from package_dir.parent. The package's committed identity was therefore compared against the stamp of the directory above the checkout and never matched, so every checkout read as moved and the guard routed every call to the served child.

Reproduction at the base. The seven ids fail at dea3758c1 and the first failure prints the guard's own refusal: {"ok": false, "error": "stale_server_code", ... "code stamp 7c2e16eef187 to fd365f2f4ab0"} for a tree that has not moved. The production crew read measured below reports moved: true at the base and is answered by the served child from the second call on.

Fix. moved_checkout reads the identity from the package inside the checkout (root / "reckon"), the way the running stamp is read at import, so an unmoved checkout reads as unmoved. The trust check is unchanged and unchanged in its argument: it already takes the checkout root. One test change follows from the intended contract the sibling case already documents: the persistent child is warmed by its readiness probe, and a call made while it is cold is served by the running image, so the clean moved-checkout case now waits for the probe before asserting the answer the current code served. Its assertions are unchanged. A new case asks the same guard two questions and asserts its answers: an untouched committed checkout reads as unmoved, and a checkout whose package a commit has changed reads as moved. The expected stamp is not recomputed here — a child interpreter imports the package from the checkout and prints the stamp a server records at start, so the case compares the guard's answer against a stamp the guard did not produce.
