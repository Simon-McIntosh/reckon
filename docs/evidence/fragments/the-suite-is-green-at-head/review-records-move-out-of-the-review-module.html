The review-record store family leaves the review module

Cause. tests/test_every_module_fits_a_worker_window.py failed at main on reckon/crew/review.py, which had grown back over the 50,000-token bound after an earlier split: 185,459 bytes, 52,989 estimated tokens by reckon.crew.routing._tokens_for_bytes at base c66a1ced9. A module that fills most of a window makes any node that must write it unfittable.

Deliverable. The committed review-record store family moved to reckon/crew/review_records.py: reading a run's record committed-first then from staging, selecting the copy a named head names, unioning the disposition and answer fields every copy of one review run carries, writing a record and committing that write, and the per-directory store index behind the misfiled and delivered-plan-review lookups. reckon/crew/review.py keeps read_review and re-exports the names callers resolve through it, so no importer changed.

Measure. At head, reckon/crew/review.py is 144,747 bytes — 41,357 estimated tokens — and reckon/crew/review_records.py is 43,789 bytes — 12,512 estimated tokens, against bounds of 45,000 and 40,000. The width test names neither at head; only reckon/ledger.py (52,989 tokens) is still over, which is the sibling §32 node's module and not this one's.

Patch semantics. The store resolved its shared schema constants, path builders and revision helpers as module locals, which silently broke every caller that patches one of them on reckon.crew.review — test_a_review_with_no_base_is_not_carried.py patches review_store_root, and a head arm showed 18 added failures across six files before this was corrected. The family now looks those names up through the review module at call time, which restores the patch semantics the split must preserve; the names the family defines itself stay module locals, so a patch on a moved name is applied where the moved code reads it.

Negative control. Restoring reckon/crew/review.py to its base content in a scratch copy of the head tree turns the width test red again, naming reckon/crew/review.py: 52989 estimated tokens exceeds the 50000 bound and is not allowlisted (exit 1). The log is negative-control.log under the run directory.
