Every edit path reports a refusal in one shape

Change. _changed_targets in reckon/mcp_edit_plan.py built the conflict's changed_targets from set ops alone, so a collision met through an append, resolve, lock, accept or gate verb answered without the targets it addressed and its refusal shape depended on the verb the caller chose. _op_target_path now composes each verb's address from the op's own identifying keys — an explicit path, a collection plus the record id, a decision key, a gate id — and _value_at_path resolves a two-part list address to the record it names, so the value the document holds is read back for every verb whose target exists. The composed table is declared in TARGET_COMPOSED_VERBS and a case compares it with _store._OP_DISPATCH, so a verb added to the store cannot quietly lose its target.

Measure. The listed id tests/test_every_edit_path_refuses_one_shape.py::test_the_refusal_shape_is_identical_across_op_paths fails at the base arm (1 failed, 59 passed, EXIT=1) and passes at the head arm (63 passed, EXIT=0). The case drives one op per addressing family — comment append, decision lock, followup resolve, gate verdict and state set — each naming a target the seeded document holds, and checks the current value back against the document unconditionally; a separate case pins the documented rule that an insert of a new record names its path alone. Both arms are git archive extractions on node-local disk run with the same command over the gate, every test file that imports the changed module (reckon.mcp_edit_plan: test_a_lost_race_is_refused_not_raised, test_a_malformed_request_is_refused_before_storage, test_a_retried_partial_move_is_not_replayed, test_an_added_parameter_needs_no_reconnect, test_mcp_server_serves_current_code), the case that pins the conflict contract (test_a_refused_write_names_the_next_step) and the writer-race case (test_landing_write_races_every_writer). No failure is added. ruff check and ruff format --check report nothing added on the two staged paths (7 pre-existing findings at the base arm, 7 at the head).
