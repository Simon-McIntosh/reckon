Every edit path reports a refusal in one shape

Change. _changed_targets in reckon/mcp_edit_plan.py built the conflict's changed_targets from set ops alone, so a collision met through an append, resolve, lock, accept or gate verb answered without the targets it addressed and its refusal shape depended on the verb the caller chose. The new _op_target_path composes each verb's address from the op's own identifying keys — an explicit path, a collection plus the record id, a decision key, a gate id — and _changed_targets resolves each against the document the store holds. The shape case now compares the refusal across op paths apart from changed_targets, and requires each path to name its own targets with the value read back off disk, because those targets differ between kinds by construction.
