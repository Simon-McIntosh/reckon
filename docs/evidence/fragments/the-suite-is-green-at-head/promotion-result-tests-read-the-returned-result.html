Promotion-result tests read the result promotion returns

Cause. Three shipped changes altered the values these ten tests read, and each change was intended. The release outcome now lands through the landing owner and carries that landing's own check on the returned receipt. A refused landing commit now takes back every write it made, so an interrupted landing no longer leaves its plan comment on disk. A review promotion now names which delivery condition it refused, instead of one generic sentence. Each test pinned the older value, so all ten failed while the production behaviour was the one the commits described.
