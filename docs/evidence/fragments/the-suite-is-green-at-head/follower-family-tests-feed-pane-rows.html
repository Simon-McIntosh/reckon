follower-family-tests-feed-pane-rows

Outcome. The pane delivers an observed session's rows and the own session's start past the observer-context hold — commit 36f853918 feat(crew): deliver an observed session's rows and the own launch start, in reckon/crew/ticker.py and reckon/crew_follow_commands.py. The follower family then feeds rows a live pane actually delivers: commits b9ad4075d and 13bc76841, which supersedes the earlier attempt to park the observing cases' own run at dispatched. The fifteen named ids pass alone at head — 24 passed, 0 failed, EXIT=0 (logs/thirteen-ids-2.log), and tests/test_follow_settled_rows.py and tests/test_row_policy_holds_observer_context.py are inside that run.

Cause, named. The family's cases built the row they awaited out of a launch the pane had already read as working. The pane's live baseline derivation reports a run as (None, working) whatever its pointer's phase — measured for a pointer at phase = "dispatched", which the row path fed as from_state=None, to_state=working. A start arriving afterwards for that same run is therefore a re-announcement, and RowPolicy's state-dedup guard drops the launch (dispatched, working) as one. So the cases were waiting for a row a live pane never makes, and the failures were the fixture's premise rather than the delivery: fed directly, with no prior baseline, the row path delivers that same start, and the follower's own selection admits it.

Repair. The source delivers what the pane is asked about. A row belonging to a session the pane was told to observe is printed however the classifier classes its kind (_is_observed in RowPolicy.feed), and the own session's start is recognised for both start pairs — a fresh launch's dispatched → working and a resumed attempt's starting → working (_is_own_start, START_KINDS) — and the follower's row path is built with the naming it needs to make either decision (follower_row_path, which now passes own_session and observed_sessions to PaneRowPath). The family's cases now arm first and feed the move the run makes after the arming, so every delivery they measure is one a live pane makes; the observing cases gate the write of their own run's arrival on the checkpoint a finished first arming leaves. Each case that measures a delivery counts the rows before it asserts their shape, because the shape assertions are quantified over what was delivered and an empty list satisfies every one of them.
