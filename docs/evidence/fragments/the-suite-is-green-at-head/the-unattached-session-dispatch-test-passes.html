The unattached-session dispatch test passes at head

Cause. The test passed its own assertions and then failed in its finally. A dispatch arms the project's watch producer before the delivery admission refuses a session that cannot hear the run, so the refusal leaves a live producer behind. The teardown stopped it with recovery.unwatch. The producer rewrites its seat registration in place (truncate then write), and unwatch refuses to signal a seat whose record names no project — so a release landing in that window raised CrewError: refusing to stop watcher for project 'sample': the locked registration names ''. The refusal under test — a dispatch refused where a manual one is — was correct throughout.

Why it is host-dependent. Arming differs by host. On the fleet node the producer is spawned by the allocation's batch step; on a plain compute node a supervisor is spawned first (subprocess.Popen) and writes the producer's seat later, widening the window the teardown read into. Measured: with the cause present the test fails 5 of 5 alone in an exclusive all_debug job (job 1291645, host 98dci4-clu-3141), and passes 5 of 5 alone on the fleet node.

The same teardown, three times. All three tests in the file that release the watch seat did it the moment watch_state reported a live producer, so each was exposed to that window. The exposure is real rather than theoretical for the two dispatch tests: an instrumented run that restores the immediate release records a live seat at teardown for both, i.e. both do reach unwatch (fleet-negprobe.log). Neither reproduced the failure in 5 runs on an exclusive all_debug node with the cause restored (job 1291667), and the reason is visible in the ordering: those two carry a long test body between the arming and the teardown, so the registration has settled by the time they release, while the refusal returns from arming in one step and the teardown follows it immediately.

Repair. One shared helper serves all three teardowns. It waits, bounded, for the seat registration to settle to name its project before calling unwatch, then waits for the producer to release the seat. No product code changed.
