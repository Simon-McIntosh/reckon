An overdue duty test pins its clock

Change. The obligations fixture in tests/test_an_obligation_never_offers_a_promotion_past_a_blocking_finding.py pinned obligations._utc_now only. The review-duty row is built by obligations._classified_rows, which calls recovery.classify_pointer(pointer) with no now_seconds, so the classifier read recovery_classification._utc_seconds() — the wall clock — and the run's age was never the instant the fixture supplied. The fixture now pins that boundary to the same instant, and the module states its pin as IMPORTED_AT + timedelta(minutes=2) rather than at import time, so the pinned clock is demonstrably not the wall clock.
