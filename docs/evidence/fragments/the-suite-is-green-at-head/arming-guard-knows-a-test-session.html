arming-guard-knows-a-test-session — the watch-arming guard refuses a producer from any pytest session, whatever its basetemp is called

Defect. _refuse_arming_under_a_throwaway_home (reckon/crew/dispatch.py) stood down whenever the resolved configuration home did not sit under a directory whose name matched _PYTEST_TEMPORARY_ROOT (^(pytest-of-.+|pytest-\d+)$) — pytest's default base temp. A session given an explicit --basetemp whose directory carries no pytest name, such as /tmp/anything, therefore armed a detached crew watch producer that outlives the run and polls a home the session is about to delete. The suite worked around this by planting a pytest-named directory above each home it places under a custom base temp (repair merge b5f20abe8), so the guard's rule and the test's scaffolding disagreed about which temporary root is pytest's.

Fix, one commit. The guard now recognises the throwaway home from the running pytest session as well as from a pytest-named ancestor. _running_under_pytest reads PYTEST_CURRENT_TEST/PYTEST_VERSION; _declared_basetemp reads the temporary root the session declares on its own command line (--basetemp=X or --basetemp X) from this process and its ancestors' /proc/<pid>/cmdline — the process itself in a serial run, the session master under pytest-xdist, whose workers carry argv ['-c']. _temporary_home_root returns the declared root when the home lies under it, which is a path test on both sides: an ordinary home outside the declared root is still armed, so the guard stays bound to the throwaway home rather than to pytest itself.

Evidence. tests/test_arming_guard_knows_a_test_session.py: 4 passed, EXIT=0. The refusal case drives a real child pytest session with --basetemp at a directory directly under the system temp root (no pytest name), places RECKON_HOME inside it, removes RECKON_WATCH_ARMING, and reads the guard's verdict from disk: the guard refuses, naming the root and outlive. The ordinary-home case clears the session markers and asserts the guard does not raise. Two unit cases pin the parsing and the root boundary (a home outside the declared root is not a throwaway).
