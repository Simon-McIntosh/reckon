A classification read creates no run directory

Cause. The classification memo was moved into each run's own directory and named there classification.json. classify_pointer writes that memo at reckon/crew/recovery.py:7069, and the writer created its parent directory unconditionally (path.parent.mkdir(parents=True, exist_ok=True)). Classifying a pointer is documented as a pure read, but it had acquired three effects on disk: a run directory that did not exist was made, an empty one was filled with the memo, and either way the run appeared to have a durable home it never had.

Decision, per id. Both named ids are red because the shipped change is wrong, not because their fixtures are stale — neither test was modified.

  • tests/test_a_discard_never_reads_promoted.py::test_a_discarded_block_never_reads_promoted — the pointer has no run directory. Classification created one, so crew.discard found a directory and wrote its discard.json marker into it, and the departure folded as discarded instead of the withdrawn a pointer that only vanished earns.
  • tests/test_crew_discard_reads_discarded.py::test_a_discard_leaves_no_record_when_its_run_directory_is_gone — the fixture makes an empty run directory, classifies (the memo filled it), then rmdirs it. The rmdir found it non-empty.

Fix. _write_classification_memo now writes only into a run directory that already holds the run's records: if the directory is absent or empty it returns without writing. A read therefore creates or fills no run's home, while a run with records in its directory still keeps its memo. An empty directory has nothing for the memo — the cache of the run's own records — to cache.

New case. tests/test_a_classification_read_creates_no_run_directory.py holds the rule from three sides: a pointer with no run directory is classified and left with none; an existing empty directory is left empty; and the positive control — a directory holding a run record still receives the memo — shows the guard skips an empty home rather than disabling the memo for every run.
