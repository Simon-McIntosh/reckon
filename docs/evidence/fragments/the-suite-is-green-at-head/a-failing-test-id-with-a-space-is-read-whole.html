A failing test id with a space is read whole

Change. _GATE_FAILURE_RE in reckon/crew/review.py captured (\S+), so a pytest summary id was cut at the first space. It now captures the rest of the line, and _pytest_failure_ids takes the id up to pytest's " - " reason separator or the end of the line, trimming surrounding whitespace. The ctest reader is untouched.

Measure. A space-free id and a no-reason line read as before. Gate: 23 passed, EXIT=0, in logs/gate.log; ruff check and ruff format --check add no findings on the two changed Python files (logs/ruff.log).
