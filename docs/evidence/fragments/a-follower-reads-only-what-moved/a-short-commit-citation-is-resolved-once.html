Commit abbreviations reuse the bounded resolver cache

reckon/crew/recovery_review_subject.py now remembers a hexadecimal candidate of at least seven characters only when the resolved commit starts with that candidate. Successful answers reuse the existing process cache and the answer store in recovery_watch. Misses stay only in the process cache, against git_head._head_identity; a moved HEAD causes another query. Strict callers continue querying git on every call, and ref names and nonmatching hex refs are not retained.

The implementation is committed at c012ec2bd8b1c9f6615b803ab97bbe6710580124. The eight tests in tests/test_a_short_commit_citation_is_resolved_once.py use temporary git repositories and count resolver subprocess calls.
