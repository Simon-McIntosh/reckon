The lanes view says what the coordinator's own share of the lane is, and how old that answer is

What changed. crew(view="lanes") already attached the parsed lane document to each lane row, so a coordinator could read the lane's headroom and verdict but not its own position in it. Given session=..., the view now also carries a top-level session_share block:

fieldwhat it is
worker_slots the session's published share, read through obligations._published_worker_slots — the same function a dispatch refusal quotes, so the read and the refusal cannot disagree about one number
live_runs the router's count of the session's live runs, or "unknown" when the router has listed no entry for it — an absent entry is not a zero
observed_at, age_seconds, shelf_life_seconds the local lane document's own vintage
stale, detail a document past the shelf life it publishes is marked stale, with the age that disqualifies it in words

One carrier. crew(view="directory") and ready_set_view copy no figure of these; the block is served only when a session is named, and a stale document is marked stale rather than inherited as current. No view is added.

One unreachable derivation retired. _ready_set_coordinators read the crew's plan-coordinator derivation whenever the ready-set view was asked for the filtered set with no coordinators passed. Its only production caller (reckon/serve.py) never asks for the filtered set, so the branch and its swallow-all fallback could not run: the view now takes the coordinator rows it is given and reports none otherwise, and the crew's derivation stays the one statement of who owns a plan. The ready-set view's existing cases still pass.

Measured

tests/test_the_lane_share_lives_on_the_lanes_view.py, seven cases, with the lane document placed through RECKON_LOCAL_LANE_DOCUMENT so no test reads the workstation's real lane. On a document listing the calling session at worker_slots: 7, live_runs: 2, observed five seconds before the composition, the block reads worker_slots == 7, live_runs == 2, observed_at equal to the document's stamp, age_seconds == 5, stale is False; and worker_slots equals a direct call of _published_worker_slots(SESSION), so the block is not a second reading. A session the router has not listed reads live_runs == "unknown", with the share falling back to the lane-wide figure exactly as the refusal does. With the document observed past its own 45-second shelf life the block reads stale is True at age_seconds == 46; a document publishing no shelf life reads stale is False with "no shelf life" in its detail, because unjudged freshness is not freshness.

The gate (tests/test_the_lane_share_lives_on_the_lanes_view.py plus tests/test_mcp_tools.py) passes, 42 passed. The base arm — the existing suites that cover the changed module, run over the base revision in a scratch extraction — is 92 passed, EXIT=0, so the change adds no failure against its base.

Negative control. The declared mutation drops the staleness comparison ("stale": False in place of the document's own reading). The stale-document case then fails — 1 failed, 6 passed, EXIT=1 — because nothing else in the block looks at the age, while the unmutated head passes all seven.
