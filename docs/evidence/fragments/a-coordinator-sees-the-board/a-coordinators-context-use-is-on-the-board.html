What landed

Every coordinator row the directory lists now carries context_use: the context the session had used at its last turn, the window its model runs in, and the fraction between them. The figure is the charged input of the session's last assistant request — uncached input plus cache creation plus cache read — read through _charged_claude_tokens in reckon/crew/dispatch_accounting.py, the same rule that records coordinator.authoring_turn at dispatch, so the board's figure and the dispatch record cannot disagree about what a turn cost.

The transcript is the one a dispatch already reads, named after the session the live pointer already carries, under ~/.claude/projects/*/<session> .jsonl. One walk of that root resolves every session on the board (_session_transcripts), taking the newest transcript where a session is recorded under more than one working directory. The last request is read from the end of the file (_last_assistant_request): the read starts at 256 KiB, grows to 1 MiB and then 4 MiB, and falls back to a forward scan when the request sits deeper. Measured on this workstation, eight live coordinators resolved in 20 ms in total, so the board's cost is the read it already made rather than a parse of half-gigabyte session files.

Three states are kept apart, because collapsing them is how a series reports a measurement it never took. A session with no transcript reads unmeasured with no figure and no window. A readable transcript whose assistant records charge nothing reads unmeasured with its own reason. A model with no declared window keeps its measured use, carries window_tokens: null, and reports no fraction rather than a guessed one. No case returns zero: zero is the measurement of an empty context.
