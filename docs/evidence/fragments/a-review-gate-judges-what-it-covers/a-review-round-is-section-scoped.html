A review round traces the sections asked and carries their whole history

Work is dispatched one section at a time, but the re-review brief was drawn from the whole plan's history: newest first, capped at twenty findings across every section, each cut to 280 characters. On 2 November the re-review of three sections of a plan with 79 stored findings received twenty, most about sections the round was not asked to build, while earlier findings on the sections in scope were pushed out by the cap. The round then re-traced code it had not been asked about and lacked the history of the code it had.

crew review --plan <slug> --section sN (repeatable) composes a review scoped to the named sections. The brief carries the whole plan's text, names the units whose code is traced and says that no other section's code is, and carries every prior finding from every stored review of that rubric whose unit is one of them — in full, with the answer it was given and that answer's note, with no cap and no truncation. Findings about units out of scope are absent. A plan with no stored review under the rubric widens the scope to every unit and says so in the brief; a scope naming a section the plan does not carry is refused naming the sections it does carry, rather than narrowing to nothing.

The scope is recorded on the delivered sidecar under traced_units and carried onto the stored record, and review_coverage now reads it: a record naming traced units contributes coverage only for those, is never taken as a whole-plan fingerprint cover, and its recorded acceptances cannot cover an untraced unit either. So a section a scoped review read only for consistency is still uncovered afterwards, which is the difference between reading a plan and reviewing a section of it. reviews_for_unit_burst reads the same key, so a scoped review counts toward a unit's review budget only for the units it traced. The scope rides a context variable set around the composition — the CLI and the composer between it and the brief writer take no scope parameter — set only by a composition, so every read composes as it did.
