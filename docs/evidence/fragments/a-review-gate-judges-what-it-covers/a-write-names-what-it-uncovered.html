A write names what it uncovered

review_owed on a plan write is the plan's whole review debt: a stored review leaves a unit uncovered until its prose is reviewed again, so set sprint, close or a comment write returned inherited debt that read as though the write had caused it. Every plan write now also answers with uncovered_by_write — the units this write moved from covered to uncovered — beside the unchanged review_owed and review_invocation.

Coverage is a function of the plan's content, and _review_owed_fields runs only after the write, so _edit_plan_tool in reckon/mcp_edit_plan.py reads the plan's coverage before the write through a new _uncovered_before_write and passes that set into _review_owed_fields in reckon/mcp_deadlines.py.
