A node is gated on its own section

The dispatch gate already narrowed coverage to the units a request reads — its own section and the document unit — but the document unit's digest folds the plan's remainder prose together with its summary, decisions and gates. Editing a note between sections therefore uncovered the document unit and held every node whose own section a review covered. The gate now drops the document unit from a node's hold when the change is confined to text that is no node's contract, and the refusal names every uncovered unit again rather than only the ones the node reads.

plan_review_units in reckon/crew/routing.py remains the one definition of the units a dispatch reads, and plan_review.review_coverage remains the one coverage predicate. In require_plan_reviewed, the uncovered set is kept whole for the refusal, and a gating set is filtered to the caller's scope. When the document unit falls inside that gating set, _document_change_is_contract compares CONTRACT_DOCUMENT_FIELDS — summary, decisions, gates — between the present plan and the snapshot recorded by the newest stored review that read the document unit; a change confined to the remainder leaves the unit out of the hold, a contract change keeps it in, and a review with no readable snapshot falls back to holding the node.
