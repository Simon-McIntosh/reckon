An answer says what was done

reckon crew review --answer <id> --acted now requires --note "<what changed>", and the MCP answer action takes the same note as note. The note is stored on the finding's response, read back by plan_review._stored_response, and printed by the next review brief in place of a bare -> acted, so a reviewer reads what the fix changed instead of re-deriving it from the diff. A note without an answer is refused naming --answer: composing a review with one dropped it silently and reported a review of a finding nobody answered. Every acted-answer example in the build, create, edit and review skills names the note.
