The skills teach the write-time review, and the build skill no longer waives it

The authoring skills now state one rule: the session that writes a plan reviews it before it leaves. skills/reckon-create/SKILL.md Step 4.5 and skills/reckon-edit/SKILL.md rule 9 each say, once, that when the authoring burst ends the writing session composes one content review, answers every finding before it leaves the plan — fixing it or declining it with a reason — and only then releases, and that an answered finding's edit is covered by that finding's review only while it leaves the section's done-when paragraph unchanged and stays under the change threshold, so an answering edit of that shape starts no new round while an edit to a done-when owes one scoped to that section. Each gives the reason it is the writer rather than a later coordinator: the writer still holds the context to fix what a finding names.

The build skill relied on that review already and never composed it, but it left a coordinator free to answer content findings it did not own. skills/reckon-build/SKILL.md now says a coordinator does not compose the content review and does not waive the gate: when one is owed it hands the plan back to its writer, or lets the producer's backstop compose it, and dispatch waits for the answer. Answering is scoped to the design review, which the build skill itself composes.
