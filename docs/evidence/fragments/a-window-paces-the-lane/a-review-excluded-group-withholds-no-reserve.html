A group that cannot serve reviews withholds no bookend reserve

The bookend reserve is lifted for a declared wallet whose every member the configuration removes from review routing, and the key that sets it becomes a declared BudgetConfig slot a flight layer can write.

Landing

bookend_reserve_pct is now declared in BudgetConfig (reckon/schema/flight.yaml, regenerated into reckon/_flight_schema.py), so a flight layer may set it. A declared budget group whose every member appears in review_excluded_backends withholds no bookend reserve: budget_group.group_figures reports reserve_pct == 0, and an implement dispatch judged through dispatch_admission._refuse_against_the_bookend_reserve reaches the group's full ceiling. A group with one review-capable member keeps the configured reserve, read from the configuration at assertion time.

The negative control forces the all-members-review-excluded predicate to return False; the all-excluded assertions then fail (2 failed, exit 1). The public test suite at head passed 215 tests with exit 0; the base arm over the pre-existing gate files passed with exit 0, so the node adds no failure.
