The reserves read the lift

One composition function resolves a lift against the review-exclusion rule, and the three readers of a group's budget block — the bookend refusal, the wallet's own figures, and routing's dispatch-purpose reserve check — read its result. While a lift is in force on a group, all three reserves read zero for it and the implementation ceiling opens to 100%; once it ends, each returns to the figure the configured reserves give.

What landed

budget_group.effective_block(config, group, *, readings, now, session, path) composes the two rules that can zero a wallet's reserves through one resolution: budget_lift.effective_budget applies a lift in force, and reserve_block_for_group then applies the review-exclusion rule to its result. Three readers consult it.

  • dispatch_admission._refuse_against_the_bookend_reserve now judges through the effective block, handing the resolver the dispatch's own pace row as the newest reading, so a lift whose reset has already moved in that row is not in force.
  • budget_group.group_figures reports reserve_pct from the effective block, deriving the resolver's reading from the wallet's own freshest window report.
  • routing._budget_verdict resolves the judged backend's declared wallet and hands budget.policy a configuration whose budget block is the effective one, so the resume and coordinator reserves reach zero and the effective dispatch ceiling reads 100%.

The measure

Gate at head: tests/test_reserves_read_the_lift.py plus the eight existing reserve/pacing suites, 111 passed, EXIT=0. At the base revision the eight pre-existing suites give 104 passed, EXIT=0: zero added failures. Every figure in the new file is derived from the configuration and fixtures at assertion time.

Negative control — replacing budget_lift.effective_budget with a function that returns config["budget"] unchanged — turns the 100%-ceiling assertion and the admit assertion red: 4 failed, EXIT=1. That both the multiple and the reserve release pass through the one function is what the red arm shows.
