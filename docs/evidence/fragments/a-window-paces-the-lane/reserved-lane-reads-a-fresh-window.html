Reserved lane window refresh

A hardest-tier pick with no fresh five-hour reading now makes one bounded request, dates its window report, and reuses the published reading for later picks inside its shelf life.

Observed path

The host flight sets budget_check: true for Claude. paid_lanes.publish_document invokes the account read for that backend and persists the attempt. Its live document reports five_hour.state=unknown, utilisation=null, and a probe failure of account read failed — HTTP Error 403: Forbidden at 2026-10-18T14:58:05.548755+00:00. A direct _backends.probe_budget call with the configured Claude command reproduced that same 403. The account parser in _backends.py also selects its named weekly window, so this route cannot establish the five-hour figure even if access changes.

snapshot._compose_budget_report reads the published document and previously recorded run windows. With no readable five-hour source, _reserved_lane_exclusion receives None and returns its window reading is unknown or stale. In a direct control using the normalized reserved policy and the declared hardest tier, 42% returned no exclusion and 60% returned window is 60% used, at or above the 60% reserved-lane ceiling. The gate therefore responds correctly to a supplied fresh figure; the missing reading is the defect.

What landed

snapshot.candidates checks the node's declared reserved tier and the lane's own five-hour clock, aged by the same shelf life as the published paid-lanes document. Only a qualifying non-cached pick with an unknown or stale clock asks for a new reading. It refreshes the budget view held by pick() after a successful probe, so the offered lane and the rendered question read the same figure. A weekly or account-overage figure never substitutes for the five-hour clock.

paid_lanes.refresh_reserved_window holds the publisher's document lock, writes an attempt stamp before requesting, and reads the typed rate_limit_event.unifiedWindows.five_hour from one tool-free claude -p request. The request has a USD 0.05 ceiling and a 60-second timeout. A served event with a numeric utilisation and a future reset is dated from the request and published where the budget view already reads; the publisher preserves that reading and the attempt stamp. A refused request, absent window, or invalid reset leaves the lane closed. A repeated pick inside the shelf life reuses the stored outcome without another request.
