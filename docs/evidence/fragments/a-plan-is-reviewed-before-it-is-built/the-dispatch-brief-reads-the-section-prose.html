The dispatch brief reads the section prose verification

dispatch._plan_section_text resolved a requested section spelling to a heading record and then read the section's text with its own soup walk over the heading span. That walk was the same extraction the section view and the review digests take. It now takes an authored plan section's text from _plan_html.section_prose, the one reader the review digests cover, so no second walk extracts a plan section's prose.
