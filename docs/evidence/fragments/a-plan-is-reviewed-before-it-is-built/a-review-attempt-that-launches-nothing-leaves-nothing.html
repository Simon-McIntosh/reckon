A review attempt that launches nothing leaves nothing

A plan-review attempt composes its run directory under the plan's report root — the brief.md, the plan.html snapshot and the plan-review.json sidecar — before the lane admits it. The composer in reckon/crew/recovery.py now records the directories it brought into being, and one private exit, _discard_composed_plan_review, removes them on every path that launches nothing: the no-project/no-repo refusal, the unavailable-local-lane hold, the no-eligible-lane hold, and the BudgetHold, LanePaused and CrewError branches. Each branch calls that one function rather than carrying its own removal. Only directories this call created are removed, deepest first, and the empty ancestors it created are pruned, so a refusal leaves no new run directory while a directory that already existed when the call began is never removed. The refusal payload is unchanged: a paused lane still returns error: lane-paused with the gate it read.

The measure is tests/test_a_review_attempt_that_launches_nothing_leaves_nothing.py, all six cases passing. A plan-review dispatch refused by a paused lane leaves the plan's report root holding no new run directory and still returns lane-paused with the gate reason; a run directory that existed before the call, holding a delivered report.md, survives the refusal untouched; an admitted dispatch keeps its composed directory with the brief, snapshot and sidecar; and the composer names the run directory it created.
