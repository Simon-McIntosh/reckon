a-plan-review-judges-the-endpoint

The composed plan-review briefs now judge a section's endpoint and never its implementation. In the content rubric, reasoning drops the two checks that judged a stated method — whether a section's mechanism produced its done-when, and whether the mechanism ran on a named production caller — and asks instead whether the endpoint is reachable and checkable and whether the section prescribes implementation, which is a finding. anchors_resolve no longer requires claims to be cited: a reference is judged on resolution alone. In the design rubric, the reuse map is produced for the node brief and no finding asks the plan to name a module, function or file to extend. skills/reckon-build/SKILL.md and skills/reckon-review/SKILL.md state that the reuse map stays out of the plan.

The measure is tests/test_a_plan_review_judges_the_endpoint.py: it composes both briefs through the production composer for a temporary plan and asserts the clauses above, including that the base rubric's method checks are absent.
