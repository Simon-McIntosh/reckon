A report is admitted on what its own parser read

The separate admission guard is gone. delivered_report_record now reads the sidecar's subject once, dispatches a code subject to _code_review_record and every other subject to parse_review_report, and refuses the report as not a review when the parse of its own grammar holds no rubric item and no finding. The refusal names the grammar the report was read under — plan or health. _report_line_reader and report_carries_review_lines are deleted with it.

A code report whose only emitted lines are RUBRIC evidence: pass and a TREATMENT line is now refused rather than stored with six absent items: evidence is not a health-rubric item, so the health grammar reads no item and no finding in it. A plan report whose only RUBRIC line names an item outside its own rubric is refused the same way. A bulleted plan report is still admitted, its finding still stored and still answerable through crew review --answer.

Head arm: the declared gate ran 85 cases, all 85 passed, EXIT=0. Base arm: 83 passed and 2 failed, EXIT=1, the two failures being this node's own new refusal cases, which the head arm does not fail. Negative control: the base revision with the new test file copied in keeps the old pattern match and failed the same 2 cases with EXIT=1, so the check this node adds is red exactly where the mutation admits a report on the pattern match.

The host-review importer kept a private copy of the deleted guard and read every delivery through it, so the importer raised AttributeError on the removed name instead of importing a report. That copy is gone: a delivery reaches delivered_report_record and is admitted or refused by its own grammar, and a report that is not a review is listed among the refused with the reason the builder gave, rather than dropped or raising.

The rule is rubric-agnostic, so it also refused three pre-existing fixtures that declared the design rubric in their sidecar but emitted only RUBRIC wiring: pass, wiring being a content-rubric item. Those fixtures now emit RUBRIC reuse_search: pass, a design item, and the cases go on testing what they tested.
