What was measured

Every stored plan review, enumerated only through reckon.crew.plan_review.list_plan_reviews() so the population, each record's project and its review_path come from the one reader that walks every project and excludes code reviews. The census sits in the plan's cumulative record at docs/evidence/archive/a-plan-is-reviewed-before-it-is-built-landed.html#s11, and the script that reproduces its table byte for byte is docs/figures/a-plan-is-reviewed-before-it-is-built/plan-review-census/census.py.

Share of reviews carrying a reuse_search, duplicate_owner or thin_wrapper finding: 9 of 9. Share of those findings whose anchor resolves: 23 of 23. Unresolved anchors: none. The reading's --as-of is the newest stored review timestamp (2026-10-04T23:14:03Z), so two runs diff empty.

Gate: census.py run twice, diff empty, EXIT=0; 9 rows equal the 9 plan-*.json files under the crew review store. The script asserts its own negative control on every run — three anchors known not to resolve must be reported unresolved — so the all-resolved column is shown to be a measurement rather than a blind spot.
