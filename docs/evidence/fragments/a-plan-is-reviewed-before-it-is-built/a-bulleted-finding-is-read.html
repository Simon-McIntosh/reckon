What changed

One plan-report line reader, _plan_report_lines, strips a leading Markdown list marker (- , * , 1. ) before the plan-report patterns see the line, and parse_plan_review_report reads through it. The shared _review_text_lines and _PLAN_RUBRIC_LINE_RE are untouched, so the run-review and health-review grammars do not move.

The admission guard report_carries_review_lines, which refuses a report carrying no emitted line, reads a report through the reader that report's own grammar parses with: the plan-report reader for a plan report, _review_text_lines for a code report. It selects the reader from the same subject that selects the record builder, so a report is admitted on exactly the lines its own parser will see and the two grammars cannot diverge. An independent review of the first delivery of this node found the guard sharing the plan-report reader across both subjects: a code report whose RUBRIC and FINDING lines carried a list marker was then admitted on a stripped bullet the health grammar never sees, parsed to no item and no finding, and stored as a review with every rubric item absent. Reading by subject refuses that report, as it was refused before the marker reading was introduced.

A content review delivered with one of its brief's rubric items missing is stored incomplete, and review_coverage skips a record carrying that mark, so every unit it would have covered stays uncovered and require_plan_reviewed names them.

Deviation, for the coordinator. The mark is set on the content rubric only. Taking the design rubric with it cost five existing deliveries their coverage — test_gate_accepts_a_stored_or_delivered_review[delivered-*], test_unstored_sidecar_is_promoted_before_coverage[*] and test_answer_stores_an_unstored_delivery_before_answering each deliver a design report carrying one emitted line and expect the plan then covered. Those files are outside this node's write paths, and the section's done-when exercises a content review throughout. If the section means the mark to reach the design rubric too, that is a follow-on that updates the five deliveries.
