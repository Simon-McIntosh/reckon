A retired crew verb is a tombstone that names its successor

Change. reckon/crew/tombstones.py adds a registry of retired crew verbs. Each row (Tombstone) names the retired verb, its successor and the successor's invocation, and declares that successor as either a CLI token path into the live command tree (argv) or a view/action of the crew MCP tool (mcp_view/mcp_action). Three rows are seeded: review-plan → crew review, obligations → the MCP crew(view="obligations") (no CLI twin, by decision), and promote → crew complete. Invoking a row writes nothing: it prints one JSON document naming the retired verb, the successor, the successor invocation with the caller's arguments carried across, and the exit code, then exits 10 — the lowest code above 9 that no crew command raises, and so one the crew group's help documents beside 9, which is member-in-flight. The crew group in reckon/crew_dispatch_commands.py becomes _CrewGroup, whose get_command resolves a retired name to its tombstone only when a caller types it. A tombstone is deliberately absent from the group's commands mapping, so no retired name appears in crew --help nor in a census that reads the live command tree — the fold stays invisible until it is reached for. The command sets ignore_unknown_options and no help option, so it captures the caller's arguments intact and answers --help with its successor rather than a help page.

Test. tests/test_a_retired_verb_names_its_successor.py checks seven properties. Every row exits 10 (the code the crew group's help documents) and its JSON names the retired verb and the successor. No row is a listed command of the crew group. crew review-plan --plan p --answer f --acted prints the invocation reckon crew review --plan p --answer f --acted and, against literals written in the test rather than the row, reports the successor crew review. Every row's successor resolves — a CLI successor by walking the live click tree, an MCP successor by asking the tool (an unknown view answers invalid_view, an unknown action invalid_action, so any other answer proves recognition). A row whose CLI successor is an unregistered verb is reported by name. The retirement code is read against every literal code the crew commands raise (reckon/crew_*.py and reckon/crew/), so 9 — dispatch's member-in-flight — cannot be shared by a tombstone. tests/test_cited_commands_exist.py gains _retired, which walks the command tree and recognises the one shape a tombstone takes (the token after crew), and its main check reports a citation naming a retired verb with the successor it must be repointed to. A dedicated case shows the guard fires on a citation of crew review-plan and stays silent on the current corpus.
