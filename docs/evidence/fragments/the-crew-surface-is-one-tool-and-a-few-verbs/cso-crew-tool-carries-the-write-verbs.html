The crew MCP tool carries the coordinator's write verbs

The crew MCP tool accepts eight more actions — complete, land, dispose, ack, answer, widen, stop and discard. reckon/mcp_crew_actions.py maps each action's tool parameters onto the same command function its crew CLI verb runs through, calls that function in-process and returns the one JSON document the verb emits, so the tool and the CLI cannot drift about what one call returns. The tool description names every action's parameters. A refused complete or land is re-read through the promotion's own dry run, so its answer carries every failing guard in guards alongside the invocation that would pass rather than one refusal at a time. The obligations view now renders each duty's printed command in the tool's action form as next_action, so a coordinator can call the action directly instead of composing a shell command from the printed tokens.

Measure: tests/test_crew_tool_carries_the_write_verbs.py — 12 passed. For each of the eight actions the MCP tool and the CLI run on one temporary configuration home and their answers are compared, with a CLI refusal normalised from its bare Error: line to the tool's ok/error/detail shape.
