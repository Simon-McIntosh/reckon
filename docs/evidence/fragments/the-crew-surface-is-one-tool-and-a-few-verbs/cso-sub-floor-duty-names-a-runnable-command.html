The sub-floor duty hands the coordinator a command, not a sentence

The sub-floor duty composed its next_command as prose — dispose durability scored 4 against a floor of 10 on run r-x: folded with the dispatched node's id, or exempted with the recorded reason. That field is read as one runnable command by the action-form builder, and the apostrophe in "node's" is a quotation mark to shlex, so the sentence could not be tokenised at all. It now carries reckon crew dispose --project <project> --run <run> --dimension <dimension> --kind folded --node '<the node the finding went into>', every value quoted with shlex.quote. The one part the coordinator supplies is the node the finding was folded into, spelled as a placeholder the way the repair duty already spells its --reason. The exemption shape, --kind exempted --reason '<…>', rides in a separate exempt_alternative prose field on the same row rather than in next_command, because a second --kind there would name two dispositions in one command.
