The fixture that outlives the verb

tests/test_read_verbs_retire_behind_crew_view.py already held the two retired reads' answers as documents composed by the functions their verbs called. The listing's answer cannot be composed that way — it is a classified row, built by a different projection on each side — so the rows are written down: CREW_LIST_BASE_ROWS holds what the retired verb answered for each of the four selections, keyed by case and then by run id, over CLASSIFICATION_FIELDS, the eight-field set owned by tests/test_crew_surface_parity.py. The comparison therefore still runs once the verb is a tombstone instead of erroring on a name that no longer resolves.

The rows were captured by driving the verb over a fixture fleet: two projects, two phases and two sessions, with every clock in the classification path held at one instant and the stream's mtime fixed around it, so elapsed_seconds, log_age_seconds and budget_overrun are fixture values rather than readings of when the case ran. The capture had to be path-free as well as deterministic: a pointer whose phase leaves its process unalive is classified against the worktree path it would be recovered from, and that answer embeds an absolute path the fixture cannot write down a second time. The second pointer is therefore a queued one, whose remedy is the fixed “wait for a local lane slot”.

The fixture exists so that it can fail. Every case is asserted non-empty, and the four cases are asserted to narrow to different id sets — a case whose filter was dropped would otherwise answer the same rows as one whose filter worked, and both would pass. Every classified field is checked for presence on both sides before its value is compared, and the successor's id set must equal the captured one, so an answer that went empty fails rather than agreeing with an empty capture.

The file's other half reads the whole tree: every file under reckon/ is scanned for the retired name as a command, so a refusal answer left pointing at a name about to expire — the defect this node was dispatched to fix — fails here rather than being found by a coordinator following it.
