One call lands a run

crew complete --land promotes a finished run and then lands it in one call. It registers no module: reckon/crew/merge.py's land_merge gains a verify seam, and land is the thin caller that hands its marker check through it, so one landing loop serves both and the pinned-HEAD build, the index.lock retry, the --ff-only move and the push exist once. The loop builds the merge out of objects (merge-tree, then commit-tree) so the shared index and the primary branch are untouched until a single --ff-only step. The one new step sits between building the merge and moving the branch: the merged tree must carry a marker the change introduced and lack any marker it removed. The markers are read from the head's diff against the merge base of the branch before the merge, so the promotion's own ledger commits already on the branch are not attributed to the run's change; a diff against the branch head would read a ledger path the promotion added as one the change deleted and refuse a correct landing. The check reads the merge commit's own tree, so a resolution that drops the change refuses with the branch unmoved and nothing pushed, and a refused landing costs no cleanup. After the push the worktree is released through the existing _release_after_promotion, which is what turns the release from a withheld tree into a removal: promotion's own release runs before any merge and therefore with the head not yet reachable from the branch, so it withholds the tree, and the landing's second release runs once the head is an ancestor and removes it. The release records its outcome as a second ledger commit, so that commit is pushed too and the remote ends equal to the local branch rather than one commit behind it. Each step reports under steps — promote, land, release — and a step that fails stops the call and names the command that resumes from it: a dropped merge names the crew merge invocation, a withheld worktree names crew gc --apply, and a push that failed after the landing names the same head to rerun.

Measure: tests/test_one_call_lands_a_run.py builds a temporary repository with a bare remote and a finished run whose worktree holds one committed change, and calls crew complete --land on it through the CLI. The primary branch carries the change's marker, the remote ref equals the local one, and the worktree is gone. The declared negative control resolves the merge tree to the base's own tree — the change dropped — and the marker check refuses with the branch unmoved, the remote unchanged and the worktree kept for recovery.
