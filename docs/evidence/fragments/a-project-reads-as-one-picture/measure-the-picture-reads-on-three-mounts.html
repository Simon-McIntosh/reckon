The four coordinator questions through the CLI reads

Each question was put to one command-line read per mount, timed around the process with date +%s.%N and bounded by timeout 50. The three mounts' calls for one question ran concurrently, so each figure carries three-way contention and is an upper bound on an isolated call. The config home was a writable copy (RECKON_HOME) because the run's write fence makes ~/.config/reckon/cache read-only, which otherwise forces a full metadata-index recompute on every call. Raw timings and outputs are in the run directory under calls/.
