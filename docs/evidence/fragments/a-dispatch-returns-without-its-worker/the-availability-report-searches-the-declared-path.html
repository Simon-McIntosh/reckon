The availability report searches the declared path

The flight availability report located a backend with a bare shutil.which(command), so a command the launcher could only find through a search path declared in the flight layer was reported command_found: false with the detail "not on PATH" while a launch resolved it. The two views of one backend disagreed. The report now searches the process PATH first and the backend's declared directories after it, reading the declaration from the resolved backend entry it was handed, so a directory declared only in a project's own layer is seen too. The entry carries a new command_source naming which search held the command — "PATH" or the declared directory — and a command found on neither still reads command_found: false, with a detail that names the declared directories when there are any. A backend that declares no search path reads exactly as before.

The gate is tests/test_the_availability_report_searches_the_declared_path.py at head: 6 passed, EXIT=0. With a temporary project layer declaring a directory holding a stub, a host layer declaring none, and a launcher PATH that misses it, the report marks the stub command_found true and sets command_source to the declared directory. A host-layer declaration locates it the same way; a command present on the process PATH reports command_source "PATH"; and a declaration pointing at an empty directory leaves the report reading false.

The seventy-eight test files that import reckon.flight, built from the head's tests/ with grep, run one arm at a time with -n 4: head reports 20 failed, 957 passed, 2 skipped, 1 error, and the base revision with the node's own new file dropped reports 20 failed, 951 passed, 2 skipped, 1 error. The diff of the two failure-id sets is empty, so the node adds no failure; the six-test difference is the new file. Both arms carry the same tests/conftest.py::test_temp_config_home collection error, because that file's helper is named like a test and is collected when the file is passed explicitly — it reads nothing this node changed.

Negative control: the declared arm is replaced by a bare shutil.which(command), and the first case fails — test_a_project_layer_declared_path_locates_the_backend and its host-layer sibling report command_found false, 2 failed and 4 passed, EXIT=1.
