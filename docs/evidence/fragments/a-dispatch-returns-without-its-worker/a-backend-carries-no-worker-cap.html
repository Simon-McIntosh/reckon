A backend carries no worker cap

A dispatch was refused when a backend's max_concurrent_runs was reached, counting every non-terminal live pointer that claimed the backend. That counted a project's promotion backlog rather than load on the engine, so a session could be refused the right to hold its own runs. The key is retired: dispatch no longer enforces it and the summary reports the roster entry as retired. Only the roster bound retires; the partition-cores and login-memory bounds stay enforced and a case drives the cores bound to exhaustion to show the dispatch is still refused on it.

What changed

  • reckon/crew/summary.py: roster_bound returns a retired entry — utilisation unknown, admits_one_more true, value "retired" — so it is still readable by a summary reader and never binds. The now-unreachable roster branch of bound_refusal_text is removed, and the module comment names the two enforced candidates.
  • reckon/crew/dispatch.py: comments at the admission-check call site and on _refuse_over_concurrency_ceiling name the resource bounds that refuse. No enforcement code changed here because enforcement flows through summary.concurrency_bounds/binding_bound, which no longer return the roster as binding.
  • tests/test_backend_carries_no_worker_cap.py (new): declares max_concurrent_runs: 2 for a stub backend in a temp RECKON_HOME and a resolved flight layer, seeds three non-terminal pointers claiming it, and asserts a fourth dispatch is admitted; asserts the summary's roster entry reads "retired"; and drives a spent 2-core reservation to assert the dispatch is still refused on the partition-cores bound.
  • Existing tests that asserted the roster refusal are updated to assert its absence: tests/test_crew_binding_bound.py, tests/test_concurrency_bound_refuses_by_name.py and tests/test_lane_concurrency_ceiling.py. tests/test_lane_reading_at_dispatch.py, tests/test_backend_reference_contract.py and tests/test_dispatch_launch_is_not_its_own_conflict.py were named as candidates but assert no roster refusal — delta none.
