A dry run predicts the host's delivery

reckon crew dispatch --dry-run from a session whose host is waiting on its FIFO now reports the host delivery the identical real dispatch reaches, rather than refusing watcher-required, and writes no byte to the FIFO. The dry run reads the host's own liveness — the descriptor the entry point holds open across its wait, probed by the same non-blocking open the real request uses and closed without a byte — so a FIFO with no reader is a host that has gone and the session is refused exactly as a real dispatch refuses it.
