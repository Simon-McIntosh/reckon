A dry run predicts the host's delivery

reckon crew dispatch --dry-run now reports the delivery the identical real dispatch reaches, rather than refusing watcher-required or reading monitor where the launch reads host, and writes no byte to the host's FIFO. It mirrors both arms of the real admission. A session whose host is waiting on its FIFO is read from the host's own liveness — the descriptor the entry point holds open across its wait, probed by the same non-blocking open the real request uses and closed without a byte — so a FIFO with no reader is a host that has gone and the session is refused exactly as a real dispatch refuses it. A session a follower already runs is host delivery when the host's own census names that follower, and monitor otherwise, so the coordinator's own session — attached after its first dispatch — also reads host.
