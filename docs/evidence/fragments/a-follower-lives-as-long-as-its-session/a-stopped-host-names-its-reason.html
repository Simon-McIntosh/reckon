A stopped host names its reason

SessionHost.stop takes its reason as a required argument and refuses a reason that is not a non-empty string with a ValueError before any state changes, so neither a null nor an empty reason can reach the record. Every stop path names its reason: the request descriptor reaching end-of-file records request stream ended, the entry point's finally records host exited, a bare request_stop() records the signalled reason, and an exception escaping the read loop records host failed and still propagates. tests/test_session_host.py and tests/test_dispatch_session_host.py pass 26 tests with a bare EXIT=0; the four new tests fail when the reason their path records is removed, and the read-loop test fails when the fallback is made signalled for every exit, not only a requested stop.
