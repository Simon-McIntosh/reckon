The session host plugin waits silently on a node-local FIFO

plugins/crew-host holds .claude-plugin/plugin.json, monitors/monitors.json declaring one monitor with when: "always", and the bin/crew-host entry point. The entry point creates the FIFO at RUNTIME/reckon-session-host/PID-START.fifo, waits silently, removes that FIFO and exits within one interval of its owner's end, and execs the checkout's .venv/bin/reckon crew host on the first request line with the FIFO descriptor still open. The plugin loads as reckon-crew-host, and its single monitor carries the short label reckon crew. tests/test_session_host_plugin.py passes 5 tests with a bare EXIT=0.
