An unchanged run costs one stat

The producer's snapshot path carries a per-run cache keyed on the stat identity of the pointer, manifest, stream, exit record, run directory and promotion ledger row, and, on a hit, reads process liveness fresh through the same host-gated reader the classifier uses — the process and its descendant. A run whose files and liveness both hold reuses its previous snapshot: the unchanged poll opens no file and stats each of the four, and only the stream-silence reading is recomputed, from the poll's own moment. The silence decision is a pure helper both the full and reused paths call, so a reused snapshot cannot disagree with a fresh one.
