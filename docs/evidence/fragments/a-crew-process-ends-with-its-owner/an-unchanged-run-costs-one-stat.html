An unchanged run costs one stat

The producer's snapshot path carries a per-run cache keyed on the classification's own input composition (_classification_inputs: the pointer, manifest, stream, the run's exit/worker/attempt records, the review-store candidates and the worktree's git head), the newest stream's identity and the promotion ledger row, and, on the reuse path, reads process liveness fresh through the same host-gated reader the classifier uses — the process and its descendant. A run whose inputs and liveness both hold reuses its previous snapshot: the unchanged poll opens none of the four named files, stats each, and only the stream-silence reading is recomputed from the poll's own moment. The silence decision is a pure helper both the full and reused paths call, and the parity case compares the whole snapshot, excluding only the moment-derived quiet_seconds. Each watch_ticker invocation carries its own cache, so no watcher is served another's reading.
