A late observe keeps a terminal stored phase

What changed

The supervisor is the single writer of a terminal stored phase: once the worker exits it writes the delivered manifest's phase onto the live phase. A later observe() folds the run's stream back into the pointer, and a stream that was rewritten, truncated, or read before its terminal event reports a live phase for a run that has already ended. Folding that over the stored terminal phase showed a finished run as still running.

  • reckon/crew/dispatch.py gains _terminal_phase_survives, consulted at both phase-write sites in observe(). When the stored phase is terminal (complete, failed, stopped, interrupted) and the observation is not, the stored phase is kept. The deliberate resume override that reopens a live resumed attempt is untouched.
  • tests/test_terminal_stored_phase_has_one_writer.py writes the terminal phase through _publish_stored_phase(..., ended=True) as the supervisor does, then observes a live stream and asserts the phase is unchanged; a second case shows a non-terminal stored phase still advances.
