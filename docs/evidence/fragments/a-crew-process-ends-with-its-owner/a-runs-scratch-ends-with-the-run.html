A run's scratch ends with the run, never with its age

A worker's temporary trees are sent under $TMPDIR by the composed contract, so promotion's existing removal covers archives and basetemps. crew gc --scratch lists every scratch directory with its run's state and removes one only when the run has no live pointer and a terminal record — a ledger row or a discard marker — printing each path and its size before deletion and running as a dry run unless --apply is given. A tree no run can be attributed to is reported with its ctime, size and holding processes and is never removed. Promotion records the scratch directory's size on the run's row under a stated budget.

Five cases pass in a temporary RECKON_HOME with the scratch root under the test's own tmp, adding no failing id against the base arm. The declared mutation — make gc decide by age — fails the case keeping a complete-but-unpromoted run's scratch (EXIT=1).
