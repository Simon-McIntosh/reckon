§11 — a live producer reads only what changed since its last poll

The producer's tick now carries each run's stream cursor forward instead of re-parsing every record. The classification memo already recorded the byte offset an observation reached, so this keeps one cache rather than adding a second: the read resumes at that offset, the whole file is read only when the inode moves or the size drops below the offset, and the commits-beyond-base count is cached against the worktree head read from .git.
