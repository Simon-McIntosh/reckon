A vanished worktree reads as no referent

tests/test_a_vanished_worktree_reads_as_no_referent.py removes a registered worktree's directory and shows both cases emitting a parsed JSON payload: a commitless promotion reads the vanished tree as no repository change, promotes, and names the absence in its released worktree payload (tree is no longer available); a promotion citing a commit is refused with the single no-referent acknowledgement. Before the guard, the same case raised TypeError: 'NoneType' object is not iterable at reckon/crew/promotion.py:640; the negative-control log records that red run (EXIT=1).
