A replayed row carries the time its run entered its state

What the stamp is

The producer re-emits a baseline event for every live run about every 25 minutes, so a replayed row stamped with the last event naming the run carries the latest re-emission rather than the moment the run entered its state. _recorded_fleet_times in reckon/cli.py now takes, for each run, the current state and the earliest recorded time in the unbroken trailing run of events whose to_state equals that state. A later re-emission of the same state extends the run without moving the time; a genuine change of state opens a new run and stamps it at the change.
