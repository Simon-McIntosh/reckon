A project can name its worker MCP servers

worker_mcp_servers is a reckon-owned flight key: reckon/flight.py holds it out of the generated model in _schema_view and validates it in _validate_worker_mcp_servers, so a project layer naming worker_mcp_servers: [imas-cx] resolves under the strict authoring read with no unknown key and no schema refusal, and a launch seeds a run home whose settings enable imas-cx.

A declaration that is not a list of strings is refused with a message naming the key: the resolution raises <override>: worker_mcp_servers: must be a list of MCP server names, and the reader _declared_worker_mcp_servers in reckon/_worker_fence.py raises WorkerMcpServersError rather than seeding a bare string character by character, a mapping's keys, a tuple's items or a list holding a non-string. An absent key still names no server.
