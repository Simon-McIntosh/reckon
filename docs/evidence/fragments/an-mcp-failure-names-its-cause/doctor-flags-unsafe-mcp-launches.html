Doctor flags unsafe MCP launches

`reckon doctor` now reads the user-scope stdio entries in ~/.claude.json and the .mcp.json at the root of each mounted project's checkout, and flags an uv run launch that omits --no-sync, names no absolute --project, carries a literal /home/<user> path, or names a --project directory that does not exist after ${HOME} expansion. Each flagged launch prints a corrected uv run --no-sync --project <checkout> command with the checkout rendered through ${HOME}, and doctor exits non-zero when any launch is flagged.
