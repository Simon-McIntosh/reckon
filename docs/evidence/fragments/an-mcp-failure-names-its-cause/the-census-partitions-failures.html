The census attributes each failure to one cause and skips log directories older than the window

A failed connection is now attributed once, to the first signature in CAUSES order that its log carries, and every later signature it also carried is reported beside that cause under also_carried. The cause counts are therefore a partition of failed. On the real log tree for 2026-10-01T01:00:00Z to 2026-10-08T01:00:00Z the imas-cx row sums to its 1,635 failures (2,701 cause hits before the change) and the reckon row to its 1,021.

The walk descends a mcp-logs-<server> directory only when that directory's modification time is at or after the window start, walks both levels once for every tracked server, and overlaps the metadata round trips under a bounded thread pool (WALK_WORKERS). The census over that same real log tree finishes in 10.45 s and 14.43 s on two consecutive runs, against 29.15 s before the change. directory_kind is private again as _directory_kind, so census is the module's one public function. The doctor block states the storage-slow rule beside its count: a tool result whose payload names the error.
