A fenced worker can read the crew live view

What changed. project_watch_visibility in reckon/crew/runs.py used to create the project's watch directory and open the seat lock for update on its way to an answer, so a worker whose fence mounts the config home read-only failed with [Errno 30] Read-only file system (or [Errno 13] Permission denied on a permission-fenced directory) before it could report the project's runs. The read now goes through _probe_seat_read_only, which opens the seat rb and probes its advisory lock from that descriptor — flock permits an exclusive probe whatever mode the file was opened in — creating nothing and writing nothing. An absent seat reads as an empty seat instead of being created on demand. _reconcile_watch_record, the repair-on-read repair, still repairs a stale record where the home is writable, and now reports the record unrepaired rather than raising when the home refuses the open: a dead seat under a read-only home reads as unwatched.
