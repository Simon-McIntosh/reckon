Landing record — the review-missing sampler reads a reflex-claimed duty by its review's launch

The sampler committed by the census node asked obligations._current_review_in_flight whether a duty's review was in flight and then resolved the review pointer by sweeping the project's live pointers. Those are two different questions, and for a run whose review the reflex launched they answer differently: the reflex's claim is dated from its own launch window and survives the run moving past the revision the review read, while the sweep recognises a review only at the head it was granted. The duty therefore read stale_snapshot — a fact about the snapshot's age — where the review was live when it was computed.

The sampler now resolves the pointer from the reflex's own record whenever obligations._reflex_review_in_flight is true, reading the review run the reviewed pointer's review_dispatch.run_id names, and falls through to obligations._in_flight_review over the launched pointers for every other run. The review pointer it resolves is the one that carries launched_at, so the comparison is now against a real launch. A resolved review with no launch time reads the distinct review_not_launched, never stale_snapshot.

Watch streams are enumerated through reckon.crew.query.watch_event_paths rather than a local *.events glob, so the census and the query surface see the same set of streams and the suffix is spelled in one place.

A row whose state is not one of the three counted budget-lift states no longer mints a lift_transitions entry. A limit-reset row carrying a lift_id previously created an all-zero entry for that id, which reads in the report as a lift that was observed and did nothing.

The sampler's private home= argument is gone. It pointed the snapshot reader at one directory while the pointer readers resolved the crew home independently, so a caller passing home= without moving the crew home read the operator's live pointers; with the argument removed every reader resolves through crew_home(), which RECKON_HOME names. The test asserts every pointer directory read is the fixture's, and that the operator's live directory is not among them.
