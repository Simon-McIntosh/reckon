An ended lift stays ended

A lift ends when its clock's reset is observed, and that end is read from the group's window reading at the moment of use. A reading that flips between two figures therefore ended the lift on one read and revived it on the next, under the same id — the producer announced the same id as in force again and the fleet woke to a lift that had already ended. The change makes the observed end final: the first read that sees one stamps it on the record, and the end cause is read from that stamp ahead of every reading, so no later reading returns the id to in force.

Two functions in reckon/crew/budget_lift.py carry it. record_observed_end resolves the cause and, when it is the reset cause, writes ended_at and ended_cause on the record, returning whether the document changed; settled_document runs it over every lift in the document and writes the document back once if any lift moved. Inside end_cause, the stamp is read before cleared_at and before any reading. effective_budget stamps through _stamp_observed_ends on the group it is resolving, so the pace path and the producer's sweep both latch through one code path. reckon/crew/lift_watch.py's sweep now reads through settled_document, so the producer is the writer of the stamp when it is the first to observe the end.

The latch is restricted to the reading-dependent cause. A clear, the hard ceiling and a stated instant are all functions of the record and the clock, already monotone in time; stamping one would let a read that judged the ceiling at its own clock make that verdict permanent for a reader resolving the same lift at another. The first attempt latched every cause, and five tests that resolve a lift at an artificial clock against the real one caught it: the transient ceiling verdict became durable on the record and the lift never returned to force for the rest of the test. Only the reset cause — the one that depends on which reading you happen to hold — is written down.
