A wait nothing can lift says it needs the coordinator

The recovery sweep resumes a declared wait only when the condition probe reports a declared terminal state. A probe that cannot answer at all — the command failed, or could not be run — will never report one, so a row that keeps reading waiting with "the recovery sweep will resume run … when the condition test reports a terminal state" sends the coordinator to a mechanism that is not going to act. When the worker has also recorded its own end for the current attempt, the run is classified stalled (pane word halted) and the next action names reckon crew resume. A worker still live, and a probe that answers with a state outside the declaration's terminal list, are unchanged: both are waits the sweep can still carry.

Two facts decide the arm, both structured. In reckon/crew/recovery_wait.py the probe result now carries an answered boolean — False where the command could not run or exited non-zero, True where it printed a state, terminal or not — and _wait_condition_observation carries that flag through its normalised observation, because the detail text beside it is prose for a person and changes whenever the reader is reworded. In reckon/crew/recovery_classification.py _the_probe_did_not_answer reads answered is False; both a failed probe and a non-terminal answer normalise to state unknown, which is why the state alone cannot tell them apart. The third way a probe yields no answer — a condition test that raises, caught in classify_pointer because a probe is untrusted input — builds its observation in that except arm and marks it answered: False too; an observation without the flag reads as an answer, which would leave the sweep promise standing over a worker that has ended. _exit_record_ends_the_current_attempt accepts the run's exit record only when its stamped attempt is the run's current one, so a record left by the attempt a resume replaced cannot stand for the attempt now running. One elif in the valid-wait arm composes the halted reading, placed after the two met-condition arms so a met condition still offers its resume first.
