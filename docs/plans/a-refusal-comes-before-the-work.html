§1 — Why: three refusals that arrived after the work they judged

power-convertor-df reported these on 6 November from the power_convertor filter-recommendation sprint (session c76cf9d1, 5–6 November). Each is a check that exists but runs later than the first call that could have made it.

  • A batch skips the node contract. crew dispatch --batch queued malformed entries that a single dispatch or --dry-run refuses. The single path runs validate_node (reckon/crew/dispatch_plan.py near line 843). The batch path, queue_batch (reckon/crew/dispatch_batch.py near line 478) into queue_requests (reckon/crew/dispatch.py near line 293), runs only admission_domain_findings, so the contract refusals surface later at admission. The single path's contract is four refusals, not one: validate_node, then negative_control_finding (near line 851), gate_population_finding (near line 863) and the execution-fit refusal (near line 869).
  • A brief run's plan link is asked for only at landing. An implement-role run dispatched with --brief and no --plan must land with --plan-link or --unplanned-reason (reckon/crew/promotion_checks.py near line 1770), at both crew complete and crew merge. Dispatch neither asks for it nor records it, so the coordinator first meets it after the work is done.
  • An edit refusal reveals one missing field at a time. append_evidence raises on a missing plan, then anchor, then title, then body (reckon/_store.py near lines 1289–1305); close raises on status, then by (near lines 4141–4149); append on target (near line 3668). Each retry costs a round trip to learn the next field.

The same report found a fourth: a write path under ~/.cache/power_convertor-briefs/ was accepted by --dry-run and refused by the real call as outside the authorised work repository (_require_write_paths_in_authority, reckon/crew/dispatch_admission.py near line 1983, called from plan_dispatch in reckon/crew/dispatch_plan.py near line 911). a-dry-run-must-resolve-what-the-real-call-resolves §5, which made the dry run resolve what the real call resolves, is done, so this is a gap it left; §5 here owns it.

Deliverable. validate_node (reckon/crew/node.py near line 1182) is already the judge that reports every property a node fails.
