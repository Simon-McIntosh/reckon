§2 — Reckon adopts its four north-star directions

north-star-orientation §5 proposed four directions:

  • State that tells the truth: every status, number and gate verdict is derived from evidence a reader can re-check, and nothing computable is stored as an assertion.
  • Unattended execution: an orchestrator carries a sprint from ready node to committed evidence without a human in the loop, and holds recoverably rather than failing when it must stop.
  • Legible to human and agent alike: a person and an agent read the same plan state through surfaces suited to each, with neither a second store nor a second truth.
  • Portable across harnesses: reckon's contracts hold whichever agent harness runs the work, so adding a backend never adds a second execution path.

Its write path, validated north_stars in project state (e8efbc7), is landed. The declaration was blocked only by stale server and MCP code.

Done when the four directions are declared in reckon's project state and returned by a read of the project resource.
