A Review Can See The Figure

A text reviewer reads a diff, and the rules this repository enforces on figures are visual ones. Legible at a glance, high data-ink, labels that clear contrast on their background, and the rule most often broken — never an image of what is naturally a table. None of those can be judged from a diff, so every figure that has shipped here shipped unreviewed against its own rules. For the poloidal-flux work in the physics repositories the gap is worse than cosmetic: a flux plot is the evidence, and a review that cannot open it is reviewing a filename.

The capability exists and has existed throughout. The codex dialect composes codex exec at reckon/_backends.py:1220, and that subcommand takes -i, --image <FILE>... — optional images attached to the initial prompt. Nothing had to be built to make the lane see; what was missing was any way to say which lanes can.

That absence is the whole risk, and it fails open. BackendConfig carries 27 slots and not one expresses modality. So a figure profile has nothing to select on and falls through to default_backend — plausibly a lane that ignores -i entirely and answers from the filename, the path and the diff. The reply is well-formed, scored, and stored. A review that reports a judgement it could not have formed is worse than no review, because it produces a record. This plan therefore declares before it dispatches, and refuses rather than degrades.

§3 — What the lane can actually judge, measured against known-bad input

This is an evaluation and it needs a negative control or it measures nothing. Asking whether the lane can see is nearly answered by the flag. The question is whether it can apply these rules, and the only way to learn that is to give it figures whose verdict is already known and require it to discriminate.

PairKnown-bad inputKnown-good input
the most-broken rulea rendered table of labels and valuesa genuine continuous plot
contrastgrey text on a dark or saturated fillnear-white on dark, or dark on light
legibilitybody text well below the stated floortext at or above it
data-inkgradients, shadows, decorative fillshairline rules and direct labels
the physics casea poloidal-flux plot with an unlabelled or mis-signed axisthe same plot, correct

Measure. Each pair is presented independently and the verdicts are recorded per pair. A lane that passes the good figure and fails the bad one on the same rule has discriminated; a lane that returns a plausible critique of both has not, and the figure profile is not enabled on the strength of a reply that reads well.

The format boundary is part of the measurement, not an afterthought. Most figures in this repository are SVG and vision models generally take raster input. If SVG is not accepted, the capability does not reach the artifacts it was built for, and the finding is either a render-to-PNG step in the figure contract or a scoped claim that only PNG figures are reviewable. Measure it rather than assuming either way.

§4 — Selection by artifact, and the cheap review first

No coordinator chooses text or text-plus-image. The choice is available as a fact and taking it as a decision is how a guess enters. A run that changed an image under a figures directory gets the figure profile; a run that did not, does not. This is §2g's existing rule — selection by what the run wrote, never by the role it was dispatched under — applied to the one profile that needs a different lane.

Sequence, and what it bounds. The text review runs first on the freely served lane at high concurrency, as it does now. The figure review fires only when the diff carries an image, so metered spend is bounded to exactly the runs that produced figures rather than to every run that might have.

Two reviews, not one review with pictures. They take different inputs, apply different rules, run on different lanes and cost differently; their findings meet in one record and are attributed separately. A blended score cannot say which half failed, and a vision model reading a diff is a text reviewer with a more expensive tokenizer.

The figure reviewer writes one thing. Per §6 of the scoring plan it may write the caption and nothing else, flagging every other defect for the node that drew it. A reviewer that redraws becomes a second author with no reviewer, and its findings stop being falsifiable because the evidence moved.

§5 — Sequencing

§1 precedes everything: until a lane can declare the capability, any figure reviewer routes by luck and the failure is silent. §2 follows, since an attachment that never reaches the command line makes §3 unmeasurable. §3 gates §4 — the profile is enabled on measured discrimination, not on the flag existing. §4 is the smallest of the four and is mostly the application of a rule §2g already carries.
