Measured on 2026-10-11 in coordinator session health-review-1010, with its follower attached and the producer live throughout. The review reflex launched no review for these deliveries, and each was dispatched by hand from the live view's next_action:

  • first deliveries: source-text-assertions-multi-site, source-text-assertions-single-site, structural-guards-have-one-home, home-fixture-has-one-home and git-test-helper-has-one-home;
  • resumed runs whose head moved, for which the reflex launched no review at the new head: structural-guards-have-one-home (c47c99ef6 to 71bb011d8), gc-bounds-a-run-file (92d3ec6ca to 2cf592a55 to 3fa0ce0ef) and dispatch-names-the-health-review (29185a66a to 624314887).

The review store holds a review at every one of those heads today, but every review in this list was dispatched by the coordinator with reckon crew dispatch --role review after the reflex had launched nothing, not by the reflex itself. A resumed run reads complete again while its stored review is keyed to a superseded head, so the head that merges goes unreviewed unless the coordinator notices. The mechanism meant to prevent this already exists and is reached: dispatch_review_for_run in reckon/crew/recovery_review_dispatch.py calls review_head_move and carry_review_forward, and the watch path in reckon/crew/recovery_watch.py calls it. a-review-is-sized-to-its-risk §5 landed it, saying that a runtime-source move earns a light re-review. So the question is why that path did not launch here, not how to build one.

§2 — Why the reflex launched nothing is recorded

Deliverable. A read-only investigation, recorded as a report in the run directory, that explains for each of the nine deliveries in §1 why the reflex launched no review. For each delivery, the report records three things. First, whether dispatch_review_for_run was reached for it at all, read from the producer's watch log and the run's review-dispatch records. Second, what review_head_move and carry_review_forward returned for it, reproduced against the run's stored review and its two heads. Third, whether an admission or concurrency bound deferred a launch that was never retried. It ends with one stated cause, or several each with the deliveries it explains, and the module and function a fix must change.

Done when the report names a cause for each of the nine deliveries, each cause cited to a log line or a reproduced return value, and names the function §3 changes. A delivery the logs cannot explain is listed as unexplained, with what was missing. The negative control is the report's own reproduction: for one resumed run, calling review_head_move with the run's two heads must return the value the report says it returned. Write paths: the run's own directory.

§3 — The reflex launches a review for every settled head

Deliverable. The cause §2 names is repaired in the function it names, by extending the existing path through dispatch_review_for_run, review_head_move and carry_review_forward in reckon/crew/recovery_review_dispatch.py. No second launch path is added. After the repair, the reflex launches a review whenever a run settles at a head that no stored review is keyed to. That covers a first delivery, a resumed run whose head moved, and a launch an admission bound deferred, once the bound clears. It still carries a review forward when §5 of a-review-is-sized-to-its-risk says the move needs none.

Done when tests/test_a_moved_head_is_reviewed.py drives the watch path with a temporary run through three cases. A run completes and is reviewed at head A, then is resumed and completes again at head B: the reflex launches exactly one review keyed to B. A run whose stored review is keyed to its head gets no launch. A first delivery whose launch was deferred is launched once the bound clears. Each case that reproduces a cause from §2's report is named for it. The tests importing reckon/crew/recovery_review_dispatch.py or reckon/crew/recovery_watch.py show no added failure against base, their list built from the head tree. The negative control is executed and logged: with the cause §2 named restored, the case it explains fails. Write paths: the module and function §2's report names, and tests/test_a_moved_head_is_reviewed.py. This section runs after §2.
