§1 — Why: ceremony sized for features, applied to every edit

A 12-line fix costs about 35 minutes of worker time and a 20-minute review before promotion, against about 10 minutes inline (s22); one imas-ambix feature that was a 20-minute edit took five implement nodes and five reviews, about 2.5 hours. Writing and committing a followup only so a goal can cite it costs 5–10 minutes each (s23). The median node now takes 44 minutes from dispatch to worker completion, against August's 9.8-minute median wall per run, and 83 minutes to promotion; and the fleet adds 5.35 record lines for every product line, excluding the figures directory (crew pattern review §4). The survey's majority holds that the delegation discipline for product code stays — the worktree, the gate and the negative control — so the lever is the ceremony around a small node, not whether a small node exists (§10).

§2 — A finding or a followup is a brief

Deliverable. A finding from a stored review, or an open followup, dispatches as a brief attached to the plan and section it already belongs to, using the stored-brief carrier that a-worker-can-take-a-brief adds. The carrier copies the brief into the run directory at dispatch, so no plan text is written and nothing is committed first. The brief records the finding id. On promotion the repair's manifest answers each finding — repaired with its commit, or declined with a reason — and promotion writes those answers onto the reviewed run's ledger row; this section adds that answer record for code reviews, which today have a store but no answer field.

Done when a stored review finding dispatches as a repair with no plan write and no commit in between, and after promotion the reviewed run's ledger row shows the finding answered with the repair's commit.

§3 — A small node records one landing line

Deliverable. A node is small when its diff has at most 50 changed lines (added plus deleted), or when it changes no product code (source or tests) and has at most 300 changed lines. A small node writes one landing: line in its manifest — what changed and its measure's figure — and writes neither evidence prose nor a figure unless its done-when names that artifact; naming one does not permit the other. Promotion writes the line as a comment on the plan section the node is attached to; a brief run with no plan attachment keeps it on its run record. The worker prompt says so, and says that any single data file above 300,000 bytes belongs in the run directory rather than the repository.

Done when the small-node prompt fixture carries both rules, and over the first week after this section lands, small nodes' record lines (plan, evidence and research HTML, docs/state; the figures directory excluded, as in the 5.35 baseline) are at most equal to their product lines.

§4 — What a coordinator may commit directly

Deliverable. A closed list, stated as one table in the build skill, of edits a coordinator commits itself, each recorded on the ledger as a coordinator commit: correcting a recorded sha, heading or path string; the union of a conflict in plan, evidence or sprint HTML (both sides' additions kept) or in a JSON file whose conflict is confined to append-only arrays or disjoint keys, with the result passing audit-doc or a JSON parse before commit; correcting a path field inside a manifest; and plan and sprint state. Product source and tests, including test fixtures, are never edited inline, and a .py conflict is resolved only in a scratch worktree. This writes down what s23 and s22 already do, and holds the line s21 learned from an outage.

Done when the build skill states the table, and the coordinator-overhead census, re-run for the week after this lands, classifies each coordinator commit that carries a worker's diff by table entry, with any commit outside the table listed.

§5 — A directory claim that overlaps a peer asks first

Deliverable. Dispatch warns when a declared write path is a directory that contains, or is contained in, another live run's claimed path, and lists the files the brief names as the exact alternative; the dispatch proceeds with the directory claim only when it carries --accept-directory-claim. The imas-ambix coordinator lost about 30 minutes to its own tests claim blocking a peer.

Done when a test with a live run claiming tests/test_x.py and a dry-run claiming tests returns the warning and the alternative, and the same dry-run with the flag proceeds.

§6 — Measure the small-change path end to end

Deliverable. One week after §2 lands, measure for repairs of at most 50 changed lines the median time from the stored review's record time to the repair's promotion.

Done when the median is recorded with its sample size, against a target of 30 minutes.
