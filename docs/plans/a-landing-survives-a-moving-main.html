§2 — A measurement survives commits that cannot change what it measured

Deliverable. When main has moved since a delivery was measured, the lander keeps the measurement if every commit between the measured primary and the current one touches only paths outside the measured population's inputs, and the delivery still merges cleanly onto the current primary. The worker first reproduces the livelock: a stubbed pass in which a docs-only commit lands on main during measurement, showing the run deferred again on the next pass. It then decides, and states in its manifest, which paths cannot change the measurement. Product source under reckon/, tests/, pyproject.toml and uv.lock always invalidate it; docs/ plans, state, evidence and figures do not. It applies that test at the deferral near line 1460 and at the stored-measurement lookup, so the measurement is reused rather than repeated.

Done when a new tests/test_a_landing_survives_a_moving_main.py shows four things with a temporary repository and a stubbed measure: a delivery measured before a commit touching only docs/plans/ lands on the next pass without being measured again; a delivery measured before a commit touching reckon/ is measured again; a delivery that no longer merges cleanly after a docs-only commit is not landed on the stale measurement; and the pass record names a deferred run's reason.
