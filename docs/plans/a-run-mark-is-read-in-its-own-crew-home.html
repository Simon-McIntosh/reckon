§1 — A run's environment mark is read only within its own crew home

Why. _processes_owning_run in reckon/crew/process_signal.py names every process of this user whose environment carries RECKON_RUN_ID equal to a run id. Two doors read it. local_liveness in reckon/crew/recovery_liveness.py uses it, through _env_scan_run_pid, as the last reach for a reparented worker. The stop path uses it to end a run's whole process tree. a-run-has-one-live-writer §2 introduced both, and that plan is complete. Neither door asks which crew home the process belongs to. On 2026-10-16, the exclusive-node population run of the fence reports seal (run r-20261016T212841719818, job 1287701) hit this. tests/test_resume_anchors_the_run_harness_home.py::test_a_resume_reaches_the_home_the_dispatch_composed[codex] failed under -n 10 with "run 'r-resume-codex' reads 'alive' for a lift … (pid 3666792)", although its fixture records only a pid beyond pid_max. It passed 5 of 5 alone at base and at head. Nine test files use run ids of the form r-resume-*, each under its own temporary crew home. A child that one test launched, carrying that id, was read as the worker of another test's run. The same match would let a stop signal a process belonging to another crew home.

Deliverable. A process is named for a run only when its environment also places it in the caller's crew home. That home is RECKON_HOME resolved, with an absent RECKON_HOME standing for the default home a launcher without it used. Both doors inherit the narrowing by going through _processes_owning_run, with no second matcher.

Done when a new test, tests/test_a_run_mark_is_read_in_its_own_crew_home.py, starts two live child processes carrying the same RECKON_RUN_ID under two different RECKON_HOME values. Called under the first home, _processes_owning_run names only the first child. A record whose own pids are gone and whose run id only the second home's child carries reads not alive from local_liveness. A child carrying no RECKON_HOME is named when the caller's home is the default one, and not otherwise. Negative control: with the crew-home comparison removed, the test names the second home's child and fails, logged under the run directory. ruff check and ruff format --check add no findings on the changed Python files. The coordinator runs the importer population at merge. Write paths: reckon/crew/process_signal.py and the test file.
