§2 — The browser harness finds the browser that is installed

Deliverable. installed_browser() resolves, in order, RECKON_BROWSER, the three names on PATH it looks for today, and Playwright's headless shell under $PLAYWRIGHT_BROWSERS_PATH or ~/.cache/ms-playwright/chromium_headless_shell-*/chrome-headless-shell-linux64/chrome-headless-shell, newest first. Its skip message names every location it checked, so tests/test_browser_skip_is_not_vacuous.py keeps its meaning. The browser tests that then fail are not fixed here: each failing id is listed in the manifest against a base arm run the same way, and the coordinator records them on the-suite-is-green-at-head.

Done when the browser population (the tests reaching installed_browser_or_skip, built at dispatch from the head tree) runs on the compute allocation with 0 skips for a missing browser, logged once with -rs; a unit test points PLAYWRIGHT_BROWSERS_PATH at a temporary directory holding an executable stub at the headless-shell path and asserts the harness returns it, and with an empty directory and an empty PATH asserts the skip message lists the locations. The negative control is executed and logged: with the Playwright clause removed, the population skips again. tests/test_browser_skip_is_not_vacuous.py, whose no-browser guard strips only PATH, is changed to also point PLAYWRIGHT_BROWSERS_PATH and HOME at an empty temporary directory, so it still exercises the skip once the new clause can resolve. Write paths: tests/spa_browser_harness.py, tests/test_browser_harness_finds_playwright.py, tests/test_browser_skip_is_not_vacuous.py.

§3 — The suite record carries its skips

Deliverable. The record reckon crew suite run writes gains skipped and skipped_ids, parsed from the same pytest output it already reads, and the suite's summary line in the follower and the velocity view prints the skip count beside passed and failed.

Done when tests/test_suite_record_counts_skips.py feeds the record writer a fixed pytest log ending 3 failed, 10 passed, 2 skipped with two SKIPPED lines under -rs, and asserts skipped == 2 and both ids; a log with no skips records 0 and an empty list, not an absent field. The negative control is executed and logged: with the skip clause removed from the summary parse, the first log records 0 and the test fails. Write paths: reckon/crew/standing_suite.py, tests/test_suite_record_counts_skips.py.

§4 — A helper copied across test files has one home

Deliverable. The helpers the health review found copied whole across three or more test files (config_home, _spawn_runner, _row, checkout, _placed_backend, _replace_stream, _start_worker, assert_untouched, _git_env, _seat_record and the rest of that list) move to tests/helpers/, one module per subject, and every copy is replaced by an import. A copy that differs from the others in behaviour is left where it is and named in the manifest. Fixtures that must stay fixtures move to tests/conftest.py only when every importer is in the suite's root.

Done when for each helper named above, the number of test files defining a module-level function of that name (counted with grep -rlE "^def <name>\(" tests/, the counts summed) falls to at most one per helper outside tests/helpers/, with the before and after sums in the manifest; the test files touched pass at the integrated head with the same pass and fail ids as at base, the population built at dispatch; and the line delta over tests/ is negative. The negative control is executed and logged: one replaced helper's import pointed at a stub that raises fails the tests that imported it. Write paths: tests/helpers/, tests/conftest.py, and the test files holding the copies, listed at dispatch from the clone report.

§5 — An assertion on source text becomes an assertion on behaviour, or is deleted

Deliverable. Each of the 37 sites that read a module's source (inspect.getsource, or ast.parse of __file__) is either rewritten to call the code and assert its effect, or deleted where the behaviour it stood for is already asserted elsewhere, citing that test in the manifest. A site that guards a structural invariant no behaviour shows (a module exporting no forbidden name, say) stays, and the manifest says why. Tests for the reach graph and the clone detector, whose subject is source, are out of scope.

Done when grep -rn -e inspect.getsource -e "__file__).read_text" tests/ counts at most 10 sites, against 37 at 646bbacf5, each remaining one listed with its reason; the edited test files pass at the integrated head; and for three rewritten tests, chosen by the reviewer, reverting the behaviour they now assert makes them fail, logged as the negative control. Write paths: the test files holding the sites, listed at dispatch from the grep.
