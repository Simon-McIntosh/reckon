§1 — What the row carries, and what its readers use

The lead's pane on 2026-09-22 showed this row, among others:

21:34:16  review  review-of-pta-adopted-read-cost-red…  working → unpromoted  dsv4.1-flash xhigh  3w· 1b· 7u  57:01  –  1mu

Four coordinators said which cells they use. All four act on the destination state, the node name, and the reason text at the end of an actionable row. Three use the elapsed time to spot a run over its budget. Three used the model and effort pair to catch a review routed to a metered lane despite --local, so that pair earns its place. None of the four could decode the age cell, which prints the age of the oldest unpromoted run as minutes followed by the bucket letter. None used the generation-rate cell, which renders the absence marker whenever the transition carries no rate. The row census in the measurement plan §3 supplies the counts across four projects.

Two layout defects compound this. The model cell is ten columns and deliberately lets a wider alias overflow, and the locally served lane's alias dsv4.1-flash is twelve, so every row on that lane shifts the cells after it. The node cell cuts at 36 columns from the right, so two reviews of similarly named nodes render identically, which nova-37 and imas-efit-e3 both hit. And ANSI colour reaches an agent reader as escape sequences inside the notification, as imas-ambix-b6 reported, so any state carried by colour alone is lost to the reader who most needs it.

The row census in the measurement plan §3 rendered every recorded transition across four projects. The model cell overflows on 47.5 percent of reckon rows and 78.2 percent of imas-efit rows, and dsv4.1-flash alone overflows on 3,954 rows. Model-cell text reaches 19 characters in nova. The rate cell renders the absence marker on 3,847 of 4,025 reckon rows, and every project carries age cells of the 0mu form. A real blocked row's reason clips at every width from 145 to 198 columns, which includes the 160 columns the follower normally runs at.

The open section crew-observability-truth §20 measured the same dead cells over 366 rows, with the rate populated in 1.9 percent of them, and moves here. Its sibling §19, where a discard and a stop render as promoted, stays with that plan because it waits on the lead's disposition decision there.

All changes here are in reckon/crew/ticker.py, with its tests in tests/test_crew_ticker.py and tests/test_crew_ticker_layout.py. The sections share those files and run one after another.

§2 — The state cell shows the destination only

Render only the state the run moved into. Drop the from-state cell and the arrow between them. A baseline row is marked by the word now before the state rather than by a bullet glyph, because a glyph at small size is the entire signal and imas-ambix-b6 read three baseline rows as fresh dispatches.

Done when a rendered transition from working to unpromoted contains the word unpromoted once and neither the word working nor an arrow, and a baseline row contains now immediately before its state. The row is at least thirteen columns narrower than the base revision's rendering of the same event at the same width, measured on the reason cell's room. Existing ticker tests that assert on the from-state are updated to assert its absence, and the delta against the base revision's test run is stated.

§4 — The row drops the cells nobody reads

Remove the generation-rate cell and the age cells from the row. Keep the elapsed time, and render it in hours and minutes, as in 57m or 1h33m, rather than as a clock. The age of a run that needs the coordinator moves into the needs-you line of a-follower-keeps-your-work-in-view, where it is spelled beside the node it belongs to.

Done when no rendered row matches the pattern of a number followed by m and a bucket letter, no row carries the absence marker in a rate position, and a run with 3,421 seconds elapsed renders 57m. The width recovered is stated as a column count.

§5 — A long node name keeps the part that distinguishes it

Cut a node name longer than its cell from the middle, keeping its start and its end. When two rows in the same follower would still render identical node text, append the last four characters of the run id to both.

Done when review-of-sgc-sweep-control-at-the-banked-seam and review-of-sgc-sweep-control-at-the-four-of-twenty render with different node text at the default width, and a name that fits is unchanged.

§6 — The reason clause is cut at a word

When the reason clause is longer than its room, cut it at the last word boundary that fits and end it with an ellipsis, rather than mid-word. The full text remains in the transition record and in the live view.

Done when a reason clause of forty words rendered into thirty columns ends in a whole word followed by an ellipsis, and a clause that fits is unchanged.

§ Decisions

Which time and spend measures stay on the row?

The lead doubted the time and token figures were useful. Three of four coordinators used the elapsed time to find runs over budget, and none used the rate or the age cells, so elapsed stays and the rest go. The lead may reverse this; §4 is the only section it governs.
