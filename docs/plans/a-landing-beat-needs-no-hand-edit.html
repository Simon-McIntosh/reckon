A landing beat needs no hand edit

The lead's rule is that editing a plan by hand should be rare but still allowed. The S23 coordinator ran fifteen landing beats on 2026-09-24 and 25. Every write went through edit_plan except two kinds, and those two had no op.

§1 — The hand edits that remained

  • Evidence records. A correction appended to a-worker-knows-it-is-on-compute-landed.html after the review found a vacuous mutation control. Also two add/add merges where two nodes each created the same cumulative evidence file, which had to be spliced by hand. edit_plan writes plan state; it has no op for an evidence resource's anchored sections.
  • Collapse on landing. reckon-build §6b tells a coordinator to replace a shipped section's body with a two-to-four-line landed card. No op does that, so the only routes are a text-mode edit anchored on the section's own prose or a direct file edit.
  • Inserting a section. Solved on 2026-09-25 by insert_section, in the-mcp-answers-within-its-ceiling §7.

§2 — An op appends an anchored section to an evidence record

edit_plan accepts {op:"append_evidence", plan, anchor, title, body}. It targets the cumulative record docs/evidence/archive/<plan>-landed.html.

  • If the record is missing, the op creates it with reckon-type=evidence and plan-evidence-for.
  • It appends one <section id=anchor> before </main>.
  • It refuses an anchor that already exists, so two writers never overwrite each other.

A second writer's append lands beside the first, removing the add/add splice.

Done when:

  • Tests assert creation with the required meta, an append beside an existing anchor, refusal of a duplicate anchor, and reckon audit-doc passing on the result.
  • The declared mutation, dropping the duplicate-anchor refusal, is applied and observed to fail. The log is recorded.

§3 — An op collapses a landed section

edit_plan accepts {op:"collapse_section", section, summary, evidence_anchor}. It replaces the authored body under that section's h2 with the §6b landed card, which carries the ✓ landed badge, the summary and the evidence link. It keeps the h2 id, and it sets that section's declaration to done in the same versioned write.

Done when:

  • Tests assert that the body is replaced, the heading and id are kept, the declaration reads done, structured-state regions are untouched, and a missing section is refused.
  • The result passes reckon audit-doc with no header-duplicate finding.
  • The declared mutation, leaving the declaration unchanged, is observed to fail. The log is recorded.

Done when:

  • The vocabulary-completeness test from the-mcp-answers-within-its-ceiling §8 passes with both ops present.
