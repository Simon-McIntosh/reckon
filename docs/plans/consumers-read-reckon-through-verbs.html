§4 — Hand recipes become verbs

Its negative control reproduces the prior-line append defect. reckon sync --write is the explicit fallback-repair path for mounts.json and the state symlink: without --write, that fallback reports proposed changes and touches neither location; its negative control proves an unguarded fallback write is refused. §5 — Session captures leave the committed roster

crew observe and dispatch must leave docs/state/<project>/crew.json byte-identical: a captured worker session is one per run on that run's live pointer and ledger row, never a <member>.json file and never a roster member field. The committed roster retains only the member identity and role needed to select that member; session identity, model, ownership and history belong to the run. The capture-record design in new-work-gets-a-new-worker §3 is authoritative, while §5 owns removing the residual observe/dispatch writes and its non-mutation test.
