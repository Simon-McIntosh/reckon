§1 — Why

Conservative cleanup never garbage-collects, and no reckon crew command owns removal. Measured on this workstation: 27 leftover worktrees totalling 12 GB under ~/Code/.reckon-worktrees/ (including a nested reckon-worktrees/reckon-worktrees directory of unknown origin), and 270 run-stream directories (129 MB) under the config home (fleet review §8). The ledgers also record one worktree deleted out from under a live run by a coordinator cleanup — the inverse failure, cleanup without a liveness consult.

§2 — Deliverables

A crew-surface GC command. reckon crew gc (dry-run by default) that removes worktrees whose HEAD is an ancestor of the primary branch (integrated), reports dirty or unintegrated trees without touching them, prunes run directories past a retention window once their run is promoted, and reaps live pointers whose pid is dead and whose node has a completed ledger record. Done when a dry run against the current backlog itemizes the 12 GB correctly and the real run reclaims only the integrated/promoted subset.

Live-pointer consult before removal. Every removal path — the new GC and the vendored cleanup-session — refuses a worktree referenced by a live pointer in a non-terminal phase. Done when the recorded worktree-deleted-under-a-live-run scenario refuses under test.

Root anomaly. Explain and remove the nested reckon-worktrees/reckon-worktrees directory (likely a transitional artifact of the worktree-placement fix); add a guard so the root cannot nest. Done when the root contains only per-repo families.

Per-repo prerequisite check. Dispatch verifies the vendored fleet script exists in the target repo and fails with a message naming the fix (it is absent in imas-efit today). Done when the missing-script failure is a one-line actionable error.

§ Followups

Build crew gc and clear the backlog

All four §2 deliverables. The backlog clearance runs only after the GC's dry-run report has been reviewed — several worktrees may hold unintegrated work, and live runs from other sessions must never be touched.
