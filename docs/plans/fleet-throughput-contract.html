§1 — Why

Measured across 259 runs the fleet sustains 2.26 concurrent workers against a 13-wide peak, and roughly 45% of purchased worker-time idles at the contract's wave barrier (fleet review §2/§5/§6). None of the serialization is in code: it comes from the reckon-ship contract's wave-and-wait shape, the over-broad landing freeze, a uniform 25m time ceiling, and per-run polling that makes wide fleets expensive in orchestrator context. This plan raises throughput by removing artificial serialization only — the DAG and file-scope disjointness still decide what may run together, so no parallelism is forced that plans do not expose. Depends on crew-state-integrity and dispatch-lifecycle-safety: a wider fleet is exactly what trips the ledger races and the member-collision loss.

§2 — Contract changes (reckon-ship SKILL.md + references)

Rolling refill replaces the wave barrier. A finished, verified worker's slot refills immediately with the next ready node; the barrier survives only where a dependent node consumes an unverified predecessor. Done when the skill's wave section describes slot refill, and the safety rule is restated as "no dependent node builds on unverified work".

Narrowed landing freeze. The landing beat's inviolable half stays (the plan write may not be skipped, nothing merges or promotes before it); dispatching an unrelated ready node no longer waits on another node's plan write. Done when the hard rule's wording separates the two.

One wave-size vocabulary. The three inconsistent fleet-size bands (2–8, 3–8, at-most-three) collapse to one advisory table in one file, explicitly marked advisory, with the member roster named as the real ceiling. Done when the other copies reference rather than restate it.

Preamble diet. Reference files whose content the engine already injects via compose_prompt are gated behind "only when hand-composing"; the mandatory-read set shrinks accordingly. Done when the per-session fixed read is measured under half its current ~24k tokens.

§3 — Time budgets that mean something

Per-role defaults from measurement. Set role-level time budgets near the measured p75 of actual role wall time (review/investigate are far shorter than implement) instead of one 25m for everything; separate the default from the ceiling so a node may declare a larger budget up to the fence without a host config edit. Done when a 45m implement node dispatches against defaults while a review node defaults smaller.

Runtime watchdog. The budget becomes a deadline signal, not a dead letter: the live classification flags budget-overrun runs, and an opt-in enforcement (grace multiple, then stop with phase recorded) exists for orchestrators that want it. Done when a synthetic overrun is flagged within one poll and the opt-in stop leaves a truthful phase.

Concurrency config wired or deleted. backends.*.concurrency either becomes a dispatch admission check (refuse when live runs on that backend reach it) or leaves the schema; declared-but-dead config is worse than either. Done when the flight schema, provenance and docs agree with the runtime behaviour.

§4 — Cheap observation and state writes

Fleet polling. The contract prescribes one polling surface — the MCP crew(view="live") (honest liveness lands in dispatch-lifecycle-safety) — and drops the per-run observe loop; crew list gains project/phase filters; the ledger records view gains plan/since/limit filters. Done when an eight-worker wave is monitorable in one call per beat.

Version-only read. A minimal read shape (or server-side version re-check in edit_plan) removes the 3–6k-token raw read whose only consumed field is version. Done when a landing's state write costs one small call.

Roles for the workers the contract already mandates. Test and doc workers get configured roles (or the contract stops mandating role names the CLI refuses). Done when every worker type in the skill dispatches without a role error.

§5 — Skill/CLI reconciliation sweep

Fold the review's contract-gap list into one pass: stale classifier prose (the manifest IS read now), the missing budget view in the skill's read table and the stale MCP view literal, manifest-path guidance unified on the durable default, the member-collision paragraph updated once the guard lands, in-harness caveats on resume/stop/continuity, the undocumented vendored-script prerequisite (present-check at dispatch with a clear error), and the config-home rename reflected in the repo AGENTS.md. Done when a fresh orchestrator can follow the skill against the current CLI without hitting a documented-but-absent or absent-but-required step.

§ Decisions

Wire backends.*.concurrency as a dispatch admission check, or delete it from the schema?

Wiring gives a real per-backend cap tunable per host/project; deleting keeps admission purely roster-driven and the config surface smaller. The status quo — declared and ignored — misleads every reader.
