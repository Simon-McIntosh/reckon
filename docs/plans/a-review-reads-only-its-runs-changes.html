Deliverable. One shared helper, own_changed_paths(tree, older, tip, *, integration_ref), in reckon/clones.py beside changed_paths (near line 629). It returns the paths changed by commits reachable from tip but not from older or integration_ref; this is the rule unintegrated_claim_work in reckon/crew/node.py already applies to commits (its rev-list near line 1662), expressed as paths.
