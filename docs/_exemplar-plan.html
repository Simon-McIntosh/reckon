Plan, research, and evidence authoring

This file is a working plan and the canonical annotated source for all three typed HTML resources. Copy the matching specimen, replace its example identity and prose, then run reckon audit-doc <path> before relying on it.

How to use this file

ResourceCopyMachine-readable relationship
Plan This complete file, including the semantic collections below plan-depends-on only for executable prerequisites
Research The complete specimen under Research record plan-informs names the plans that consume the input
Evidence The complete specimen under Evidence record plan-evidence-for names the plan whose execution it records

Authored prose lives outside section[data-reckon]. Structured writes may regenerate those semantic collections, while preserving this prose. Never author plan-version, plan-modified, or plan-impl; the server owns them.

Plan record

The document you are reading is the plan specimen. Its head carries stable identity, lifecycle, effort, ownership, and topical tags. The semantic collections at the end exercise every collection parsed and regenerated by Reckon. Keep actionable decisions, gates, followups, and questions on plans only.

docs-project and plan-slug
Form the stable project-qualified identity.
reckon-type=plan
Enables plan lifecycle and workflow collections.
plan-effort-hours and plan-wall-clock-hours
Record total worker effort and elapsed time at supported parallelism.
data-reckon sections
Visible semantic state, not hidden JSON or a sidecar file.

Evidence record

Evidence is an execution outcome. It points back with plan-evidence-for, optionally narrows the verified sections, and retains commands, artifacts, quantitative measures, and caveats. This specimen is complete and can be copied as one file.
