A run's gates are the distinct log paths it cites (test_logs, baseline_suite.log_path, after_suite.log_path, each read once) joined with the test-runner tool calls in its stream. A tool call whose text contains a cited log path is the same gate as that log and is charged once, at the log's duration. A gate's duration is the runner's own in N s summary, read by reckon.crew.promotion_gate._GATE_LOG_DURATION; only where no log reports one does the foreground tool call's wall span stand in. A gate that ran in the background and cites no log has neither, so its run has no measurable share. The denominator is wall_seconds from read_records — the span between the row's own dispatched_at and completed_at.

Did the denominator cover every attempt? Checked run by run against the supervisor's per-attempt attempt-*-exit.json stamps. Where the attempt spans sit outside the row's own span, the run is listed under “wall span misses an attempt” in §5 rather than silently averaged in.

§6 — What this measurement cannot see

  • A gate with no cited log and no foreground tool call — typically a backgrounded gate citing nothing — is counted unmeasurable, not zero. Those runs enter neither median; the counts above say how many.
