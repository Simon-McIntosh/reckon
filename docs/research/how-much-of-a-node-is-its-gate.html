Conclusion. On this host the budget is a soft limit for every mounted project: the watchdog that could stop a worker is disabled everywhere, and the paths that remain either state the deadline or label a run after the fact. A worker that cuts its gate short to meet the deadline is responding to the prompt, not to any enforcement. The one exception is structural rather than a fence: a worker placed as its own scheduler job is submitted under a one-hour time limit that the scheduler enforces, so on that path a gate is cut by the partition, not by the run.

A run's gates are the cited logs that carry a test runner's own in N s summary, joined with the test-runner tool calls in its stream. A tool call that wrote a cited log is the same gate as that log and is charged once, at the log's duration: the join names the log's absolute path, and falls back to its file name only where that name identifies one of the run's cited logs alone. Where no log reports a duration, a foreground tool call's own span stands in. A cited log that no runner wrote and that carries no duration — a soak, a census, a probe — is not a gate, and the runs citing one are named in §5. The denominator is wall_seconds from read_records, the span between the row's own dispatched_at and completed_at.

§6 — What this measurement cannot see

  • A gate whose command the detector cannot classify is invisible: a suite launched through a shell variable, eval, or a heredoc. The detector resolves wrappers (uv run, env, timeout, bash -lc, srun, sbatch --wrap) and ;/&&/| chains, and --control-detector checks seventeen shapes whose answer is known, in both directions.
  • A cited log whose worktree was released, or whose run was pruned, cannot be read; it becomes an unmeasured gate unless promotion preserved a copy under the run directory.
  • The denominator is the row's own wall span. It includes coordinator wait and any resume gap, so a share is diluted by time the worker spent waiting rather than working.
  • A tool-call span includes shell startup, so a gate charged from the fallback reads slightly longer than the runner reports. Measured on one run: 88.4 s against the log's 80.8 s, about 9%.
  • A run whose wall span misses an attempt has a denominator wrong in an unknown direction; it is recorded per lane so a reader can exclude it.
