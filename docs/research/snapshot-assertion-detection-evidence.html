The proposed mechanism meets both bounds. It flags 3 of 4 historical snapshot assertions at their own pre-repair revisions, meeting the required minimum of three, and flags 0 of 4 legitimate exact-value carve-outs.

The sensitivity result is deliberately not described as universal. The literal-token specimen survives an additive perturbation, so perturb-and-observe detects closedness and source-order coupling but does not detect every assertion that pins implementation text.

Method

For each historical specimen, the experiment read the assertion and its observed source from the repository revision immediately before the recorded repair. The assertion was first evaluated unchanged. A single benign member was then added to the observed value while the asserted behaviour was preserved. A specimen is flagged only when the unchanged assertion passes and the perturbed assertion fails:

flagged = baseline_pass and not perturbed_pass

The control is load-bearing: every baseline passed, and every historical source probe also confirmed a known marker was present before interpreting an absence. The positional specimen additionally uses the real historical transition from commit b04df538961a554b893b4120be53bec5cb9fca07 to pre-repair revision eb517152ec03c6b27958703f96fd9e70e045d0f6; the added renderRun helper retained member and section rendering while moving those tokens ahead of the source anchor.

Decision consequence and limit

Perturb-and-observe is viable for the declared bound. It reaches the required 3-of-4 historical sensitivity with zero flags across the four named carve-outs. A bound check can therefore use additive perturbations where the observed container has an honest injection point.

It should not be sold as a source-literal linter. The one historical miss shows the exact boundary: required-token membership survives an addition even when it is still a snapshot of implementation spelling. Detecting that separate class needs substitution, deletion, or a rendered behaviour control. Keeping that limitation explicit prevents a passing perturbation gate from implying broader coverage than it measured.
