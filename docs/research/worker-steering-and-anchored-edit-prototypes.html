§2 — The duplicate delivery the steering prototype exposed

In the Claude run the model issued its three echo commands as parallel tool calls. Three hook processes ran concurrently, each found the same unread message, and each delivered it. The receipts file held three rows for one message, all within 0.2 ms: {"message": "001.md", "delivered_at": 1794326473.1949534, "event": "PostToolUse", "tool": "Bash"}, then the same at …194959 and …1951315. A product hook must claim each message atomically, for example by renaming it into a claimed name, so exactly one hook process delivers it.

§3 — The steering hook as run

Registered as {"hooks":{"PostToolUse":[{"matcher":"*","hooks":[{"type":"command","command":"STEER_INBOX=<dir>/inbox <dir>/hook.py"}]}]}} through claude -p --settings, with the prompt on stdin and --allowedTools "Bash(echo:*)".

#!/usr/bin/env python3
# Deliver unread inbox messages as additionalContext after a tool call; record a receipt.
import json
import os
import pathlib
import sys
import time

event = json.load(sys.stdin)
inbox = pathlib.Path(os.environ["STEER_INBOX"])
msgs = sorted(inbox.glob("*.md"))
if not msgs:
    sys.exit(0)
text = "\n\n".join(f"[coordinator message {p.name}]\n{p.read_text()}" for p in msgs)
receipt = inbox.parent / "receipts.jsonl"
with receipt.open("a") as f:
    for p in msgs:
        f.write(json.dumps({
            "message": p.name,
            "delivered_at": time.time(),
            "event": event.get("hook_event_name"),
            "tool": event.get("tool_name"),
        }) + "\n")
        p.rename(p.with_suffix(".delivered"))
print(json.dumps({"hookSpecificOutput": {
    "hookEventName": event.get("hook_event_name", "PostToolUse"),
    "additionalContext": text,
}}))

§4 — The anchored edit server as run

Started over stdio from the reckon checkout's interpreter (mcp 1.28.1). For Claude: --mcp-config naming it, --strict-mcp-config, and its two tools in --allowedTools. For codex: -c mcp_servers.anchored.command=…, -c mcp_servers.anchored.args=[…] and the approval mode above, with -s workspace-write. It has no write-root confinement; the product module must add it, because an MCP server runs outside codex's command sandbox.

"""Prototype: line-anchored file editing over MCP.

read_anchored returns each line as ``N:HHH|text``, where HHH is a short hash of
the line's content. edit_anchored addresses lines by those anchors, so the model
never retypes the old text; an anchor whose hash no longer matches the file is
refused before anything is written, and the refusal carries fresh anchors for
the region so a retry needs no re-read.
"""

from __future__ import annotations

import hashlib
from pathlib import Path

from mcp.server.fastmcp import FastMCP

HASH_CHARS = 3
CONTEXT = 3
server = FastMCP("anchored-edit")


def line_hash(text: str) -> str:
    return hashlib.sha1(text.encode("utf-8", "surrogatepass")).hexdigest()[:HASH_CHARS]


def render(lines: list[str], start: int, stop: int) -> str:
    return "\n".join(f"{n}:{line_hash(lines[n - 1])}|{lines[n - 1]}" for n in range(start, stop + 1))


def parse_anchor(anchor: str) -> tuple[int, str]:
    number, _, digest = anchor.strip().partition(":")
    return int(number), digest.split("|", 1)[0]


@server.tool()
def read_anchored(path: str, offset: int = 1, limit: int = 400) -> str:
    """Read a text file as anchored lines `N:HASH|text`. Use the `N:HASH` anchors with edit_anchored."""
    lines = Path(path).read_text().split("\n")
    stop = min(len(lines), offset + limit - 1)
    header = f"{path}: lines {offset}-{stop} of {len(lines)}"
    return header + "\n" + render(lines, offset, stop)


@server.tool()
def edit_anchored(path: str, edits: list[dict]) -> str:
    """Apply edits addressed by anchors from read_anchored.

    Each edit: {"start": "N:HASH", "end": "M:HASH" (optional, inclusive, default start),
    "op": "replace" | "insert_after" | "insert_before" (default replace),
    "text": "new lines joined by \\n; empty string with replace deletes the range"}.
    All anchors are checked before anything is written; a stale anchor refuses the whole call.
    """
    target = Path(path)
    lines = target.read_text().split("\n")
    resolved = []
    stale = []
    for edit in edits:
        start, start_hash = parse_anchor(edit["start"])
        end, end_hash = parse_anchor(edit.get("end") or edit["start"])
        for number, digest in ((start, start_hash), (end, end_hash)):
            if not 1 <= number <= len(lines) or line_hash(lines[number - 1]) != digest:
                stale.append(number)
        resolved.append((start, end, edit.get("op", "replace"), edit.get("text", "")))
    if stale:
        regions = []
        for number in sorted(set(stale)):
            low = max(1, number - CONTEXT)
            high = min(len(lines), number + CONTEXT)
            regions.append(render(lines, low, high))
        return "REFUSED: stale anchor(s) at line(s) " + ", ".join(map(str, sorted(set(stale)))) + \
            "; nothing was written. Current anchors:\n" + "\n...\n".join(regions)
    spans = sorted(resolved, key=lambda item: item[0], reverse=True)
    for (a_start, a_end, *_), (b_start, b_end, *_) in zip(spans, spans[1:]):
        if b_end >= a_start:
            return f"REFUSED: edits overlap at lines {b_start}-{b_end} and {a_start}-{a_end}; nothing was written."
    touched = []
    for start, end, op, text in spans:
        new = [] if (op == "replace" and text == "") else text.split("\n")
        if op == "replace":
            lines[start - 1:end] = new
            touched.append((start, start + len(new) - 1))
        elif op == "insert_after":
            lines[end:end] = new
            touched.append((end + 1, end + len(new)))
        elif op == "insert_before":
            lines[start - 1:start - 1] = new
            touched.append((start, start + len(new) - 1))
        else:
            return f"REFUSED: unknown op {op!r}; nothing was written."
    target.write_text("\n".join(lines))
    shown = []
    for start, end in sorted(touched):
        low = max(1, start - 1)
        high = min(len(lines), max(end, start) + 1)
        shown.append(render(lines, low, high))
    return f"OK: {len(edits)} edit(s) applied to {path}. Fresh anchors around the change:\n" + "\n...\n".join(shown)


if __name__ == "__main__":
    server.run()
